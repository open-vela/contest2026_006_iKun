# 考试历史页编译失败修复报告

时间：2026-09-17 23:56

## 1. 问题描述

考试历史页编译失败，错误信息：Unsupported Event value。快应用的 onclick 事件不支持三元表达式。

## 2. 根因分析

快应用的 onclick 事件只支持四种格式：
1. 箭头函数：onClick="()=>{}"
2. 函数：onClick="function(){}"
3. 函数名：onClick="funName"
4. 调用表达式：onClick="funName(x, y)"

当前考试列表项的 onclick 用了三元表达式，快应用编译器无法解析。

## 3. 修改方案

将考试列表项的 onclick 从三元表达式改为调用一个统一方法，在方法内部根据 selectMode 判断走哪个逻辑。

## 4. 修改的文件和行号

| 文件 | 行号 | 修改内容 |
|------|------|----------|
| `src/pages/exam-history/exam-history.ux` | 68 | onclick 从三元表达式改为 onExamItemClick($item.id) |
| `src/pages/exam-history/exam-history.ux` | 443-450 | 新增 onExamItemClick 方法 |

未修改其他文件。
