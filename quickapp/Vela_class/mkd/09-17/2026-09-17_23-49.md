# 考试历史页面批量选择清除功能报告

时间：2026-09-17 23:49

## 1. 问题描述

考试历史页已有一键清除功能，现在需要增加批量选择清除功能。用户点"管理"进入选择模式，可勾选多个考试项，然后批量删除选中的用户添加的考试。

## 2. 根因分析

需要增加选择模式，复用已有的 clearHistoryExams 和 isUserCreatedExam 函数。

## 3. 修改方案

在操作栏增加"管理"按钮，点击进入选择模式：
- 操作栏切换为"已选N项" + "全选" + "删除" + "完成"
- 考试项左侧出现勾选圆圈
- Mock 考试显示锁定标记且不可选

| `src/pages/exam-history/exam-history.ux` | 模板、private、样式、方法 |

## 6. 测试步骤

### 正常模式
1. 进入考试历史页
2. 确认有"管理"按钮
3. 点考试项跳转详情正常

### 进入选择模式
1. 点"管理"
2. 操作栏变为"已选0项"+"全选"+"删除"+"完成"
3. 考试项左侧出现勾选圆圈

### 勾选
1. 点用户考试项 → 圆圈变为实心 → "已选"计数增加
2. 点 Mock 考试项 → 不响应（显示🔒）

### 全选
1. 点"全选" → 所有用户考试被选中
2. 再点"全选" → 取消全选

### 删除
1. 勾选若干项
2. 点"删除" → 确认提示
3. 点"确认" → toast 提示已删除
4. 自动退出选择模式 → 列表刷新

### 取消
1. 点"完成" → 退出选择模式，恢复正常显示

### 左滑返回
1. 选择模式下左滑 → 退出选择模式而非返回上一页
