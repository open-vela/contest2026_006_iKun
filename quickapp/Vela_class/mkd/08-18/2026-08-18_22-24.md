## 2. 待办持久化修复

### 原存储方式
- 使用 `localStorage.getItem()` / `localStorage.setItem()`
- 与 OpenVela Quick App 官方存储方式不一致

### 新存储方式
- 使用 `import storage from '@system.storage'`
- 通过 `storage.get()` / `storage.set()` 实现持久化

### system.storage 声明
- 在 manifest.json 的 features 中增加 `{ "name": "system.storage" }`

### cache 设计
- 内存缓存：`courseCache`、`examCache`、`taskCache`
- 页面运行期间同步读取缓存
- system.storage 负责真正持久化

### updateTaskStatus 保存逻辑
- 更新内存缓存中的任务状态
- 调用 `storage.set()` 持久化到系统存储
- 返回 Promise，成功后才刷新页面

## 3. 详情页完成状态

### 标记完成流程
1. 点击"标记完成"
2. 调用 `updateTaskStatus(taskId, true)`
3. 等待 Promise 成功
4. 重新 `loadTask()` 读取最新状态
5. 页面立即显示"取消完成"

### 取消完成流程
1. 点击"取消完成"
2. 调用 `updateTaskStatus(taskId, false)`
3. 等待 Promise 成功
4. 重新 `loadTask()` 读取最新状态
5. 页面立即显示"标记完成"

### 状态刷新方式
- 使用 Promise 异步等待存储成功
- 成功后调用 `this.loadTask()` 刷新当前页面

## 4. 待办主页刷新

### onInit
- 页面创建时调用 `loadTasks()`

### onShow
- 页面每次显示时调用 `loadTasks()`
- 从详情页返回时自动刷新列表

### 返回页面后如何刷新列表
- `onShow` 生命周期自动触发
- 重新读取 `getTasks()` 获取最新状态
- 任务自动分配到正确的分组

## 5. 已完成任务

### 是否支持点击详情
- 已完成任务的 `task-info` 绑定 `onclick="goToDetail($item.id)"`
- 点击任务文字区域可进入详情

### 是否支持直接恢复未完成
- 已完成任务左侧 ● 绑定 `onclick="toggleTask($item.id)"`
- 点击可直接恢复为未完成状态

### 已完成数量显示
- 标题改为 `已完成 · {{ finishedTasks.length }}`
