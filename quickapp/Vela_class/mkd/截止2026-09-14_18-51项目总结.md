# VELA CLASS 项目总结报告

时间：2026-09-14 18:51

## 一、项目概述

VELA CLASS 是一款运行在 OpenVela 智能手表上的校园助手应用，基于 QuickApp 框架开发，设计尺寸为 466×466 圆形屏幕。

**项目定位**：学生校园助手，帮助学生管理课程、考试和待办事项。

**技术栈**：
- 框架：OpenVela QuickApp
- 设计尺寸：466×466 圆形屏幕
- 存储：@system.storage
- 输入法：自定义 InputMethod 扩展组件

## 二、核心功能

### 1. 首页（home）

- **实时时间显示**：当前时间和日期
- **智能课程状态**：
  - 下一节课：课程名、开始时间、教室、倒计时
  - 正在上课：课程名、剩余时间、进度条
  - 今日课程结束：显示明天/最近课程
  - 今日无课：显示最近考试信息
- **底部摘要**：课表、考试、待办入口
- **定时刷新**：每秒更新时间，每30秒更新课程状态，每60秒更新考试倒计时

### 2. 课表模块（schedule）

- **今日模式**：纵向时间轴显示今日课程，区分已结束/进行中/未开始
- **本周模式**：周次选择器 + 星期选择器 + 课程列表
- **全部模式**：显示整个学期所有课程，含单双周标签
- **学期设置**：支持自定义学期第一周日期
- **教学周计算**：支持16周教学周，自动计算当前教学周

### 3. 考试模块（exam）

- **考试列表**：显示所有未来考试
- **考试详情**：考试时间、地点、课程信息
- **考试倒计时**：支持天/小时/分钟显示
- **历史考试**：已结束考试归档
- **进行中状态**：考试进行中时显示"考试进行中"

### 4. 待办模块（task）

- **智能分组**：已逾期/今天/本周/以后/已完成
- **状态管理**：支持标记完成/取消完成
- **倒计时**：显示截止时间倒计时
- **紧急程度**：红色/橙色/灰色标识

### 5. 添加功能

- **添加课程**：分步骤填写（基本信息→时间→周次）
- **添加考试**：选择课程、日期、时间、考场
- **添加待办**：任务名称、关联课程、类型、截止时间

### 6. Debug 功能

- **默认演示数据开关**：控制是否显示 Mock 数据
- **重新加载默认数据**：更新 Mock 数据缓存
- **入口**：首页连续点击5次"VELA CLASS"

## 三、技术架构

### 数据层

- **Storage 模块**：统一数据源管理，内存缓存 + system.storage 持久化
- **Mock 数据**：15门课程、3场考试、8个待办
- **数据隔离**：Mock 数据与用户数据分离，支持动态合并

### 业务逻辑层

- **schedule.js**：课程状态判断、周次计算、课程筛选
- **exam.js**：考试状态管理、倒计时计算
- **task.js**：待办分类、紧急程度判断
- **time.js**：时间工具函数

### UI 层

- **OLED 深色主题**：#000000 背景
- **状态色系统**：蓝/绿/红/紫/橙
- **圆形屏幕适配**：466×466 安全布局
- **自定义输入法**：InputMethod 扩展组件

## 四、已完成优化

1. **首页性能优化**：拆分定时器，减少不必要的计算
2. **数据同步优化**：页面返回时自动刷新数据
3. **Mock 数据隔离**：支持开启/关闭默认演示数据
4. **键盘避让优化**：使用自定义 InputMethod 替代系统键盘
5. **异常处理**：Storage 读取失败、数据为空等情况的容错
6. **生命周期管理**：定时器正确创建和销毁

## 五、可提升的地方

### 1. 输入法体验

- **问题**：当前使用 div + text 模拟输入框，输入体验不如原生 input
- **建议**：等待 OpenVela 支持真正的文本输入组件，或优化 InputMethod 交互

### 2. 数据同步

- **问题**：当前使用 localStorage，多设备无法同步
- **建议**：可考虑接入云同步服务

### 3. 课程冲突检测

- **问题**：添加课程时未检测时间冲突
- **建议**：添加课程时检查是否与已有课程时间重叠

### 4. 通知提醒

- **问题**：当前没有推送通知功能
- **建议**：课程开始前、考试前、待办截止前提醒

### 5. 数据导入导出

- **问题**：当前不支持数据备份和恢复
- **建议**：支持导出/导入 JSON 格式数据

### 6. 主题切换

- **问题**：当前只有深色主题
- **建议**：支持浅色主题切换

### 7. 性能优化

- **问题**：列表滚动在数据量大时可能卡顿
- **建议**：使用虚拟列表优化

### 8. 国际化

- **问题**：当前只有中文界面
- **建议**：支持多语言切换
