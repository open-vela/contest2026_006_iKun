## 四、Timer生命周期分析

### 当前设计

```
首次进入
  ↓
onInit()
  ↓
ensureStorageReady()
  ↓
startTimers()  ← 创建定时器

页面显示
  ↓
onShow()
  ↓
ensureStorageReady()
  ↓
startTimers()  ← 重新创建定时器（内部先清理再创建）

页面隐藏
  ↓
onHide()
  ↓
clearTimers()  ← 清理定时器

页面销毁
  ↓
onDestroy()
  ↓
clearTimers()  ← 再次确保清理
```

### 定时器列表

| 定时器 | 变量名 | 周期 | 职责 |
|--------|--------|------|------|
| 时间定时器 | timeTimer | 1秒 | 更新时间显示 |
| 课程状态定时器 | courseTimer | 30秒 | 更新课程状态 |
| 考试倒计时定时器 | examTimer | 60秒 | 更新考试倒计时 |

### 关键函数分析

#### startTimers()

```javascript
startTimers() {
  this.clearTimers()  // 先清理现有定时器
  
  // 创建新定时器
  this.timeTimer = setInterval(...)
  this.courseTimer = setInterval(...)
  this.examTimer = setInterval(...)
}
```

**特点**：每次调用前先清理，确保不会重复创建。

#### clearTimers()

```javascript
clearTimers() {
  if (this.timeTimer) {
    clearInterval(this.timeTimer)
    this.timeTimer = null
  }
  if (this.courseTimer) {
    clearInterval(this.courseTimer)
    this.courseTimer = null
  }
  if (this.examTimer) {
    clearInterval(this.examTimer)
    this.examTimer = null
  }
}
```

**特点**：逐个检查、清理、置空，确保完整清理。
