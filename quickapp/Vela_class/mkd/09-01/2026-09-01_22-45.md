## 一、修改内容

## 二、检查发现的问题

**问题**：首页 `onShow()` 没有从 Storage 重新读取数据，直接使用内存缓存。

**原代码流程**：
```
onShow()
  ↓
ensureStorageReady()
  ↓
updateStaticSummary()  ← 直接使用内存缓存
updateCourseStatus()   ← 直接使用内存缓存
```

**问题场景**：
1. 用户在考试页面新增考试 → 考试页面调用 `refreshExamsFromStorage()` 更新内存缓存
2. 返回首页 → 首页直接调用 `getNearestExam()` 读取内存缓存
3. 但首页自己的内存缓存可能还是旧数据

## 三、修改文件

## 四、首页数据同步流程分析

### 修改后的流程

```
onShow()
  ↓
ensureStorageReady()
  ↓
refreshExamsFromStorage()     ← 从 Storage 重新读取考试数据
refreshTasksFromStorage()     ← 从 Storage 重新读取任务数据
refreshCoursesFromStorage()   ← 从 Storage 重新读取课程数据
  ↓
updateStaticSummary()         ← 使用最新数据
updateCourseStatus()          ← 使用最新数据
```

### 关键代码修改

#### 导入语句（第301行）

```javascript
// 修改前
import { ensureStorageReady } from '../../common/storage'

// 修改后
import { ensureStorageReady, refreshExamsFromStorage, refreshTasksFromStorage, refreshCoursesFromStorage } from '../../common/storage'
```

#### onShow() 函数（第380-401行）

```javascript
onShow() {
  ensureStorageReady()
    .then(() => Promise.all([
      refreshExamsFromStorage(),
      refreshTasksFromStorage(),
      refreshCoursesFromStorage()
    ]))
    .then(() => {
      this.updateTime()
      this.updateStaticSummary()
      this.updateCourseStatus()
      this.startTimers()
    })
}
```
