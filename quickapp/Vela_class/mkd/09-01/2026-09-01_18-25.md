# 项目修改报告

时间：2026-09-01 18:25

## 一、修改内容

优化首页倒计时显示逻辑，解决"剩余0分钟"无意义显示问题。

## 二、修改原因

当考试剩余时间是整小时（如60分钟、120分钟）时，`remainingMinutes` 为 0，导致显示"剩余0分钟"，影响用户体验。

## 三、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/home/home.ux` | 修改倒计时显示条件 |

## 四、修改内容

### 修改前

```html
<text if="{{ examCountdown.isOngoing }}" class="exam-remaining">剩余{{ examCountdown.remainingMinutes }}分钟</text>
```

### 修改后

```html
<text if="{{ examCountdown.isOngoing && examCountdown.remainingMinutes > 0 }}" class="exam-remaining">剩余{{ examCountdown.remainingMinutes }}分钟</text>
```

### 显示逻辑

| 剩余时间 | value | unit | remainingMinutes | 显示效果 |
|----------|-------|------|------------------|----------|
| 90分钟 | 1 | 小时 | 30 | 1小时 剩余30分钟 |
| 61分钟 | 1 | 小时 | 1 | 1小时 剩余1分钟 |
| 60分钟 | 1 | 小时 | 0 | 1小时（不显示剩余分钟） |
| 59分钟 | 59 | 分钟 | 0 | 59分钟 |
| 30分钟 | 30 | 分钟 | 0 | 30分钟 |
| 1分钟 | 1 | 分钟 | 0 | 1分钟 |

## 五、测试结果

| 测试场景 | 预期显示 | 实际结果 |
|----------|----------|----------|
| 剩余90分钟 | 1小时 剩余30分钟 | ✓ |
| 剩余61分钟 | 1小时 剩余1分钟 | ✓ |
| 剩余60分钟 | 1小时（无剩余分钟） | ✓ |
| 剩余59分钟 | 59分钟 | ✓ |
| 剩余1分钟 | 1分钟 | ✓ |
| 已结束考试 | 保持原逻辑 | ✓ |

## 六、是否存在潜在影响

- 无潜在影响
- 只修改了显示层逻辑
- 不影响数据计算和定时刷新机制
