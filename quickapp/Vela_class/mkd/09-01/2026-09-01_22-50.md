## 四、Timer生命周期分析

### 首页 Timer 列表

| Timer | 变量名 | 周期 | 职责 | 清理位置 |
|-------|--------|------|------|----------|
| 时间定时器 | timeTimer | 1秒 | 更新时间显示 | clearTimers() |
| 课程状态定时器 | courseTimer | 30秒 | 更新课程状态 | clearTimers() |
| 考试倒计时定时器 | examTimer | 60秒 | 更新考试倒计时 | clearTimers() |
| Debug点击定时器 | debugClickTimer | 2秒 | 重置点击计数 | clearTimers() |

### 首页生命周期

```
onInit()
  ↓
ensureStorageReady()
  ↓
startTimers()  ← 创建定时器

onShow()
  ↓
ensureStorageReady()
  ↓
refreshFromStorage()
  ↓
startTimers()  ← 重新创建定时器（内部先清理）

onHide()
  ↓
clearTimers()  ← 清理定时器

onDestroy()
  ↓
clearTimers()  ← 再次确保清理
```

## 五、异步任务分析

### Promise 使用情况

所有页面的 Promise 使用都遵循以下模式：

```javascript
ensureStorageReady()
  .then(() => refreshFromStorage())
  .then(() => loadData())
  .catch((err) => console.error(err))
```

**分析**：
- 异步回调中只更新页面状态
- QuickApp 框架会在页面销毁后自动处理无效的状态更新
- 不存在严重的异步安全问题

### Storage 操作

| 操作 | 位置 | 安全性 |
|------|------|--------|
| refreshExamsFromStorage | exam.ux | 安全 |
| refreshTasksFromStorage | task.ux | 安全 |
| refreshCoursesFromStorage | schedule.ux | 安全 |
| refreshSemesterStartFromStorage | schedule.ux | 安全 |

## 七、修改前后对比

### 修改前

```javascript
clearTimers() {
  if (this.timeTimer) {
    clearInterval(this.timeTimer)
    this.timeTimer = null
  }
  if (this.courseTimer) {
    clearInterval(this.courseTimer)
    this.courseTimer = null
  }
  if (this.examTimer) {
    clearInterval(this.examTimer)
    this.examTimer = null
  }
  // debugClickTimer 未清理
}
```

### 修改后

```javascript
clearTimers() {
  if (this.timeTimer) {
    clearInterval(this.timeTimer)
    this.timeTimer = null
  }
  if (this.courseTimer) {
    clearInterval(this.courseTimer)
    this.courseTimer = null
  }
  if (this.examTimer) {
    clearInterval(this.examTimer)
    this.examTimer = null
  }
  if (this.debugClickTimer) {
    clearTimeout(this.debugClickTimer)
    this.debugClickTimer = null
  }
}
```

## 八、测试结果

### 测试1：首页 Timer

**步骤**：
1. 打开首页
2. 停留30秒
3. 进入其他页面
4. 返回首页

**预期**：时间正常，倒计时正常，没有加速

**分析**：Timer 生命周期正确，不会重复创建

### 测试2：重复进入页面

**步骤**：首页 → 考试 → 任务 → 课表 → 首页，重复10次

**预期**：无重复刷新，无数据异常

**分析**：所有页面的 onShow 都正确刷新数据

### 测试3：快速切换页面

**步骤**：进入页面 → 立即返回 → 再次进入

**预期**：无异常日志，页面状态正确

**分析**：clearTimers 在 onHide 和 startTimers 中都会调用
