# 项目修改报告

时间：2026-09-01 17:29

## 一、修改内容

修复课表模块周日期计算、考试进行中状态、首页考试倒计时刷新问题：

1. 未设置学期第一周时，切换第2周、第3周后日期没有变化
2. 考试开始后考试记录会消失，无法显示"进行中"
3. 首页长时间停留时考试倒计时不会刷新

## 二、问题原因分析

### 问题1：未设置学期第一周时周日期不变化

**原因**：updateWeekDates() 的 fallback 逻辑没有考虑 selectedWeek

原代码：
```javascript
} else {
  // 未设置学期第一周时，使用当前自然周作为备选
  const currentWeekday = getWeekdayNumber(now)
  const mondayOffset = currentWeekday - 1
  const monday = new Date(now)
  monday.setDate(monday.getDate() - mondayOffset)
  targetMonday = monday  // 没有考虑 selectedWeek！
}
```

**影响**：
- 第1周、第2周、第3周都显示相同的日期
- 周切换功能失效

### 问题2：考试开始后消失

**原因**：getUpcomingExams() 和 getNearestExam() 只考虑开始时间

原代码：
```javascript
.filter(e => parseDateTime(`${e.date}T${e.startTime}:00`) > now)
```

**影响**：
- 考试开始后立即从列表中消失
- 无法显示"进行中"状态
- 例如：考试 09:00-11:00，在 10:00 时已经消失

### 问题3：首页考试倒计时不刷新

**原因**：examCountdown 只在 updateStaticSummary() 中更新，而该函数只在 onShow 时调用

原代码逻辑：
- onShow → updateStaticSummary() → 更新 examCountdown
- 之后不再更新

**影响**：
- 用户停留首页时，考试倒计时不会变化
- 例如：显示"还有2小时"，5分钟后仍然显示"还有2小时"

## 四、课表周日期计算修复

### 修改后的 updateWeekDates()

```javascript
} else {
  // 未设置学期第一周时，使用当前自然周作为第1周基准
  const currentWeekday = getWeekdayNumber(now)
  const mondayOffset = currentWeekday - 1
  const monday = new Date(now)
  monday.setDate(monday.getDate() - mondayOffset)
  // 增加 (selectedWeek - 1) * 7 天来计算目标周
  targetMonday = new Date(monday)
  targetMonday.setDate(targetMonday.getDate() + (this.selectedWeek - 1) * 7)
}
```

### 计算示例

假设今天是 2026-09-01（周一），未设置学期第一周：

| selectedWeek | 计算过程 | 结果 |
|--------------|----------|------|
| 1 | 9月1日 + 0天 | 9月1日~9月7日 |
| 2 | 9月1日 + 7天 | 9月8日~9月14日 |
| 3 | 9月1日 + 14天 | 9月15日~9月21日 |

## 六、首页考试倒计时刷新优化

### 新增定时器

```javascript
// 考试倒计时定时器：每60秒更新考试倒计时
this.examTimer = setInterval(() => {
  this.updateExamCountdown()
}, 60000)
```

### 轻量刷新函数

```javascript
// 轻量刷新考试倒计时（每60秒调用，不重新查询考试列表）
updateExamCountdown() {
  if (this.currentExam) {
    const now = getNow(DEBUG_NOW)
    this.examCountdown = getExamCountdown(this.currentExam, now)
  }
}
```

### 保存当前考试对象

```javascript
// 在 updateStaticSummary() 中
const nearestExam = getNearestExam(now)
this.nearestExam = nearestExam
this.currentExam = nearestExam  // 保存当前考试对象用于轻量刷新
```

### 定时器生命周期

| 定时器 | 周期 | 职责 |
|--------|------|------|
| timeTimer | 1秒 | 更新时间显示 |
| courseTimer | 30秒 | 更新课程状态 |
| examTimer | 60秒 | 更新考试倒计时 |

所有定时器在 onHide() 和 onDestroy() 时清理。
