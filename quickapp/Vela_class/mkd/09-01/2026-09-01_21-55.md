## 四、考试页面刷新流程分析

### 当前已实现的流程

```
考试页面显示
  ↓
onShow() 触发
  ↓
ensureStorageReady()
  ↓
refreshExamsFromStorage()  ← 重新读取考试数据
  ↓
loadExams()                ← 刷新考试列表
```

### 关键代码分析

#### onShow() 函数（exam.ux 第211-221行）

```javascript
onShow() {
  ensureStorageReady()
    .then(() => refreshExamsFromStorage())  // ← 重新读取 Storage
    .then(() => {
      this.loadExams()                      // ← 刷新列表
    })
    .catch((err) => {
      console.error('Failed to refresh exams:', err)
      this.loadExams()
    })
}
```

#### loadExams() 函数（exam.ux 第223-233行）

```javascript
loadExams() {
  const now = getNow(DEBUG_NOW)

  // 获取所有即将到来的考试
  const exams = getUpcomingExams(now)
  this.examList = exams.map(e => ({
    ...e,
    dateText: formatExamDate(e).split(' · ')[0],
    countdown: getExamCountdown(e, now)
  }))
}
```
