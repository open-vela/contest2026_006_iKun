## 二、问题原因分析

### 问题1：考试进行中倒计时文案错误

**原因**：getExamCountdown() 只计算距离开始的倒计时

原代码：
```javascript
export function getExamCountdown(exam, now) {
  const examDate = parseDateTime(`${exam.date}T${exam.startTime}:00`)
  return formatCountdown(examDate, now)
}
```

**影响**：
- 考试进行中时，仍然显示"距离考试开始"
- 例如：考试 09:00-11:00，在 10:00 时显示"距离考试开始 -1小时"

### 问题2：最近考试选择逻辑

**原因**：getNearestExam() 只按开始时间排序

原代码：
```javascript
.sort((a, b) => {
  const dateA = parseDateTime(`${a.date}T${a.startTime}:00`)
  const dateB = parseDateTime(`${b.date}T${b.startTime}:00`)
  return dateA - dateB
})
```

**影响**：
- 多个考试同时进行时，不优先选择进行中的考试
- 不优先选择即将结束的考试

## 四、考试状态展示优化

### 修改后的 getExamCountdown()

```javascript
export function getExamCountdown(exam, now) {
  const status = getExamStatus(exam, now)
  const examDate = parseDateTime(`${exam.date}T${exam.startTime}:00`)
  const examEnd = parseDateTime(`${exam.date}T${exam.endTime}:00`)

  if (status === 'ongoing') {
    // 考试进行中：计算剩余时间
    const remaining = examEnd - now
    const totalMinutes = Math.floor(remaining / (1000 * 60))
    const hours = Math.floor(totalMinutes / 60)
    const minutes = totalMinutes % 60

    if (hours > 0) {
      return { value: hours, unit: '小时', status: 'ongoing', isOngoing: true, remainingMinutes: minutes }
    }
    return { value: minutes, unit: '分钟', status: 'ongoing', isOngoing: true, remainingMinutes: 0 }
  }

  // 考试未开始：计算距离开始的时间
  const result = formatCountdown(examDate, now)
  return { ...result, status: status, isOngoing: false }
}
```

### 返回值结构

| 状态 | 返回值示例 |
|------|-----------|
| upcoming | `{ value: 2, unit: '小时', status: 'upcoming', isOngoing: false }` |
| ongoing (1小时20分) | `{ value: 1, unit: '小时', status: 'ongoing', isOngoing: true, remainingMinutes: 20 }` |
| ongoing (45分) | `{ value: 45, unit: '分钟', status: 'ongoing', isOngoing: true, remainingMinutes: 0 }` |

### 首页显示逻辑

```html
<text class="exam-label">{{ examCountdown.isOngoing ? '考试进行中' : '最近考试还有' }}</text>
<text class="exam-countdown">{{ examCountdown.value }} {{ examCountdown.unit }}</text>
<text if="{{ examCountdown.isOngoing }}" class="exam-remaining">剩余{{ examCountdown.remainingMinutes }}分钟</text>
```

## 五、最近考试选择逻辑优化

### 修改后的 getNearestExam()

```javascript
export function getNearestExam(now) {
  const exams = getExams()
  const validExams = exams
    .filter(e => {
      const examEnd = parseDateTime(`${e.date}T${e.endTime}:00`)
      return examEnd > now
    })

  // 分类：进行中 和 即将开始
  const ongoingExams = []
  const upcomingExams = []

  validExams.forEach(e => {
    const status = getExamStatus(e, now)
    if (status === 'ongoing') {
      ongoingExams.push(e)
    } else {
      upcomingExams.push(e)
    }
  })

  // 优先选择进行中的考试
  if (ongoingExams.length > 0) {
    // 多个进行中考试时，选择结束时间更早的
    ongoingExams.sort((a, b) => {
      const endA = parseDateTime(`${a.date}T${a.endTime}:00`)
      const endB = parseDateTime(`${b.date}T${b.endTime}:00`)
      return endA - endB
    })
    return ongoingExams[0]
  }

  // 否则选择即将开始的考试
  upcomingExams.sort((a, b) => {
    const startA = parseDateTime(`${a.date}T${a.startTime}:00`)
    const startB = parseDateTime(`${b.date}T${b.startTime}:00`)
    return startA - startB
  })

  return upcomingExams.length > 0 ? upcomingExams[0] : null
}
```

### 选择优先级

| 优先级 | 条件 | 排序依据 |
|--------|------|----------|
| 1 | 进行中的考试 | 结束时间更早的优先 |
| 2 | 即将开始的考试 | 开始时间更早的优先 |
