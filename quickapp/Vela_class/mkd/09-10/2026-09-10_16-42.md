# 输入系统重构报告

时间：2026-09-10 16:42

## 一、官方文档结论

### OpenVela input 组件

根据官方文档 https://iot.mi.com/vela/quickapp/zh/components/form/input.html：

**input 只支持三种类型**：
- `type="button"` - 按钮
- `type="checkbox"` - 复选框
- `type="radio"` - 单选框

**不支持 `type="text"`**，因此：
- `readonly` 属性不存在
- `disabled` 属性不存在
- `placeholder` 属性不存在
- `placeholder-color` 属性不存在
- `color` 是样式属性，不是组件属性
- `change` 事件只在 checkbox/radio 时触发

### OpenVela input-method 扩展组件

根据官方文档 https://iot.mi.com/vela/quickapp/zh/guide/developer-materials/extension-components.html：

- 是独立的输入法组件
- 适配不同屏幕形状（圆形、矩形、胶囊）
- 支持全键盘和九键模式
- 是 UI 组件，需要手动处理输入逻辑
- 不与 input 组件绑定

## 二、当前源码问题

### 问题1：两个键盘同时出现

**原因**：`<input type="text">` 不被官方支持，运行时可能将不支持的 type 当作默认类型处理，触发了系统默认行为导致系统键盘弹出。

### 问题2：InputMethod 无法输入

**原因**：input 的 `value` 绑定因类型不支持而无法正确更新显示，且系统键盘和 InputMethod 冲突。

### 问题3：颜色不生效

**原因**：
- `color` 是样式属性，但 `type="text"` 不被支持，样式可能不生效
- `placeholder-color` 不被官方支持
- `readonly` 不被官方支持

## 三、采用方案

**方案B**：恢复 div + text 显示 + InputMethod 输入方案

```
div.input-wrapper（点击触发 InputMethod）
  ↓
text 显示当前内容（placeholder + 输入文字）
  ↓
InputMethod 扩展键盘输入
  ↓
更新页面变量
  ↓
text 重新显示
```

## 五、输入流程

### task-add

```
用户点击 input-wrapper
    ↓
@click="onInputFocus('title')"
    ↓
记录 currentInputField = 'title'
    ↓
打开 InputMethod (keyboardHidden = false)
    ↓
用户点击扩展键盘按键
    ↓
@complete="onKeyboardInput"
    ↓
this.title += content
    ↓
<text>{{ title }}</text> 更新显示
    ↓
左滑退出
    ↓
保存内容 + 关闭键盘
```
