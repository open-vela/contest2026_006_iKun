# 项目修改报告

时间：2026-09-10 15:38

## 一、修改目标

实现官方 `<input>` + 自定义 InputMethod 扩展键盘的组合方案，解决：
1. input 默认文字颜色为黑色，在深色背景下不可见
2. 需要继续使用自定义扩展键盘 InputMethod

## 二、当前输入架构

```
官方 <input>
    |
    ↓
获取焦点 / 当前输入字段
    |
    ↓
自定义 InputMethod 扩展组件
    |
    ↓
用户点击键盘按键
    |
    ↓
input-change 事件
    |
    ↓
更新 input 对应 value
```

- **input 负责**：输入框、value 绑定、光标、focus 状态、页面布局
- **InputMethod 负责**：自定义键盘 UI、按键输入、删除、保存、退出

## 四、输入流程

### task-add（标题输入）

1. 用户点击 input → `onInputFocus('title')` → 记录 `currentInputField = 'title'` → 打开键盘
2. 用户点击键盘按键 → `onKeyboardInput(evt)` → `this.title += content`
3. 用户点击删除 → `onKeyboardDelete()` → `this.title = this.title.slice(0, -1)`

### course-add（名称/教师/教室）

1. 用户点击 input → `onInputFocus('name')` / `onInputFocus('teacher')` / `onInputFocus('classroom')`
2. 键盘输入 → 根据 `currentInputField` 更新对应变量
3. 键盘删除 → 根据 `currentInputField` 删除对应变量最后一个字符

### exam-add（考场）

1. 用户点击 input → `onInputFocus('classroom')`
2. 键盘输入 → `this.classroom += content`
3. 键盘删除 → `this.classroom = this.classroom.slice(0, -1)`

## 五、左滑退出逻辑

```javascript
onBackPress() {
  if (!this.keyboardHidden) {
    this.keyboardHidden = true
    this.currentInputField = ''
    return true
  }
  return false
}
```

- 左滑时关闭键盘
- 清除当前输入字段
- 不改变页面滚动位置

## 六、input 样式修复

```html
<input
  class="input-field"
  type="text"
  value="{{ title }}"
  placeholder="请输入任务名称"
  placeholder-color="#666666"
  color="#FFFFFF"
/>
```

- `color="#FFFFFF"`：输入文字白色
- `placeholder-color="#666666"`：placeholder 灰色
- 背景保持透明
