# 项目修改报告

时间：2026-09-10 14:13

## 一、修改内容

修复添加课程、添加考试、添加待办页面中输入框避让相关逻辑：
1. 键盘弹出后不滚动的问题
2. 关闭键盘后页面回到顶部的问题

## 二、问题原因

### 问题1：键盘弹出后不滚动

**原因**：`_scrollToField()` 在 `showKeyboard()` 中立即执行，此时键盘还未完全展开，页面可视区域未变化，导致输入框判断为"未被遮挡"，不执行滚动。

### 问题2：关闭键盘后页面回到顶部

**原因**：`hideKeyboard()` 和 `onBackPress()` 中直接执行 `scrollTo({ top: 0 })`，将页面强制滚动到顶部。

## 四、实现逻辑

### 1. 键盘显示后触发滚动

**修改前**：
```javascript
showKeyboard(field) {
  this.currentInputField = field
  this.keyboardHidden = false
  this._scrollToField(field) // 立即执行，键盘未展开
}
```

**修改后**：
```javascript
showKeyboard(field) {
  this.currentInputField = field
  // 保存当前滚动位置
  const scrollEl = this.$element('formScroll')
  if (scrollEl) {
    scrollEl.getScrollRect((rect) => {
      this.beforeKeyboardScrollTop = rect.top || 0
    })
  }
  this.keyboardHidden = false
  this._scrollToField(field) // 延迟400ms等待键盘展开
}
```

### 2. 获取真实 scrollTop

使用 `getScrollRect()` 的 `top` 字段获取当前滚动位置：
```javascript
scrollEl.getScrollRect((scrollRect) => {
  const currentScrollTop = scrollRect.top || 0
})
```

### 3. 输入框位置计算

使用 `getBoundingClientRect()` 获取输入框真实位置：
```javascript
inputEl.getBoundingClientRect((inputRect) => {
  const inputBottom = inputRect.bottom
  const keyboardTop = 466 - 321 // 页面高度 - 键盘高度
  const visibleBottom = keyboardTop - 10 // 10px安全间距
  
  if (inputBottom > visibleBottom) {
    // 需要滚动
    const needScroll = inputBottom - visibleBottom + 10
    let scrollTo = currentScrollTop + needScroll
  }
})
```

### 4. 遮挡距离计算

```
遮挡距离 = 输入框底部 - 可见区域底部 + 安全间距
目标滚动 = 当前滚动位置 + 遮挡距离
```

### 5. 关闭键盘恢复位置

**修改前**：
```javascript
hideKeyboard() {
  this.keyboardHidden = true
  setTimeout(() => {
    el.scrollTo({ top: 0, behavior: 'instant' }) // 回到顶部
  }, 100)
}
```

**修改后**：
```javascript
hideKeyboard() {
  this.keyboardHidden = true
  setTimeout(() => {
    el.scrollTo({ top: this.beforeKeyboardScrollTop || 0, behavior: 'instant' }) // 恢复之前位置
  }, 100)
}
```
