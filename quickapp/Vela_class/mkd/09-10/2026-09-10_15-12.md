# 项目修改报告

时间：2026-09-10 15:12

## 一、修改目标

将 task-add 页面从自定义 InputMethod 输入方案改为使用 OpenVela 官方 `<input>` 组件，验证官方组件是否可以替代当前自定义输入方案。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/task-add/task-add.ux` | 替换输入框为官方 `<input>` 组件，删除 InputMethod 相关逻辑 |

## 三、input 替换过程

### 原自定义输入流程

```
点击 div
  ↓
showKeyboard('title')
  ↓
设置 currentInputField = 'title'
  ↓
设置 keyboardHidden = false
  ↓
打开 InputMethod 组件
  ↓
等待键盘显示（400ms 延迟）
  ↓
_scrollToField() 计算滚动位置
  ↓
用户点击键盘按键
  ↓
onComplete() 接收输入内容
  ↓
手动拼接 title += content
  ↓
关闭键盘时 onBackPress() 恢复滚动位置
```

### 新官方 input 流程

```
用户点击 <input> 组件
  ↓
系统自动弹出键盘
  ↓
用户输入文字
  ↓
onTitleChange() 自动接收值
  ↓
this.title = evt.value
  ↓
系统自动处理键盘关闭
```

### 删除的逻辑

1. **InputMethod 组件引用**：移除 `<import name="input-method" ...>`
2. **InputMethod 模板**：移除 `<input-method ...></input-method>`
3. **键盘状态变量**：移除 `keyboardHidden`、`currentInputField`、`currentScrollTop`、`beforeKeyboardScrollTop`
4. **键盘控制函数**：移除 `showKeyboard()`、`_scrollToField()`、`onScroll()`
5. **输入处理函数**：移除 `onComplete()`、`onDelete()`
6. **返回键处理**：简化 `onBackPress()` 不再需要键盘状态判断

### 保留的 UI 样式

```css
.input-wrapper {
  width: 100%;
  height: 52px;
  background-color: #1A1A1A;
  border-radius: 14px;

.input-field {
  width: 100%;
  height: 52px;
  font-size: 17px;
  color: #FFFFFF;
  background-color: transparent;
  border: none;
}
```
