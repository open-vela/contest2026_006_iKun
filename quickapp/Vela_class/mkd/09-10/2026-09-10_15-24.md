# 项目修改报告

时间：2026-09-10 15:24

## 一、修改目标

将 course-add 和 exam-add 页面的文本输入从自定义 InputMethod 改为 OpenVela 官方 `<input>` 组件。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/course-add/course-add.ux` | 替换输入框为官方 `<input>`，删除 InputMethod 相关逻辑 |
| `src/pages/exam-add/exam-add.ux` | 替换输入框为官方 `<input>`，删除 InputMethod 相关逻辑 |

## 三、迁移内容

### course-add.ux

**文本输入字段（替换为 input）：**
- 课程名称：`onNameChange`
- 教师：`onTeacherChange`
- 教室：`onClassroomChange`

**选择类字段（保持不变）：**
- 星期选择：`selectWeekday`
- 开始/结束时间：`onStartTimeChange`、`onEndTimeChange`
- 周次选择：`onStartWeekChange`、`onEndWeekChange`

### exam-add.ux

**文本输入字段（替换为 input）：**
- 考场：`onClassroomChange`

**选择类字段（保持不变）：**
- 考试课程：`onCourseChange`
- 考试日期：`onDateChange`
- 开始/结束时间：`onStartTimeChange`、`onEndTimeChange`

## 四、删除逻辑

### 删除的函数

| 函数 | 用途 |
|------|------|
| `showKeyboard()` | 打开自定义输入法 |
| `hideKeyboard()` | 关闭自定义输入法 |
| `_scrollToField()` | 键盘避让滚动计算 |
| `onComplete()` | 接收输入法输入内容 |
| `onDelete()` | 处理输入法删除 |
| `onScroll()` | 记录滚动位置（仅输入法使用） |

### 删除的变量

| 变量 | 用途 |
|------|------|
| `keyboardHidden` | 输入法显示状态 |
| `currentInputField` | 当前输入字段 |
| `currentScrollTop` | 当前滚动位置 |
| `beforeKeyboardScrollTop` | 键盘打开前滚动位置 |

### 删除的引用

- `<import name="input-method" src="../../components/InputMethod/InputMethod.ux">`
- `<input-method ...></input-method>` 组件
