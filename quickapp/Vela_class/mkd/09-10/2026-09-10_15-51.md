# 项目修改报告

时间：2026-09-10 15:51

## 一、问题原因

1. **系统键盘和 InputMethod 同时出现**：`<input>` 组件默认会触发系统键盘，导致两个输入源同时存在

2. **InputMethod 输入无法同步到 input**：虽然变量更新了，但系统键盘也在输入，造成冲突

3. **input 文字颜色黑色**：CSS 中设置了 `color: #FFFFFF`，但需要使用官方 input 的 `color` 属性

## 二、修改方案

使用 `readonly="true"` 属性阻止系统键盘弹出，让 InputMethod 成为唯一输入来源：

```
用户点击 input-wrapper
    ↓
@click="onInputFocus('field')"
    ↓
记录 currentInputField
    ↓
打开 InputMethod
    ↓
用户点击扩展键盘按键
    ↓
InputMethod 发送 @complete 事件
    ↓
onKeyboardInput(evt) 更新变量
    ↓
<input value="{{变量}}"> 显示最新内容
```

**职责划分**：
- `<input>`：显示组件，负责显示 value、页面布局
- `InputMethod`：输入来源，负责键盘 UI、按键输入、删除

## 四、输入流程

### task-add

```
点击 input-wrapper → onInputFocus('title') → 打开 InputMethod
    ↓
键盘按键 → onKeyboardInput(evt) → this.title += content
    ↓
删除 → onKeyboardDelete() → this.title = this.title.slice(0, -1)
    ↓
左滑退出 → onBackPress() → 关闭键盘
```

### course-add

```
点击 input-wrapper → onInputFocus('name'/'teacher'/'classroom')
    ↓
键盘按键 → onKeyboardInput(evt) → 根据 currentInputField 更新对应变量
    ↓
删除 → onKeyboardDelete() → 根据 currentInputField 删除对应变量
```

### exam-add

```
点击 input-wrapper → onInputFocus('classroom')
    ↓
键盘按键 → onKeyboardInput(evt) → this.classroom += content
    ↓
删除 → onKeyboardDelete() → this.classroom = this.classroom.slice(0, -1)
```
