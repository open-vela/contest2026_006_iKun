## 二、发现的问题

### 问题1：scrollTop 获取错误

**原因**：原代码使用 `scrollRect.top` 作为 `currentScrollTop`，但 OpenVela 的 `getScrollRect().top` 返回的是元素的绝对位置，不是当前滚动距离。

### 问题2：course-add.ux 的 onBackPress 未修复

**原因**：`onBackPress()` 中仍然使用 `scrollTo({ top: 0 })`，没有使用 `beforeKeyboardScrollTop`。

### 问题3：InputMethod 有 visibilityChange 事件

**发现**：InputMethod 组件在 `watchHidePropsChange` 中会触发 `visibilityChange` 事件，可用于监听键盘显示/隐藏状态。

## 四、修改逻辑

### 1. scrollTop 如何获取

**修改前**：
```javascript
scrollEl.getScrollRect((scrollRect) => {
  const currentScrollTop = scrollRect.top || 0  // 错误：这是元素位置，不是滚动距离
})
```

**修改后**：
```javascript
// 添加 onscroll 事件监听
<scroll id="formScroll" onscroll="onScroll">

// 通过事件记录真实滚动位置
onScroll(event) {
  this.currentScrollTop = event.scrollTop || 0
}
```

### 2. 键盘状态如何同步

**当前方案**：
- 使用 400ms 延迟等待键盘展开
- InputMethod 组件有 `visibilityChange` 事件，但当前未利用

**限制**：
- 键盘高度 321px 是固定值（来自 InputMethod.ux 的圆屏设计）
- 无法动态获取键盘高度

### 3. 输入框遮挡如何计算

```javascript
// 获取输入框真实位置
inputEl.getBoundingClientRect((inputRect) => {
  const inputBottom = inputRect.bottom
  
  // 键盘弹出后可见区域底部
  const keyboardTop = 466 - 321  // 页面高度 - 键盘高度
  const visibleBottom = keyboardTop - 10  // 10px 安全间距
  
  // 判断是否被遮挡
  if (inputBottom > visibleBottom) {
    const needScroll = inputBottom - visibleBottom + 10
    let scrollTo = this.currentScrollTop + needScroll
    
    // 限制在合法范围
    scrollEl.getScrollRect((scrollRect) => {
      const maxScroll = scrollRect.scrollHeight - scrollRect.height
      if (scrollTo > maxScroll) scrollTo = maxScroll
      scrollEl.scrollTo({ top: scrollTo })
    })
  }
})
```

### 4. 关闭键盘如何恢复

```javascript
showKeyboard(field) {
  this.beforeKeyboardScrollTop = this.currentScrollTop  // 保存当前位置
  // ...
}

hideKeyboard() {
  this.keyboardHidden = true
  setTimeout(() => {
    el.scrollTo({ top: this.beforeKeyboardScrollTop })  // 恢复之前位置
  }, 100)
}

onBackPress() {
  if (!this.keyboardHidden) {
    this.keyboardHidden = true
    setTimeout(() => {
      el.scrollTo({ top: this.beforeKeyboardScrollTop })  // 恢复之前位置
    }, 100)
    return true
  }
  return false
}
```
