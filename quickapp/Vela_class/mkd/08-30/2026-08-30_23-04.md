# 项目修改报告

时间：2026-08-30 23:04

## 一、修改内容

优化"本周"模式在学期未开始时的默认显示逻辑，并统一教学周日期计算。

### 核心改动

1. **学期未开始时，"本周"模式默认显示第1周**
2. **教学周日期计算改为根据 semesterWeek1Start 直接计算**
3. **左箭头限制：第1周时不能再往左**

## 二、问题原因

### 2.1 原始代码问题

**问题1：selectedWeek 初始化错误**
```javascript
// 原代码（第582行）
this.selectedWeek = this.currentWeek
```
当 `currentWeek = 0`（学期未开始）时，`selectedWeek = 0`，导致"本周"模式显示"学期未开始"。

**问题2：日期计算依赖当前自然周**
```javascript
// 原代码（第611-637行）
updateWeekDates(now) {
  const currentWeekday = getWeekdayNumber(now)
  const mondayOffset = currentWeekday - 1
  const monday = new Date(now)
  monday.setDate(monday.getDate() - mondayOffset)

  // 根据 selectedWeek 与 currentWeek 的差值计算目标周的星期一
  const weekOffset = this.selectedWeek - this.currentWeek
  const targetMonday = new Date(monday)
  targetMonday.setDate(targetMonday.getDate() + weekOffset * 7)
  // ...
}
```

当 `currentWeek = 0` 且 `selectedWeek = 1` 时，`weekOffset = 1`，会计算出错误的日期。

**例如**：
- 当前日期：2026-08-30
- 第一周：2026-09-14～9月20日
- 原计算：当前自然周（8月24日）+ 1周 = 8月31日（错误）
- 正确：应该是9月14日

**问题3：左箭头无限制**
```javascript
// 原代码（第696行）
if (this.selectedWeek > 1) {
  this.selectedWeek -= 1
}
```
原模板中禁用条件是 `selectedWeek <= 0`，允许进入第0周。

## 四、实现逻辑

### 4.1 selectedWeek 初始化

```javascript
// 修改后
this.currentWeek = calculateCurrentWeek(now)
// 学期未开始时，默认显示第1周
this.selectedWeek = this.currentWeek > 0 ? this.currentWeek : 1
```

**逻辑**：
- `currentWeek > 0`：学期已开始，`selectedWeek = currentWeek`
- `currentWeek === 0`：学期未开始，`selectedWeek = 1`

### 4.2 updateWeekDates 函数

```javascript
// 修改后
updateWeekDates(now) {
  const semesterStart = getSemesterWeek1Start()
  let targetMonday

  if (semesterStart && this.selectedWeek > 0) {
    // 根据学期第一周直接计算目标教学周的周一
    // 第1周：semesterWeek1Start
    // 第N周：semesterWeek1Start + (N-1) * 7天
    const week1Monday = new Date(semesterStart + 'T00:00:00')
    targetMonday = new Date(week1Monday)
    targetMonday.setDate(targetMonday.getDate() + (this.selectedWeek - 1) * 7)
  } else {
    // 未设置学期第一周时，使用当前自然周作为备选
    const currentWeekday = getWeekdayNumber(now)
    const mondayOffset = currentWeekday - 1
    const monday = new Date(now)
    monday.setDate(monday.getDate() - mondayOffset)
    targetMonday = monday
  }

  // 更新 weekDays 的日期和月份
  this.weekDays.forEach((d, index) => {
    const date = new Date(targetMonday)
    date.setDate(date.getDate() + index)
    d.date = date.getDate()
    d.month = date.getMonth() + 1
    // 只有查看当前周时才标记今天
    d.isToday = (this.selectedWeek === this.currentWeek) && (d.value === this.selectedDay)
  })

  // 根据 selectedDay 更新 displayMonth
  const selectedDayItem = this.weekDays.find(d => d.value === this.selectedDay)
  if (selectedDayItem) {
    this.displayMonth = selectedDayItem.month
  }
}
```

## 五、教学周日期计算

### 5.1 原计算方式（错误）

```
目标教学周周一 = 当前自然周周一 + (selectedWeek - currentWeek) × 7天
```

**问题**：
- 依赖 `currentWeek`，当 `currentWeek = 0` 时计算错误
- 当第一周距离当前日期较远时，计算结果偏差更大

### 5.2 新计算方式（正确）

```
目标教学周周一 = semesterWeek1Start + (selectedWeek - 1) × 7天
```

**优势**：
- 直接根据学期第一周计算，不依赖当前日期
- 无论第一周距离当前日期多远，都能正确计算

### 5.3 计算示例

**场景**：
- 当前日期：2026-08-30
- 学期第一周：2026-09-14～9月20日（semesterWeek1Start = '2026-09-14'）

| selectedWeek | 计算过程 | 结果 |
|--------------|----------|------|
| 1 | 2026-09-14 + 0天 | 9月14日～9月20日 |
| 2 | 2026-09-14 + 7天 | 9月21日～9月27日 |
| 3 | 2026-09-14 + 14天 | 9月28日～10月4日 |
