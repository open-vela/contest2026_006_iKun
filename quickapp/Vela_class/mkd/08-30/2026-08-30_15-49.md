# 项目修改报告

时间：2026-08-30 15:49

## 一、修改内容

修复课表页面设置入口图标显示错误的问题。

## 二、问题原因

原来使用 Unicode 字符 `⚙`（齿轮符号）作为设置图标，在 OpenVela 手表模拟器上显示为方框/设备图标，存在字体兼容性问题。

## 三、修改文件

- `src/pages/schedule/schedule.ux`
- `src/common/icons/settings.png`（新增）

## 四、实现逻辑

### 1. 创建本地图标文件
使用 Python 生成一个简单的 24x24 齿轮形状 PNG 图标：
- 灰色齿轮形状
- 透明背景
- 保存为 `src/common/icons/settings.png`

### 2. 修改模板
将原来的 Unicode 字符：
```html
<text class="settings-text">⚙</text>
```

改为图片组件：
```html
<image class="settings-icon" src="../../common/icons/settings.png"></image>
```

### 3. 修改样式
将 `.settings-text` 改为 `.settings-icon`：
```css
.settings-icon {
  width: 24px;
  height: 24px;
}
```

## 五、测试验证

### 测试步骤：
1. 打开课表页面
2. 确认右上角显示齿轮图标（不是方框）
3. 点击齿轮图标，确认可以进入课表设置页面
4. 返回课表，确认功能正常

## 六、后续建议

1. 如果需要更精美的图标，可以使用设计工具创建
2. 可以考虑将图标放到统一的图标目录管理
