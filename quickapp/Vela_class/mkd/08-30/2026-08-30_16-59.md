# 项目修改报告

时间：2026-08-30 16:59

## 一、修改内容

修复课表"学期未开始"无法进入第1周，以及修改第一周后返回课表不立即刷新的问题。

## 二、问题原因

### 问题1：学期未开始时无法切换到第1周
`nextWeek()` 函数中有 `this.selectedWeek > 0` 的判断，导致 `selectedWeek = 0`（学期未开始）时无法执行。

### 问题2：保存第一周后返回课表不刷新
`onShow()` 只调用了 `refreshCoursesFromStorage()`，没有刷新学期第一周设置。

## 三、修改文件

- `src/pages/schedule/schedule.ux`
- `src/common/storage.js`

### 1. 修复 nextWeek 函数

### 2. 修复左箭头禁用条件

```html
<!-- 修改后 -->

```

### 3. 添加 refreshSemesterStartFromStorage 函数
在 storage.js 中新增从 Storage 重新读取学期第一周设置的函数。

### 4. 修改 onShow 函数
同时刷新课程数据和学期设置：
```javascript
onShow() {
  ensureStorageReady()
    .then(() => Promise.all([
      refreshCoursesFromStorage(),
      refreshSemesterStartFromStorage()
    ]))
    .then(() => {
      this.currentWeek = calculateCurrentWeek(now)
      this.selectedWeek = this.currentWeek
      // ...
    })
}
```
