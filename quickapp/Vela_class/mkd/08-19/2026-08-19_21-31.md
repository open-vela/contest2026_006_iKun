## 2. 首页待办数量修改

### 原来为什么只显示今日数量
`getTaskSummary()` 只返回 `todayCount`（今天未完成数量）和 `urgentCount`（紧急数量），首页使用 `taskSummary.todayCount` 显示待办数量。

### 新增的 totalCount
在 `getTaskSummary()` 返回值中增加 `totalCount`，表示所有 `finished === false` 的任务数量。

### totalCount 的定义
```js
const allTasks = getTasks().filter(t => !t.finished)
// totalCount = allTasks.length
```

### 首页最终使用哪个字段
首页模板从 `taskSummary.todayCount` 改为 `taskSummary.totalCount`。

### 保留 todayCount
`todayCount` 继续保留在返回值中，以后其他地方如果需要仍然可以使用。

## 3. 考试页面为空原因

### examCache 与 Storage 初始化时序
`initStorage()` 是异步执行的，但考试页 `onInit` 直接调用 `loadExams()`，此时 `examCache` 仍为空数组。

### 原 exam.ux 为什么可能读取空数据
`getNearestExam()` 和 `getUpcomingExams()` 最终读取 `storage.js` 中的 `examCache`，应用刚启动时缓存为空，导致考试页读取不到数据。

## 4. 考试 Storage 初始化修复

### ensureStorageReady 接入
- 导入 `ensureStorageReady` from `../../common/storage`
- 复用现有的公共实现，不重新实现 Storage 初始化

### onInit 处理
```js
onInit() {
  ensureStorageReady().then(() => {
    this.loadExams()
  }).catch((err) => {
    console.error('Failed to initialize storage on exam:', err)
  })
}
```

### onShow 处理
增加 `onShow()` 生命周期，返回考试页时重新读取最新缓存：
```js
onShow() {
  ensureStorageReady().then(() => {
    this.loadExams()
  }).catch((err) => {
    console.error('Failed to refresh exams:', err)
  })
}
```

### loadExams 数据重置
在 `loadExams()` 开始处重置页面数据，避免旧状态残留：
```js
this.nearestExam = null
this.countdown = { value: 0, unit: '' }
this.examDate = ''
this.upcomingExams = []
```
