## 2. 首页摘要为空原因

### Storage 初始化时序
`initStorage()` 是异步执行的，但首页 `onInit` 直接调用 `updateStatus()`，此时 `taskCache` 和 `examCache` 仍为空数组。

### 首页为何读取到空 cache
`getExamSummary()` 和 `getTaskSummary()` 最终依赖 `storage.js` 中的 `examCache` 和 `taskCache`，应用刚启动时这两个缓存为空，导致首页读取到 0 场考试、0 项待办。

## 3. ensureStorageReady 接入

### home 如何等待 Storage ready
- 导入 `ensureStorageReady` from `../../common/storage`
- 在 `onInit` 中等待 `ensureStorageReady()` 完成后再调用 `updateStatus()`
- 定时器也在 Storage ready 后才启动

### 是否复用现有公共实现
是，直接复用 `storage.js` 中已有的 `ensureStorageReady()`，不重新实现 Storage 初始化逻辑。

## 4. onShow 刷新逻辑

### 首页重新显示时如何刷新
- 增加 `onShow()` 生命周期
- 在 `onShow` 中调用 `ensureStorageReady().then(() => { this.updateStatus() })`
- 从待办页或考试页返回首页时自动刷新摘要数据

### 待办或考试修改后如何同步摘要
- 用户在待办页标记完成/取消完成后返回首页
- `onShow` 触发，重新读取最新 `taskCache` 和 `examCache`
- 摘要数字立即更新

## 5. 定时器处理

### timer 是否只创建一次
是，在 `onInit` 中 Storage ready 后创建一次定时器，保存到 `this.timer`

### 是否增加清理逻辑
是，增加 `onDestroy()` 生命周期，在页面销毁时清除定时器：
```js
onDestroy() {
  if (this.timer) {
    clearInterval(this.timer)
    this.timer = null
  }
}
```

### onShow 不会重复创建定时器
`onShow` 只调用 `updateTime()` 和 `updateStatus()`，不创建新的定时器。
