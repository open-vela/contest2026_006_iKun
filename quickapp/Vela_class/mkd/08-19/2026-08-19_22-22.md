## 2. Scroll 布局异常原因

### 原来的 scroll-content 结构
```html
<scroll class="task-scroll" scroll-y="true" bounces="true">
  <div class="scroll-content">
    <!-- 所有 section -->
    <div class="bottom-safe-space"></div>
  </div>
</scroll>
```
`scroll-content` 包装层导致内部元素被 Flex 压缩。

### 为什么任务元素发生 Flex 压缩
`scroll-content` 设置了固定宽度 380px，但没有设置 `flex-shrink: 0`，导致其子元素（section、task-list、task-item）被 Flex 布局压缩以适应 scroll 的 375px 高度视口。

### 哪些元素发生 shrink
- `.section`：被压缩
- `.task-list`：被压缩
- `.task-item`：被压缩
- `.bottom-safe-space`：被压缩

## 3. Scroll 结构修复

### 是否删除 scroll-content
是，删除了 `<div class="scroll-content">` 这一层包装，同时删除了 `.scroll-content` 样式。

### section 是否改为 scroll 直接子元素
是，所有 section 直接成为 `<scroll class="task-scroll">` 的子组件。

### task-scroll 是否设置纵向排列
是，添加了 `flex-direction: column` 和 `align-items: center`。

## 4. 防压缩处理

### 实际设置的 flex-shrink / min-height
- `.section`：`flex-shrink: 0`
- `.section-title`：`flex-shrink: 0`
- `.task-list`：`flex-shrink: 0`
- `.task-item`：`flex-shrink: 0` + `min-height: 64px`
- `.task-check`：`flex-shrink: 0`
- `.empty`：`flex-shrink: 0`
- `.bottom-safe-space`：`flex-shrink: 0`

## 5. 底部安全区域

### 最终 bottom-safe-space 高度
```css
.bottom-safe-space {
  width: 380px;
  height: 90px;
  flex-shrink: 0;
}
```
从 80px 调整为 90px，因为圆形屏幕底部裁切区域较大。
