# 课程/考试/待办截止主动提醒功能规范化报告

时间：2026-09-15 23:48

## 一、修改内容

在 `src/pages/home/home.ux` 中规范化应用内提醒功能，保持课程/考试/待办三类提醒行为不变，修复考试提醒边界问题。

### 官方 API 核实结果

| API | 官方文档确认 |
|-----|-------------|
| `vibrator.vibrate({ mode })` | `mode` 为 String 类型，合法值 `"long"`（长振动）和 `"short"`（短振动），默认 `"long"` |
| `prompt.showToast({ message, duration })` | `message` 必填（String），`duration` 可选（Number，单位 ms，默认 1500，建议区间 1500-10000） |

现有代码中 `vibrator.vibrate({ mode: 'short' })` 和 `prompt.showToast({ message, duration: 3000 })` 均符合官方规范，无需修正。

`manifest.json` 已声明 `system.vibrator` 和 `system.prompt`，无需改动。

## 二、问题原因

### 原实现存在的问题

1. **考试提醒 bug**：使用 `getNearestExam(now)` 获取最近考试，但该函数优先返回「进行中」的考试。若有一场考试正在进行，`examStart < now`，`diffMinutes(now, examStart)` 为负数，永远不会触发提醒，且会遮挡下一场尚未开始考试的提醒。

2. **分钟取整问题**：使用 `diffMinutes`（`Math.floor`）取整，当距离开始不足 1 分钟时（如 30 秒），`diff = 0` 不满足 `diff > 0` 条件，会漏掉提醒。考虑到检查间隔为 30 秒，采用 `Math.ceil` 向上取整更合理。

3. **未使用的 import**：`diffMinutes` 导入后不再使用（改为内联 `Math.ceil` 计算）。

## 四、实现逻辑

### 1. 提醒状态字段（private 中保留）

```javascript
reminderTimer: null,    // 提醒检查定时器（30秒一次）
reminderDone: {}        // 已提醒集合（防重复触发）
```

### 2. 定时器管理

- `startTimers()` 中创建 `reminderTimer`（30 秒一次）调用 `checkReminders()`
- `clearTimers()` 中清理 `reminderTimer`
- 不改动 `timeTimer` / `courseTimer` / `examTimer`

### 3. checkReminders() 三类判断

**课程提醒**：
- 取 `getNextCourse(now)`
- 用 `Math.ceil((startTime - now) / 60000)` 计算分钟差（向上取整）
- `0 < diff <= 10` 且未提醒过 → 触发
- key 含日期 `${course.id}_YYYY-MM-DD`（避免跨天误判）

**考试提醒**（已修复）：
- 取 `getUpcomingExams(now)` 获取所有未结束考试
- 用 `.find()` 筛选第一场「开始时间 > now」的考试（排除进行中的考试）
- 用 `Math.ceil((examStart - now) / 60000)` 计算分钟差
- `0 < diff <= 60` 且未提醒过 → 触发
- key 用 `${exam.id}`

**待办截止提醒**：
- 遍历 `getTasks()` 中未完成项
- 筛选出未来且 `diff <= 60` 分钟的最近一项
- 用 `Math.ceil((deadline - now) / 60000)` 计算分钟差
- `0 < diff <= 60` 且未提醒过 → 触发
- key 用 `${task.id}`

### 4. 触发函数

```javascript
triggerReminder(message, mode) {
  vibrator.vibrate({ mode: mode || 'short' })
  prompt.showToast({ message: message, duration: 3000 })
}
```

- 课程提醒：短振动 `'short'`
- 考试提醒：长振动 `'long'`
- 待办提醒：长振动 `'long'`
- `duration: 3000` 在官方建议区间 1500-10000 内

### 5. 文案格式

- 课程：「《课程名》X分钟后开始」
- 考试：「《考试课程》考试X分钟后开始」
- 待办：「《待办标题》X分钟后截止」

### 注意事项

- Mock 考试/待办日期已过期，需手动添加新数据测试
- 课程提醒依赖当天课表，需确保当前教学周有对应课程
- 提醒状态用页面内内存字段，页面销毁后（退出首页再进入）会重新初始化
- 检查间隔 30 秒，使用 `Math.ceil` 向上取整，确保不会漏掉「开始前 <1 分钟」的提醒

## 六、后续建议

1. **持久化提醒状态**：当前 `reminderDone` 是内存字段，页面销毁后重置，可考虑用 Storage 持久化
2. **提醒阈值可配置**：将 10 分钟、60 分钟等阈值改为可配置项
3. **多提醒支持**：当前只取最近一项提醒，可支持多条提醒同时触发
4. **振动模式优化**：可针对不同提醒类型使用 `vibrator.start()` 实现自定义振动模式
5. **通知栏提醒**：配合系统通知实现后台提醒（需系统支持）
