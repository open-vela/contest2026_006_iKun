# 课程/考试/待办截止主动提醒功能报告

时间：2026-09-15 01:16

## 一、修改内容

新增三类主动提醒（振动 + 弹窗）：
1. **课程开始提醒**：距下一节课开始 0 < diff ≤ 10 分钟时，振动一次 + 弹窗提示
2. **考试开始提醒**：距最近考试开始 0 < diff ≤ 60 分钟时，振动 + 提示
3. **待办截止提醒**：距最近未完成待办截止 0 < diff ≤ 60 分钟时，振动 + 提示

每条提醒在其时间窗口内只触发一次，避免定时器反复弹窗。

## 二、问题原因

之前首页只实现倒计时展示逻辑，未在到达提醒时间窗口时主动触发振动与弹窗，用户需要自己点开查看详情。

## 四、实现逻辑

### 1. 新增状态字段

```javascript
private: {
  reminderTimer: null,    // 提醒检查定时器
  reminderDone: {}        // 已提醒集合（防重复）
}
```

### 2. 定时器管理

在 `startTimers()` 中新增 `reminderTimer`（30秒一次）调用 `checkReminders()`：
```javascript
this.reminderTimer = setInterval(() => {
  this.checkReminders()
}, 30000)
```

在 `clearTimers()` 中同步清理 `reminderTimer`。

### 3. checkReminders() 逻辑

**课程提醒**：
- 取 `getNextCourse(now)`
- 计算距开始分钟数 `diff`
- 若 `0 < diff <= 10` 且未提醒过该课程 → 触发提醒
- key 为 `${course.id}_${YYYY-MM-DD}`（避免跨天误判）

**考试提醒**：
- 取 `getNearestExam(now)`
- 计算距开始分钟数 `diff`
- 若 `0 < diff <= 60` 且未提醒过 → 触发提醒
- key 为 `${exam.id}`

**待办截止提醒**：
- 遍历 `getTasks()` 中未完成项
- 取其中未来且 ≤ 60 分钟的最近一项
- 若 `0 < diff <= 60` 且未提醒过 → 触发提醒
- key 为 `${task.id}`

### 4. 触发方式

```javascript
triggerReminder(message, mode) {
  vibrator.vibrate({ mode: mode || 'short' })
  prompt.showToast({ message: message, duration: 3000 })
}
```

- 课程提醒：短振动 'short'
- 考试提醒：长振动 'long'
- 待办提醒：长振动 'long'

### 5. 文案格式

- 课程：「《课程名》X分钟后开始」
- 考试：「《考试课程》考试X分钟后开始」
- 待办：「《待办标题》X分钟后截止」

## 五、测试验证

### 自查要点

1. ✅ 定时器创建与销毁配对（`reminderTimer` 在 `clearTimers()` 中清理）
2. ✅ 防重复提醒（`reminderDone` 对象记录已提醒 key）
3. ✅ 分钟差边界（`diff > 0 && diff <= 阈值`，≤0 不触发）
4. ✅ 官方组件（`@system.vibrator` 和 `@system.prompt` 已在 manifest.json 声明）

### 测试步骤

**课程提醒测试**：
1. 查看今天课表，找一门今天还未开始的课程
2. 在该课程开始前 10 分钟内进入首页
3. 应收到振动 + 弹窗提醒

**考试提醒测试**：
1. 添加一场未来 60 分钟内开始的考试（exam-add 页面）
2. 返回首页
3. 应收到振动 + 弹窗提醒

**待办提醒测试**：
1. 添加一个截止时间为未来 60 分钟内的待办（task-add 页面）
2. 返回首页
3. 应收到振动 + 弹窗提醒

### 注意事项

- Mock 考试/待办日期可能已过期，需手动添加新数据测试
- 课程提醒依赖当天课表，需确保当前教学周有对应课程
- 提醒状态用页面内内存字段，页面销毁后重新初始化

## 六、后续建议

1. **持久化提醒状态**：当前 `reminderDone` 是内存字段，页面销毁后会重置，可考虑用 Storage 持久化
2. **提醒阈值可配置**：将 10 分钟、60 分钟等阈值改为可配置项
3. **多提醒支持**：当前只取最近一项提醒，可支持多条提醒同时触发
4. **振动模式优化**：可针对不同提醒类型使用不同振动模式
5. **通知栏提醒**：配合系统通知实现后台提醒（需系统支持）
