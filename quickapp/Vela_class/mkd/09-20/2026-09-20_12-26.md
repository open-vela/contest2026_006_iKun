# AI 简报显示控制从 if 改为 show 报告

时间：2026-09-20 12:26

## 1. 修改概述

将简报区域显示控制从 if 改为 show，解决动态插入 VDOM 节点不渲染的问题。

## 2. 修改文件

仅修改 `src/pages/home/home.ux` 第58行

## 3. 修改前问题

`if="{{ hasBrief }}"` 从 false 变 true 时动态插入节点不触发渲染。

## 4. 修改后逻辑

`show="{{ hasBrief }}"` 节点始终在 VDOM 中，仅控制可见性：
- show 为 true 时节点可见
- show 为 false 时节点不可见，但节点仍保留在页面 DOM 结构中

## 5. 测试步骤

1. 启动模拟器，首页应显示 AI 简报淡蓝色文字
2. 简报内容应如"第1周 · 周日；今日无课；最近考试《操作系统》还有6天；待办7项。"
3. 删除考试后返回首页，简报应更新且正常显示
4. 若无任何数据，简报区域应隐藏（show=false），不占布局空间

## 6. 风险评估

show 与 if 的区别仅在于节点是否保留在 DOM 中，show=false 时不占布局空间，行为等价且更可靠。
