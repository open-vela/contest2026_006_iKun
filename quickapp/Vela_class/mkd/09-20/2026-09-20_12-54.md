# AI 简报去掉 show 条件报告

时间：2026-09-20 12:54

## 1. 修改概述

去掉简报区域 show 条件，改为与其他卡片一致的始终渲染方式。

## 2. 修改文件

仅修改 `src/pages/home/home.ux`：
- 模板：去掉 show 条件
- private：删除 hasBrief
- updateDailyBrief：删除 hasBrief 赋值

## 3. 修改前问题

`show="{{ hasBrief }}"` 依赖异步回调设置的 boolean 变量，重新评估不可靠导致不显示。

## 4. 修改后逻辑

brief-card 始终渲染，仅 dailyBrief 字符串绑定：
```html
<div class="brief-card">
  <text class="brief-text">{{ dailyBrief }}</text>
</div>
```

## 5. 测试步骤

1. 启动模拟器，首页主卡片下方应显示 AI 简报淡蓝色文字
2. 简报内容应如"第1周 · 周日；今日无课；最近考试《操作系统》还有6天；待办7项。"
3. 删除考试后返回首页，简报应更新且正常显示
4. 空状态时简报区域不显示文字（容器保留少量空白）

## 6. 风险评估

empty 状态时 brief-card 保留约16px padding 空白，不影响功能；与其他卡片渲染方式一致，最可靠。
