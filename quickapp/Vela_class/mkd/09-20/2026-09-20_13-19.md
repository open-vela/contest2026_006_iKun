# AI 简报改为模板方法调用报告

时间：2026-09-20 13:19

## 1. 修改概述

推翻旧的手动赋值方式，改用模板方法调用重新实现简报并清理旧代码。

## 2. 修改文件

仅修改 `src/pages/home/home.ux`：
- 清理旧代码（dailyBrief、updateDailyBrief、onInit/onShow 中的调用）
- 新增 getDailyBrief 方法
- 模板改为方法调用

## 3. 修改前问题

手动赋值 dailyBrief 在异步回调中不触发视图更新，if/show 条件渲染不可靠。

## 4. 修改后逻辑

```javascript
getDailyBrief() {
  return generateDailyBrief(getNow())
}
```

模板：`{{ getDailyBrief() }}`，每次重新渲染时自动执行。

## 5. 测试步骤

1. 启动模拟器，首页主卡片下方应显示 AI 简报淡蓝色文字
2. 简报内容应如"第1周 · 周日；今日无课；最近考试《大学英语》还有N小时；待办7项，N项已逾期请优先处理。"
3. 删除考试后返回首页，简报应更新
4. 无任何数据时，简报应显示"今天比较轻松：无课、无考试、无待办。"

## 6. 风险评估

模板方法每次重新渲染执行，generateDailyBrief 是轻量纯本地拼接，无性能风险；brief.js 不动，无其他副作用。
