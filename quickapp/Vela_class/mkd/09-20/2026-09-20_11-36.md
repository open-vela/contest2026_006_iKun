# AI 简报不显示修复报告

时间：2026-09-20 11:36

## 1. 修改概述

按快应用官方条件渲染规范，用 boolean 变量控制 if 指令，修复 AI 简报不显示问题。

## 2. 修改文件

仅修改 `src/pages/home/home.ux`：
- private：新增 `hasBrief: false`
- updateDailyBrief：添加 `this.hasBrief = this.dailyBrief !== ''`
- 模板：`if="{{ dailyBrief }}"` 改为 `if="{{ hasBrief }}"`

## 3. 修改前问题

`if="{{ dailyBrief }}"` 用字符串变量做条件，不符合快应用官方 boolean 变量用法，导致组件不渲染。

## 4. 修改后逻辑

```javascript
private: {
  dailyBrief: '',
  hasBrief: false,  // boolean 类型
},

updateDailyBrief() {
  const now = getNow()
  this.dailyBrief = generateDailyBrief(now)
  this.hasBrief = this.dailyBrief !== ''
}
```

模板：`<div if="{{ hasBrief }}" class="brief-card">`

## 5. 测试步骤

1. 启动模拟器，首页应显示 AI 简报淡蓝色文字
2. 简报内容应如"第1周 · 周日；今日无课；最近考试《操作系统》还有6天；待办7项。"
3. 删除考试后返回首页，简报应更新且正常显示
4. 若无任何数据，简报应显示"今天比较轻松：无课、无考试、无待办。"

## 6. 风险评估

仅改条件判断方式，简报生成逻辑不变，无风险。
