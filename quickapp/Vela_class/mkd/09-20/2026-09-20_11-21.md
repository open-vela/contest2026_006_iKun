# 首页 AI 简报功能报告

时间：2026-09-20 11:21

## 1. 修改概述

新增首页 AI 简报功能，根据本地课表、考试、待办数据自动生成 1～3 句中文总结。

## 2. 修改文件

| 文件 | 类型 | 修改内容 |
|------|------|----------|
| `src/common/brief.js` | 新建 | 导出 `generateDailyBrief(now)` 函数 |
| `src/pages/home/home.ux` | 修改 | 模板、样式、import、private、updateDailyBrief、onInit/onShow 调用 |

## 3. 修改前问题

首页无简报功能，用户需翻多个页面了解今日概况。

## 4. 修改后逻辑

### brief.js

纯同步函数，拼句规则：
1. 开头：`第 X 周 · 周Y` 或 `学期未开始`
2. 课程：`今天 N 节课` + 正在上/下一节信息；或 `今日无课`
3. 考试：进行中/今天/倒计时
4. 待办：`待办 N 项` + 逾期/今日截止信息
5. 空状态：`今天比较轻松：无课、无考试、无待办。`

### home.ux

- 模板：main-card 和 summary-row 之间插入 brief-card
- 样式：淡蓝色文字（#8AB4F8），13px，main-card margin-bottom 缩减为 8px
- 脚本：updateDailyBrief() 在 onInit 和 onShow 的 then/catch 中调用

## 5. 测试步骤

1. **信息齐全**：显示「第 X 周 · 周Y；今天 N 节课，下一节 课名 时间；最近考试《课名》还有 N 天；待办 N 项。」
2. **今日无课**：简报应包含「今日无课」
3. **有逾期待办**：简报应包含「已逾期请优先处理」
4. **空状态**：显示「今天比较轻松：无课、无考试、无待办。」
5. **刷新**：删除考试后返回首页，简报应立即更新
6. **布局**：简报区域不与 main-card 或 summary-row 重叠

## 6. 风险评估

| 场景 | 风险 | 说明 |
|------|------|------|
| 性能 | 无 | 纯本地同步逻辑 |
| 布局 | 无 | 已评估空间可容纳 |
| 数据结构 | 无 | 不涉及数据结构变更 |
