# 项目修改报告

时间：2026-08-31 17:39

## 一、修改内容

优化首页定时刷新逻辑，减少每秒重复计算考试、待办和课程状态。

### 核心改动

1. **拆分定时器**：将1秒定时器拆分为两个定时器
   - `timeTimer`：每1秒更新时间
   - `courseTimer`：每30秒更新课程状态
2. **拆分更新函数**：将 `updateStatus()` 拆分为三个函数
   - `updateTime()`：时间更新
   - `updateCourseStatus()`：课程状态更新（30秒）
   - `updateStaticSummary()`：考试和待办摘要（仅 onShow）
3. **正确管理定时器生命周期**：在 onHide 和 onDestroy 时清理定时器

## 二、问题原因

### 2.1 原始代码问题

**问题1：1秒定时器执行完整 updateStatus()**

```javascript
// 原代码（第354-360行）
this.timer = setInterval(() => {
  this.updateTime()
  this.updateStatus()  // 包含所有计算
}, 1000)
```

**问题2：updateStatus() 包含所有计算**

```javascript
updateStatus() {
  // 课程相关
  getCurrentCourse(now)
  getNextCourse(now)
  getNextCourseAcrossDays(now)
  isTodayCoursesFinished(now)
  getTodayCourses(now)
  
  // 考试相关（不需要每秒刷新）
  getNearestExam(now)
  getExamSummary(now)
  
  // 待办相关（不需要每秒刷新）
  getTaskSummary(now)
}
```

**问题3：定时器生命周期管理不完整**

- 原代码只在 `onDestroy()` 时清理定时器
- 页面隐藏时定时器继续运行

## 六、定时器生命周期

### 6.1 生命周期管理

```javascript
// 启动定时器
startTimers() {
  this.clearTimers()
  
  // 时间定时器：每1秒更新时间
  this.timeTimer = setInterval(() => {
    this.updateTime()
  }, 1000)
  
  // 课程状态定时器：每30秒更新课程状态
  this.courseTimer = setInterval(() => {
    this.updateCourseStatus()
  }, 30000)
},

// 清理定时器
clearTimers() {
  if (this.timeTimer) {
    clearInterval(this.timeTimer)
    this.timeTimer = null
  }
  if (this.courseTimer) {
    clearInterval(this.courseTimer)
    this.courseTimer = null
  }
}
```

### 6.2 页面生命周期调用

| 生命周期 | 操作 |
|----------|------|
| `onInit()` | 首次加载数据，启动定时器 |
| `onShow()` | 刷新静态摘要（考试+待办），刷新课程状态 |
| `onHide()` | 清理定时器 |
| `onDestroy()` | 清理定时器 |

### 6.3 避免重复定时器

```javascript
startTimers() {
  this.clearTimers()  // 先清理再创建
  // ...
}
```
