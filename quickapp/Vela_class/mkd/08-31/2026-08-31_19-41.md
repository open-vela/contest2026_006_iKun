# 项目修改报告

时间：2026-08-31 19:41

## 一、修改内容

修复 VELA CLASS 当前已确认的 4 个逻辑问题：

1. 首页从其他页面返回后，定时器没有重新启动
2. 跨周寻找下一节课程时仍然使用旧教学周
3. 周日计算"本周待办"结束日期错误
4. 首页"明天第一节"的 daysLater 判断条件错误

## 二、问题原因

### 问题1：首页返回后定时器没有重新启动

**原因**：`onShow()` 函数在刷新数据后没有调用 `this.startTimers()`

**原代码**：
```javascript
onShow() {
  ensureStorageReady()
    .then(() => {
      this.updateTime()
      this.updateStaticSummary()
      this.updateCourseStatus()
      // 缺少 this.startTimers()
    })
}
```

**影响**：从课表、考试、待办等页面返回首页后，定时器不会重新启动，导致时间停止更新、课程状态不再刷新。

### 问题2：跨周寻找下一节课程时周次错误

**原因**：`getNextCourseAcrossDays()` 在遍历未来7天时，始终使用今天的教学周 `week`

**原代码**：
```javascript
for (let i = 1; i <= 7; i++) {
  const futureDate = new Date(now)
  futureDate.setDate(futureDate.getDate() + i)
  const weekday = getWeekdayNumber(futureDate)
  const courses = getCoursesByWeekday(weekday, week)  // 始终使用今天的 week
  // ...
}
```

**影响**：
- 第1周周日寻找下一节课时，第2周周一的课程会被遗漏
- 双周课程（如 weeks: [2, 4, 6, 8]）可能无法正确匹配

### 问题3：周日"本周待办"范围计算错误

**原因**：JavaScript 的 `getDay()` 返回周日=0，但业务逻辑中周日=7

**原代码**：
```javascript
weekEnd.setDate(weekEnd.getDate() + (7 - weekEnd.getDay()))
```

**影响**：
- 周日时：7 - 0 = 7，会多加7天
- 例如：8月30日周日，weekEnd 会变成9月6日（下周日），而不是8月30日（本周日）

### 问题4：首页"明天第一节"的 daysLater 判断条件错误

**原因**：`daysLater = 0` 表示今天，`daysLater = 1` 表示明天

**原代码**：
```javascript
if (nextAcross.daysLater === 0) {
  this.nextCourseLabel = '明天第一节'  // 错误：daysLater=0 是今天
}
```

**影响**：当今天课程结束、明天有课时，无法正确显示"明天第一节"。

## 四、首页Timer生命周期修复

### 修复后的生命周期

```
首页显示 (onShow)
  ↓
刷新首页数据
  ↓
启动 timer (startTimers)

首页隐藏 (onHide)
  ↓
清理 timer (clearTimers)

首页销毁 (onDestroy)
  ↓
清理 timer (clearTimers)
```

### 修复后的 onShow()

```javascript
onShow() {
  ensureStorageReady()
    .then(() => {
      this.updateTime()
      this.updateStaticSummary()
      this.updateCourseStatus()
      this.startTimers()          // 重新启动定时器
    })
    .catch((err) => {
      console.error('Failed to refresh home:', err)
      this.updateTime()
      this.updateStaticSummary()
      this.updateCourseStatus()
      this.startTimers()          // 重新启动定时器
    })
}
```

### 防止重复创建 timer

`startTimers()` 函数已经包含 `this.clearTimers()`，确保先清理再创建：

```javascript
startTimers() {
  this.clearTimers()  // 先清理
  
  this.timeTimer = setInterval(() => {
    this.updateTime()
  }, 1000)
  
  this.courseTimer = setInterval(() => {
    this.updateCourseStatus()
  }, 30000)
}
```

## 五、跨周下一节课程修复

### 修复后的 getNextCourseAcrossDays()

```javascript
// 检查未来7天
for (let i = 1; i <= 7; i++) {
  const futureDate = new Date(now)
  futureDate.setDate(futureDate.getDate() + i)
  const weekday = getWeekdayNumber(futureDate)
  // 为每个未来日期计算它自己的教学周
  const futureWeek = calculateCurrentWeek(futureDate)
  // 跳过学期未开始的情况
  if (futureWeek < 1) {
    continue
  }
  const courses = getCoursesByWeekday(weekday, futureWeek)
  if (courses.length > 0) {
    return { course: courses[0], daysLater: i, date: futureDate }
  }
}
```

### 学期未开始时的处理

- 今天：2026-08-30，currentWeek = 0
- 8月31日：futureWeek = 1，能够找到第1周课程
- 不会因为今天 currentWeek = 0 而让未来7天全部使用 week = 0

## 六、周日本周待办修复

### 修复后的 getWeekEnd() 函数

```javascript
function getWeekEnd(now) {
  const weekEnd = new Date(now)
  // 将 JavaScript 的周日=0 转换为业务中的周日=7
  const day = weekEnd.getDay() === 0 ? 7 : weekEnd.getDay()
  weekEnd.setDate(weekEnd.getDate() + (7 - day))
  weekEnd.setHours(23, 59, 59, 999)
  return weekEnd
}
```

### 计算示例

| 星期 | getDay() | day | 7 - day | 结果 |
|------|----------|-----|---------|------|
| 周一 | 1 | 1 | 6 | 本周日 |
| 周二 | 2 | 2 | 5 | 本周日 |
| 周六 | 6 | 6 | 1 | 本周日 |
| 周日 | 0 | 7 | 0 | 今天 |

## 七、明天第一节文案修复

### 修复后的判断逻辑

```javascript
if (nextAcross.daysLater === 1) {
  this.nextCourseLabel = '明天第一节'
} else {
  const days = ['周日', '周一', '周二', '周三', '周四', '周五', '周六']
  const date = new Date(now)
  date.setDate(date.getDate() + nextAcross.daysLater)
  this.nextCourseLabel = `下一节课 · ${days[date.getDay()]}`
}
```

### daysLater 含义

| daysLater | 含义 | 文案 |
|-----------|------|------|
| 0 | 今天 | 不会进入此分支（今天有课会直接显示） |
| 1 | 明天 | "明天第一节" |
| 2 | 后天 | "下一节课 · 周X" |
| 3+ | 更远 | "下一节课 · 周X" |
