# 项目修改报告

时间：2026-08-31 19:58

## 一、修改内容

修复 VELA CLASS 学期第一周设置模块中的两个问题：

1. 第一周日期 Picker 的可选范围和默认 selectedDateIndex 不合理
2. `setSemesterWeek1Start()` 在 Storage 写入失败时没有恢复旧缓存

## 二、问题原因

### 问题1：Picker 日期范围和默认索引

**问题1A：日期范围过小**

原代码：
```javascript
for (let i = -30; i <= 120; i++) {
  // 生成日期选项
}
```

范围：过去30天 ~ 未来120天

**影响**：
- 到了学期中后期（如10月中旬），第一周（如8月31日）已超出30天范围
- Picker 无法定位到已保存的第一周日期

**问题1B：selectedDateIndex 硬编码**

原代码：
```javascript
selectedDateIndex: 14
```

**影响**：
- index = 14 对应的是"今天 - 16天"，不是今天
- 不是已保存的第一周
- 不是日期范围的中间位置

### 问题2：Storage 写入失败没有回滚

原代码：
```javascript
export function setSemesterWeek1Start(dateStr) {
  return new Promise((resolve, reject) => {
    semesterWeek1StartCache = dateStr  // 先修改缓存

    storage.set({
      key: STORAGE_KEYS.SEMESTER_START,
      value: dateStr,
      success: function () {
        resolve()
      },
      fail: function (data, code) {
        // 没有恢复旧缓存！
        reject(new Error('Failed to save semester start'))
      }
    })
  })
}
```

**影响**：
- Storage 写入失败时，内存缓存是新值，Storage 是旧值
- 当前运行期间使用新值，重启后恢复旧值
- 用户感觉设置成功了，但重启后又恢复

## 五、Picker默认定位修复

### 修改前

```javascript
selectedDateIndex: 14  // 硬编码
```

### 修改后

```javascript
selectedDateIndex: 0  // 安全初始值

// 在 initDateOptions() 中计算今天的索引
initDateOptions() {
  // ... 生成日期选项 ...

  // 计算今天的索引作为默认值
  const year = now.getFullYear()
  const month = String(now.getMonth() + 1).padStart(2, '0')
  const day = String(now.getDate()).padStart(2, '0')
  const todayStr = `${year}-${month}-${day}`
  const todayIndex = this.dateValues.indexOf(todayStr)
  if (todayIndex !== -1) {
    this.selectedDateIndex = todayIndex
  }
}
```

## 六、已有第一周设置定位逻辑

### loadCurrentSetting() 逻辑

```javascript
loadCurrentSetting() {
  const currentStart = getSemesterWeek1Start()
  if (currentStart) {
    this.week1StartDate = currentStart
    this.updateWeek1Display(currentStart)

    // 尝试找到对应的日期索引
    const idx = this.dateValues.indexOf(currentStart)
    if (idx !== -1) {
      this.selectedDateIndex = idx
    }
    // 如果已保存的日期不在范围内，保持今天的默认值
  }
}
```

### 优先级

1. **已保存的第一周**：如果存在且在范围内，定位到该日期
2. **今天**：如果没有保存第一周，或保存的日期不在范围内，定位到今天

## 七、Semester Storage回滚修复

### 修改后的 setSemesterWeek1Start()

```javascript
export function setSemesterWeek1Start(dateStr) {
  return new Promise((resolve, reject) => {
    // 保存旧值用于回滚
    const oldValue = semesterWeek1StartCache

    // 先更新缓存
    semesterWeek1StartCache = dateStr

    storage.set({
      key: STORAGE_KEYS.SEMESTER_START,
      value: dateStr,
      success: function () {
        console.log('Semester week1 start saved:', dateStr)
        resolve()
      },
      fail: function (data, code) {
        // 写入失败，恢复旧缓存
        semesterWeek1StartCache = oldValue
        console.error('Failed to save semester start:', code)
        reject(new Error('Failed to save semester start'))
      }
    })
  })
}
```

### 回滚逻辑

| 场景 | 旧缓存 | 尝试写入 | Storage结果 | 最终缓存 |
|------|--------|----------|-------------|----------|
| 成功 | 2026-08-31 | 2026-09-07 | 成功 | 2026-09-07 |
| 失败 | 2026-08-31 | 2026-09-07 | 失败 | 2026-08-31（回滚） |
