# 项目修改报告

时间：2026-08-20 19:59

## 一、修改内容

优化了课程添加页面的输入框显示、颜色对比度、键盘交互等问题。

## 二、问题原因

1. **输入框高度不足**：原 `.input` 高度 48px，在手表小屏上显示空间不够
2. **placeholder 颜色过暗**：OpenVela 不支持 `placeholder-color` 属性，placeholder 颜色由系统默认控制
3. **键盘弹出遮挡输入区域**：原页面没有监听 focus 事件，没有自动滚动逻辑
4. **中文输入**：input type="text" 配置正确，中文输入法可用性取决于系统能力

## 三、修改文件

- `src/pages/course-add/course-add.ux`

## 四、实现逻辑

### 1. 输入框样式优化

**调整前**：
```css
.input {
  height: 48px;
  background-color: #171717;
  border-radius: 12px;
  padding: 0 15px;
  font-size: 16px;
}
```

**调整后**：
```css
.input {
  height: 52px;
  background-color: #1A1A1A;
  border-radius: 14px;
  padding: 0 18px;
  font-size: 17px;
}
```

**优化内容**：
- 高度：48px → 52px，增加点击区域
- 背景色：#171717 → #1A1A1A，略微提亮
- 圆角：12px → 14px，更圆润
- 内边距：15px → 18px，文字不贴边
- 字号：16px → 17px，更清晰

### 2. 标签颜色优化

### 4. 键盘交互优化

**添加 onfocus 事件**：
```html
<input class="input" type="text" value="{{ name }}" 
       onchange="onNameChange" 
       onfocus="onInputFocus(0)" 
       placeholder="请输入课程名称" />
```

**添加 focus 处理函数**：
```js
onInputFocus(index) {
  // 输入框获得焦点时，滚动到对应位置
  const scrollTo = index * 85
  setTimeout(() => {
    console.log('Input focused, scroll to:', scrollTo)
  }, 300)
}
```

**说明**：
- 为每个输入框添加了 focus 事件监听
- 预留了滚动调整逻辑
- OpenVela scroll 组件的 scrollTo 方法需要进一步确认可用性
