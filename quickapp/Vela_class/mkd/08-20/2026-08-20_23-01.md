## 四、实现逻辑

### 1. InputMethod 组件使用方式

**引入方式**：
```javascript
import InputMethod from '../../components/InputMethod/InputMethod.ux'
```

**组件注册**：
```javascript
export default {
  components: {
    InputMethod
  },
  ...
}
```

**模板使用**：
```html
<InputMethod
  hide="{{ keyboardHidden }}"
  screentype="circle"
  keyboardtype="QWERTY"
  maxlength="5"
  complete="onComplete"
  delete="onDelete"
/>
```

### 2. InputMethod 组件 Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| hide | boolean | true | 控制键盘显示/隐藏 |
| keyboardtype | string | "QWERTY" | 键盘类型（QWERTY/T9） |
| maxlength | number | 5 | 候选词最大显示数量 |
| vibratemode | string | "" | 振动模式 |
| screentype | string | "circle" | 屏幕类型（circle/rect/pill-shaped） |

### 3. InputMethod 组件事件

| 事件 | 参数 | 说明 |
|------|------|------|
| complete | { content: string } | 输入完成时触发，返回中文字符串 |
| delete | {} | 删除时触发 |
| keyDown | { content: string } | 按键时触发 |
| visibilityChange | { visible: boolean } | 可见性变化时触发 |

### 4. 测试页面功能

- 显示输入结果
- 点击输入区域打开键盘
- 接收 InputMethod 组件返回的中文字符串
- 清除按钮重置输入

### 5. 首页入口

在首页底部摘要区域下方添加"输入法测试"临时入口，点击跳转到测试页面。

## 五、测试验证

### 测试步骤：
1. 进入首页，确认显示"输入法测试"入口
2. 点击入口，进入输入法测试页面
3. 点击输入区域，确认键盘弹出
4. 输入拼音（如 "ni" "hao"），确认显示候选词
5. 选择中文候选词，确认输入结果正确显示
6. 点击清除按钮，确认输入清空

### 预期结果：
- 输入法组件成功加载
- 键盘正常显示
- 可以输入拼音并选择中文候选词
- complete 事件返回正确的中文字符串

### 已知警告：
- `[inputmethod] Unknown element` - 自定义组件命名警告，不影响功能
- 组件路径建议使用绝对路径，不影响功能
