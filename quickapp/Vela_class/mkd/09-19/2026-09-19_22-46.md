# 修复 7 个 bug 级问题报告

时间：2026-09-19 22:46

## 1. 问题描述

本次修复 7 个 bug 级问题，涉及 6 个文件。

## 2. 根因分析

| Bug | 根因 |
|-----|------|
| schedule.ux timeline 定位错误 | `.timeline-item` 未设置 `position: relative`，`.timeline-line` 高度硬编码 50px |
| task-add.ux 日期范围仅 30 天 | 循环上限为 30，编辑模式下原 deadline 超出范围时 dateIndex 为 -1 |
| task-add.ux 默认时间边界问题 | 默认选今天 + 23:59，若在 23:59 之后选择今天则校验报错 |
| exam.js 时区问题 | `new Date(exam.date)` 将纯日期字符串当作 UTC 午夜解析 |
| formatDeadline 不一致 | task-detail.ux 无"今天"/"明天"判断逻辑 |
| toggleSelect 数组更新问题 | 直接 splice/push 可能不触发视图更新 |
| home.ux onShow 缺少守卫 | 首次显示时与 onInit 重复加载 |

## 3. 修改方案

| Bug | 修改方案 |
|-----|----------|
| timeline 定位 | `.timeline-item` 添加 `position: relative`，`.timeline-line` 用 `bottom: 0` 替代 `height: 50px` |
| 日期范围 | 循环上限改为 180，prefill 中 dateIndex 为 -1 时插入原日期 |
| 默认时间边界 | `selectedDateIndex` 从 0 改为 1（默认选明天） |
| 时区修复 | `getExamStatus` 中用 `parseDateTime` 替代 `new Date` |
| formatDeadline | 增加"今天"/"明天"判断逻辑 |
| toggleSelect | 改为重新赋值整个数组 |
| onShow 守卫 | 添加 `isInitialized` 字段和守卫 |
