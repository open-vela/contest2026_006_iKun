# 考试详情页及列表页显示星期几报告

时间：2026-09-19 21:50

## 1. 问题描述

formatExamDate 函数返回格式为"X月X日 · HH:MM"，不含星期几。

## 2. 根因分析

函数未调用 date.getDay() 获取星期。

## 3. 修改方案

formatExamDate 格式改为"X月X日 周X · HH:MM"。

## 4. 修改的文件和行号

| 文件 | 行号 | 修改内容 |
|------|------|----------|
| `src/common/exam.js` | 114-122 | formatExamDate 函数加入星期几 |

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| formatExamDate 返回值包含星期几 | ✅ |
| 星期数组为 ['周日', '周一', '周二', '周三', '周四', '周五', '周六'] | ✅ |
| exam.ux 和 exam-history.ux 的 split(' · ')[0] 逻辑无需修改 | ✅ |
| exam-detail.ux 显示完整的"X月X日 周X · HH:MM" | ✅ |

## 6. 测试步骤

1. 进入考试详情页，日期应显示"X月X日 周X · HH:MM"格式
2. 进入考试列表页，每项日期应显示"X月X日 周X"
3. 进入考试历史页，每项日期应显示"X月X日 周X"
4. 验证星期正确（如 2026-09-20 是周六）
