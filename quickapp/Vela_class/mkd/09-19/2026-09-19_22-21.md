# course-detail守卫+学期周数改为20+动态计算学期总周数报告

时间：2026-09-19 22:21

## 1. 问题描述

1. course-detail.ux 的 onShow 缺少 isInitialized 守卫
2. 学期总周数 16 硬编码在多处
3. 首页学期进度条的总周数应动态计算

## 2. 根因分析

- onShow 无守卫导致重复加载
- 16 硬编码散布在多处
- 无动态计算函数

## 3. 修改方案

- 新增 getSemesterTotalWeeks() 动态计算
- 各处用动态值替代硬编码
- course-add 默认 1-20
- course-detail 加守卫

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/pages/course-detail/course-detail.ux` | private 新增 isInitialized，onInit 完成后置 true，onShow 开头守卫 |
| `src/common/schedule.js` | 新增 getSemesterTotalWeeks() 函数，formatCourseWeeks 用动态总周数 |
| `src/pages/home/home.ux` | 模板和进度百分比用动态 semesterTotalWeeks 替代硬编码 16 |
| `src/pages/schedule/schedule.ux` | 周次上限用 semesterTotalWeeks 替代硬编码 16 |
| `src/pages/course-add/course-add.ux` | 默认周次范围改为 1-20 |

## 6. 测试步骤

1. **首页学期进度**：应显示"第X周/16周"（当前课表最大周次为 16）

2. **动态总周数**：添加一个周次到 20 的课程，首页学期进度应变为"第X周/20周"

3. **课表周次浏览**：应能翻到第 20 周（当前课表最大周次为 16 时翻到 16 周箭头禁用）

4. **添加课程默认周次**：默认选中 1-20 周

5. **课程详情页守卫**：进入后数据只加载一次，不重复
