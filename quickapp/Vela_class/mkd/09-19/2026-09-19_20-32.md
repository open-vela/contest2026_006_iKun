# 待办历史一键清除功能报告

时间：2026-09-19 20:32

## 1. 问题描述

task-history.ux 当前只有基本的列表显示，缺少批量管理/清除能力。exam-history.ux 已有完整的管理模式，task-history.ux 需要移植同样的功能。

## 2. 根因分析

- task-history.ux 仅有列表显示，无选择/删除逻辑
- storage.js 缺少 clearHistoryTasks 批量删除函数

## 3. 修改方案

1. storage.js 新增 clearHistoryTasks(taskIds) 批量删除函数
2. task-history.ux 移植 exam-history.ux 的管理模式

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 新增 clearHistoryTasks 函数 |
| `src/pages/task-history/task-history.ux` | 移植管理模式：正常模式（管理+清除）→ 选择模式（勾选+全选+删除+完成）→ 两步确认 |

## 6. 测试步骤

1. **进入待办历史页**：操作栏应显示"管理"和"清除"按钮

2. **进入选择模式**：点击"管理" → 每个待办项左侧显示勾选图标

3. **勾选操作**：勾选若干待办 → 点击"全选"应全选 → 再点"全选"取消全选

4. **删除选中**：点击"删除" → 弹出"确定删除？"确认 → 点"确认"删除选中项 → 列表刷新

5. **退出选择模式**：点击"完成" → 退出选择模式

6. **跳转详情**：非选择模式下点击待办项 → 跳转详情页

7. **清除所有**：点击"清除" → 弹出"确定清除？"确认 → 点"确认"清除所有历史待办

8. **空列表提示**：空列表时点"清除" → 提示"没有可清除的待办"

9. **返回拦截**：选择模式下按返回 → 退出选择模式而非返回上页
