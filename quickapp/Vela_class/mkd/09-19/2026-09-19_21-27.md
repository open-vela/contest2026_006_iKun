# 三个页面 onShow 添加 isInitialized 守卫报告

时间：2026-09-19 21:27

## 1. 问题描述

exam-detail.ux、task-detail.ux、task-settings.ux 三个页面的 onShow 缺少 isInitialized 守卫，首次显示时与 onInit 重复加载数据。

## 2. 根因分析

onShow 在首次显示时也触发，缺少守卫导致 onInit 和 onShow 的异步链并发执行。

## 3. 修改方案

private 新增 isInitialized，onInit 完成后置 true，onShow 开头守卫。

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/pages/exam-detail/exam-detail.ux` | private 新增 isInitialized: false，onInit 完成后置 true，onShow 开头守卫 |
| `src/pages/task-detail/task-detail.ux` | private 新增 isInitialized: false，onInit 完成后置 true，onShow 开头守卫 |
| `src/pages/task-settings/task-settings.ux` | private 新增 isInitialized: false，onInit 完成后置 true，onShow 开头守卫 |

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| 三个文件的 private 中都有 isInitialized: false | ✅ |
| 三个文件的 onInit 中异步加载完成后设置了 isInitialized = true | ✅ |
| 三个文件的 onShow 开头有 if (!this.isInitialized) return | ✅ |
| onShow 的守卫在异步链之前 | ✅ |

## 6. 测试步骤

1. **进入考试详情页**：数据应只加载一次，不重复

2. **跳转返回**：从考试详情页跳转到编辑页再返回，数据应正确刷新

3. **进入待办详情页和设置页**：同样验证数据只加载一次

4. **修改设置返回**：从待办设置页修改设置后返回待办页再进入设置页，应显示最新设置
