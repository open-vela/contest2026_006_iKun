# 课程添加页周次选择器扩展到 20 周报告

时间：2026-09-19 22:23

## 1. 修改文件列表

- `src/pages/course-add/course-add.ux`

## 2. 修改内容摘要

将周次选择器的可选范围从 1-16 周扩展到 1-20 周，默认选中值保持第 16 周不变。

## 3. 修改前后的关键代码对比

### 修改前
```javascript
startWeekIndex: 0,
endWeekIndex: 19,
weekRange: ['第1周', ..., '第20周'],
weeks: [1, ..., 20],
weeksText: '第1-20周 · 每周',
```

### 修改后
```javascript
startWeekIndex: 0,
endWeekIndex: 15,  // 默认选中第 16 周
weekRange: ['第1周', ..., '第20周'],  // 可选范围到第 20 周
weeks: [1, ..., 20],  // 可选范围到第 20 周
weeksText: '第1-16周 · 每周',  // 默认显示第 1-16 周
```

## 4. 修改原因说明

此前已将学期总周数从 16 改为 20（schedule.js 的 getSemesterTotalWeeks 动态计算），但 course-add.ux 的默认选中值需要保持第 16 周，仅扩展可选项上限到第 20 周。

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| weekRange 数组长度为 20，最后一项为 '第20周' | ✅ |
| weeks 数组长度为 20，最后一项为 20 | ✅ |
| endWeekIndex 仍为 15（默认第 16 周） | ✅ |
| weeksText 仍为 '第1-16周 · 每周' | ✅ |

## 6. 潜在影响分析

- 用户可选择第 17-20 周作为结束周
- 默认选中值不变，不影响现有课程的添加流程
- 与 schedule.js 的 getSemesterTotalWeeks() 动态计算保持一致
