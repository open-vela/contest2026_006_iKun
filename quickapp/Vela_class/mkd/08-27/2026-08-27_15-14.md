# 项目修改报告

时间：2026-08-27 15:14

## 一、修改内容

修复"全部课程"列表无法点击进入课程详情的问题。

## 二、问题原因

"全部课程"的 `list-item` 缺少 `onclick` 事件绑定：
- "今天"和"本周"模式的课程都绑定了 `onclick="goToDetail($item.id)"`
- "全部"模式的课程漏掉了这个事件绑定

## 三、修改文件

- `src/pages/schedule/schedule.ux`

## 四、实现逻辑

在"全部课程"的 `list-item` 上添加 `onclick="goToDetail($item.id)"`：

**修改前**：
```html
<list-item for="{{ allCourses }}" class="week-item" type="allCourse">
```

**修改后**：
```html
<list-item for="{{ allCourses }}" class="week-item" type="allCourse" onclick="goToDetail($item.id)">
```

复用已有的 `goToDetail()` 函数，该函数通过 `courseId` 跳转到课程详情页。

## 五、测试验证

### 测试步骤：
1. 进入课表页面，切换到"全部"模式
2. 点击任意课程 → 应进入课程详情
3. 用户添加的课程详情页应显示"删除课程"按钮
4. 删除课程后返回课表，"全部"列表应更新
5. "今天"和"本周"模式仍然正常工作
