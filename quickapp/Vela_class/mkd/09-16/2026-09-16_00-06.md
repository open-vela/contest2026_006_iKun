# 输入法无法输入问题修复报告

时间：2026-09-16 00:06

## 一、修改内容

修复三个添加页面（课程、待办、考试）的输入法键盘点击字符无法写入输入框的问题。

### 官方组件核查表

| 项目 | 官方文档结论 | 现有代码写法 | 差异 |
|------|-------------|-------------|------|
| complete 事件参数结构 | `{ detail: { content: string } }` | `evt.content` | ❌ 错误，应为 `evt.detail.content` |
| delete 事件参数结构 | `{ detail: {} }` | 无参数 | ✅ 正确（delete 事件无需取参） |

**结论**：`evt.content` 恒为 `undefined`，`undefined || ''` 结果为空串，导致输入内容无法追加到字段中。

## 二、问题原因

父页面 `onKeyboardInput(evt)` 读取事件参数时使用了 `evt.content`，而官方 input-method 组件的 complete 事件回参结构为 `{ detail: { content: string } }`，正确取值应为 `evt.detail.content`。

## 三、修改文件

| 文件 | 修改行 | 修改内容 |
|------|--------|----------|
| `src/pages/course-add/course-add.ux` | 第 384 行 | `evt.content` → `(evt && evt.detail && evt.detail.content)` |
| `src/pages/task-add/task-add.ux` | 第 254 行 | `evt.content` → `(evt && evt.detail && evt.detail.content)` |
| `src/pages/exam-add/exam-add.ux` | 第 245 行 | `evt.content` → `(evt && evt.detail && evt.detail.content)` |

未修改：
- `src/components/InputMethod/InputMethod.ux` - 组件本身未改动
- 其他页面与数据逻辑

## 四、实现逻辑

将三处 `onKeyboardInput` 方法中的取值写法统一修正：

```javascript
// 修改前
const content = evt.content || ''

// 修改后
const content = (evt && evt.detail && evt.detail.content) || ''
```

使用防御性取值（`evt && evt.detail && evt.detail.content`），避免因事件参数结构异常导致报错。

其余字段追加逻辑保持不变：
- course-add: `name` / `teacher` / `classroom`
- task-add: `title`
- exam-add: `classroom`

## 六、后续建议

1. **组件事件文档化**：在 InputMethod.ux 组件头部注释中明确事件参数结构，避免后续开发者误用
2. **TypeScript 类型检查**：若框架支持，可为事件参数添加类型定义，提前发现取值错误
3. **统一事件处理**：三个页面的 `onKeyboardInput` 逻辑相似，可考虑抽取为公共 mixin 或工具函数
