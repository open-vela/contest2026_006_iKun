# 添加考试「自定义课程」输入框重叠问题修复报告

时间：2026-09-16 00:53

## 一、修改内容

为「自定义课程」输入框添加专用样式类 `.custom-course-input`，设置 `margin-top: 8px` 消除与上方 picker 的重叠。

## 二、问题原因

picker 组件实际渲染高度略大于设定的 52px（含内置边距），紧随其后的 input-wrapper 按 52px 紧贴排列，导致两者重叠几像素。

## 三、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/exam-add/exam-add.ux` | 新增 `.custom-course-input` 样式类，设置 margin-top |

未修改：
- 模板结构
- 脚本逻辑
- 其他字段（「考场」等）
- 其他页面

## 四、实现逻辑

### 模板修改

为自定义课程输入框添加专用类 `custom-course-input`：

```html
<div if="{{ selectedCourseIndex === 0 }}" class="input-wrapper custom-course-input" @click="onInputFocus('course')">
```

### 样式修改

新增 `.custom-course-input` 样式类：

```css
.custom-course-input {
  margin-top: 8px;
}
```

仅作用于「自定义课程」输入框，不影响「考场」等其他 input-wrapper。

## 六、后续建议

1. **统一间距规范**：三个添加页面的 form-group 间距可统一规范
2. **picker 高度适配**：若其他页面也出现类似问题，可考虑统一调整 picker 的 margin 或 padding
