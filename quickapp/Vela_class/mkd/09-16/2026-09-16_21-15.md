# 首页布局尺寸调整报告

时间：2026-09-16 21:15

## 1. 问题描述

首页学期进度添加后，整体布局有点挤。需要调整尺寸让视觉更舒适。

## 2. 根因分析

主卡片偏大、学期周次文字偏小、进度条偏短，导致视觉不平衡。

## 3. 修改方案

调整首页三个样式尺寸：
1. 主卡片高度从 165px 缩小到 145px
2. 学期周次文字从 13px 放大到 15px
3. 进度条宽度从 60px 加长到 100px

## 4. 修改的文件和行号

| 文件 | 行号 | 修改内容 |
|------|------|----------|
| `src/pages/home/home.ux` | 121-124 | .semester-text font-size 从 13px 改为 15px |
| `src/pages/home/home.ux` | 127-132 | .semester-progress width 从 60px 改为 100px |
| `src/pages/home/home.ux` | 141-148 | .main-card height 从 165px 改为 145px |

未修改其他文件。

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| .main-card 的 height 为 145px | ✅ |
| .semester-text 的 font-size 为 15px | ✅ |
| .semester-progress 的 width 为 100px | ✅ |
| 未修改其他样式和文件 | ✅ |

## 6. 测试步骤

在手表上验证：

1. 进入首页
2. 确认整体布局不再拥挤
3. 学期周次文字更大更清晰（15px）
4. 进度条更长更明显（100px）
5. 主卡片适当缩小（145px）
