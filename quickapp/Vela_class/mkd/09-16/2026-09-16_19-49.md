# 课程和考试时间冲突检测报告

时间：2026-09-16 19:49

## 1. 问题描述

当前添加/编辑课程和考试时，没有时间冲突检测。用户可能在同一时间段安排两门课程或两场考试，造成数据矛盾。

## 2. 根因分析

保存前缺少冲突校验逻辑，需要在 saveCourse 和 saveExam 方法中增加检测。

## 3. 修改方案

1. 课程冲突检测：同一星期、周次有交集、时间段重叠
2. 考试冲突检测：同一日期、时间段重叠
3. 编辑模式排除自身

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/pages/course-add/course-add.ux` | saveCourse 方法中增加冲突检测（约 513-530 行） |
| `src/pages/exam-add/exam-add.ux` | saveExam 方法中增加冲突检测（约 369-383 行） |

未修改其他文件。

## 6. 测试步骤

### 课程冲突

1. 添加一门周一 08:00-09:00 的课程
2. 再添加一门周一 08:30-09:30 的课程（周次有交集）
3. 确认提示"与课程「XXX」时间冲突"且无法保存
4. 改为周一 10:00-11:00
5. 确认保存成功

### 课程编辑不误判

1. 编辑刚添加的课程，不改时间直接保存
2. 确认保存成功（不把自身算冲突）

### 考试冲突

1. 添加一场某日 09:00-11:00 的考试
2. 再添加同日 10:00-12:00 的考试
3. 确认提示"与考试「XXX」时间冲突"且无法保存
4. 改为同日 14:00-16:00
5. 确认保存成功

### 考试编辑不误判

1. 编辑刚添加的考试，不改时间直接保存
2. 确认保存成功
