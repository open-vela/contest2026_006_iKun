# 课表设置页新增"删除所有课程"功能报告

时间：2026-09-16 14:56

## 1. 问题描述

当前课表设置页只有"学期第一周"设置，缺少批量清理课程的功能。新学期开始时，用户需要逐个进入课程详情页删除旧课程，非常繁琐。

## 2. 根因分析

课程数据有两个来源：
- **Mock 数据**：从 `./data` 导入的 `courses`，硬编码
- **用户添加的课程**：`courseCache` 内存缓存

要真正让课表变空，需同时：
- 清空 `courseCache` 为空数组
- 关闭 `useMockDataCache` 为 false

## 3. 修改方案

### 第一部分：storage.js 新增 clearAllCourses()

清空所有课程数据：
1. 保存旧值用于失败回滚
2. 将 `courseCache` 置为空数组，`useMockDataCache` 置为 false
3. 同时向 storage 写入两个 key
4. 两个 storage.set 都成功才 resolve；任一失败则回滚

### 第二部分：schedule-settings.ux 新增功能

1. 模板新增"删除所有课程" section
2. 两步确认：先点按钮，再确认
3. 成功后 toast 提示"已清空所有课程"

4. 点击红色「删除所有课程」按钮
5. 验证：出现确认提示「确定删除所有课程？此操作不可恢复」，下方有「取消」和「确认删除」两个按钮
