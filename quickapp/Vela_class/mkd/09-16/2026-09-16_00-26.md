# Picker 显示 option 1 问题修复报告

时间：2026-09-16 00:26

## 一、修改内容

1. 在 time.js 中新增 getWeekday 函数，返回中文星期
2. exam-add.ux 增加无课程兜底，避免显示 option 1

## 二、问题原因

1. **日期 picker 显示 option 1**：exam-add 和 task-add 中 import 了 `getWeekday`，但 time.js 中只有 `getWeekdayNumber`（返回数字），缺少返回中文星期的 `getWeekday` 函数，导致 import 解析到 undefined，调用时抛 TypeError，日期 range 数组生成为空。

2. **课程 picker 显示 option 1**：exam-add 的 `initCourseRange` 无空数据兜底，当课表无课程时 `courseRange` 为空数组，picker 无内容可显示。

## 三、修改文件

| 文件 | 修改内容 |

| `src/common/time.js` | 新增 `getWeekday(date)` 函数，返回中文星期（'周日'~'周六'） |

## 四、实现逻辑

### 1. time.js 新增 getWeekday 函数

```javascript
/**
 * 获取中文星期
 * @param {Date} date
 * @returns {string} 如 '周一'、'周日'
 */
export function getWeekday(date) {
  const days = ['周日', '周一', '周二', '周三', '周四', '周五', '周六']
  return days[date.getDay()]
}
```

与 `formatFullDate` 内中文星期数组保持一致。

### 2. exam-add 无课程兜底

```javascript
initCourseRange() {
  const courses = getCourses()
  if (courses.length === 0) {
    this.courseRange = ['暂无课程']
    this.courseIds = []
  } else {
    this.courseRange = courses.map(c => c.name)
    this.courseIds = courses.map(c => c.id)
  }
}
```

### 3. saveExam 优化错误提示

```javascript
if (!this.courseIds[this.selectedCourseIndex]) {
  this.showError(this.courseIds.length === 0 ? '请先在课表添加课程' : '请选择考试课程')
  return
}
```
