# 考试和待办编辑功能报告

时间：2026-09-16 16:41

## 1. 问题描述

当前考试和待办只有添加和删除功能，缺少编辑功能。用户修改考试/待办需要删除后重新添加，非常不便。

## 2. 根因分析

考试和待办模块未实现编辑功能，需要参考已有的课程编辑模式进行扩展。

## 3. 修改方案

为考试和待办添加编辑功能，模式与课程编辑完全一致：
- 详情页加"修改"按钮，点击跳转到添加页的编辑模式
- 添加页支持编辑模式（接收 ID 参数、预填数据、保存时调用 update 而非 add）
- 详情页 onShow 刷新（编辑保存后返回时看到最新数据）
- storage.js 新增 updateExam 和 updateTask 函数

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 新增 `updateExam` 和 `updateTask` 函数 |
| `src/pages/exam-detail/exam-detail.ux` | 加修改按钮 + onShow + onEditClick |
| `src/pages/exam-add/exam-add.ux` | 编辑模式（protected examId、prefill、saveExam 分支） |
| `src/pages/task-detail/task-detail.ux` | 加修改按钮 + onShow + onEditClick |

## 6. 测试步骤

### 考试编辑

1. 添加一场考试
2. 进入考试详情页
3. 点击"修改考试"按钮
4. 修改考场/时间
5. 点击保存
6. 返回详情页确认数据已更新

### 待办编辑

1. 添加一个待办
2. 进入待办详情页
3. 点击"修改待办"按钮
4. 修改名称/截止时间
5. 点击保存
6. 返回详情页确认数据已更新

### Mock 不可编辑

1. 查看 Mock 考试/待办详情
2. 确认无"修改"按钮
