# 首页学期进度显示报告

时间：2026-09-16 21:07

## 1. 问题描述

首页缺少学期进度可视化，用户无法直观了解当前处于学期第几周、进度如何。

## 2. 根因分析

首页未展示学期周次信息，需要调用 calculateCurrentWeek 函数计算并展示。

## 3. 修改方案

在首页 header 的日期下方增加一行学期进度显示：
- 文字"第X周/16周"显示当前周次
- 小型 progress 进度条显示学期进度百分比
- 学期未开始时显示"学期未开始"

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/pages/home/home.ux` | 模板、样式、import、private 数据、数据计算 |

未修改其他文件。

## 6. 测试步骤

### 已设置学期第一周

1. 确保已在课表设置中设置学期第一周
2. 进入首页
3. header 日期下方显示"第X周/16周"和进度条
4. 进度条比例正确（X/16）

### 未设置学期第一周

1. 未设置学期第一周时，calculateCurrentWeek 默认返回 1
2. 首页显示"第1周/16周"和进度条

### 学期未开始

1. 当前日期在学期第一周之前
2. 首页显示"学期未开始"
