# 首页"今日无课"字体放大修复报告

时间：2026-09-16 15:40

## 1. 问题描述

主页面在"今日无课"且无考试预览时，中间区域只显示"今日无课"四个字，字体大小为 16px（使用 .status-label 样式），字体太小，影响观感。

## 2. 根因分析

.status-label 样式被四处共用："下一节课"、"正在上课"、"今日课程已结束"、"今日无课"，不能直接改大 font-size，否则影响其他状态。

## 3. 修改方案

仅在"今日无课"且无考试预览时，将"今日无课"字体放大到 24px。

1. 模板修改：给"今日无课"的 text 元素增加条件 class，当 nearestExam 为空时附加 .no-class-large
2. 样式修改：新增 .no-class-large 样式类，设置 font-size: 24px

## 4. 修改的文件和行号

| 文件 | 行号 | 修改内容 |
|------|------|----------|
| `src/pages/home/home.ux` | 42 | 模板增加条件 class `{{ !nearestExam ? 'no-class-large' : '' }}` |
| `src/pages/home/home.ux` | 138-140 | 新增 .no-class-large 样式类，font-size: 24px |

未修改其他文件。未修改 .status-label 原始样式。未修改其他三处使用 .status-label 的元素。

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| "今日无课"的 text 元素有条件 class | ✅ |
| 新增 .no-class-large 样式类，font-size 为 24px | ✅ |
| .status-label 原始样式未被修改 | ✅ |
| 其他三处使用 .status-label 的元素未被修改 | ✅ |
| 未修改其他文件 | ✅ |

## 6. 测试步骤

在手表上验证：

1. 确保今日无课（可调整学期设置使今天不在任何教学周内）
2. 确保无考试预览（或所有考试已结束）
3. 进入主页面
4. 中间区域显示"今日无课"
5. 确认字体明显大于之前的 16px（现为 24px）
