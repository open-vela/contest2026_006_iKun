# 添加考试页面「自定义课程」能力报告

时间：2026-09-16 00:42

## 一、修改内容

为添加考试页面增加「自定义课程」能力，考试科目不再依赖课表。

### 功能说明

- 「考试课程」picker 始终包含「自定义课程」选项（第 0 项）
- 选中「自定义课程」后弹出输入法，可手动输入课程名
- 自定义课程名直接作为 exam.course 值保存，不写入课表
- 无课程时仍可正常添加考试

## 二、问题原因

原实现中考试课程字段仅实现为 picker，数据源固定为课表课程列表，缺少手动输入入口。课表无课程或想考课表之外的考试时无法录入。

## 四、实现逻辑

### 1. 新增字段

```javascript
private: {
  customCourseName: '',  // 自定义课程名
  // ... 其他字段
}
```

### 2. initCourseRange 改造

```javascript
initCourseRange() {
  const courses = getCourses()
  this.courseRange = ['自定义课程', ...courses.map(c => c.name)]
  this.courseIds = [null, ...courses.map(c => c.id)]
}
```

- 第 0 项为「自定义课程」标记，courseIds[0] = null
- 后续项为课表课程

### 3. onCourseChange 处理

```javascript
onCourseChange(e) {
  this.selectedCourseIndex = e.newSelected
  if (e.newSelected === 0) {
    this.currentInputField = 'course'
    this.keyboardHidden = false
  }
}
```

选中第 0 项时弹出输入法。

### 4. 键盘事件扩展

```javascript
onKeyboardInput(evt) {
  const content = (evt && evt.detail && evt.detail.content) || ''
  if (this.currentInputField === 'classroom') {
    this.classroom += content
  } else if (this.currentInputField === 'course') {
    this.customCourseName += content
  }
}

onKeyboardDelete() {
  if (this.currentInputField === 'classroom' && this.classroom.length > 0) {
    this.classroom = this.classroom.slice(0, -1)
  } else if (this.currentInputField === 'course' && this.customCourseName.length > 0) {
    this.customCourseName = this.customCourseName.slice(0, -1)
  }
}
```

### 5. 显示方案

采用 **picker + text 辅助显示** 方案：

```html
<picker class="picker" type="text" range="{{ courseRange }}" selected="{{ selectedCourseIndex }}" onchange="onCourseChange">
</picker>
<text if="{{ selectedCourseIndex === 0 && customCourseName }}" class="custom-course-display">课程名：{{ customCourseName }}</text>
```

**方案说明**：
- picker 始终显示「自定义课程」（第 0 项）
- 选中自定义课程后，若已输入课程名，在 picker 下方用 text 显示「课程名：xxx」
- 避免使用绝对定位覆盖层（防止重蹈之前 picker-value 遮挡的坑）

### 6. saveExam 校验

```javascript
saveExam() {
  let courseName = ''
  if (this.selectedCourseIndex === 0) {
    if (!this.customCourseName) {
      this.showError('请输入课程名称')
      return
    }
    courseName = this.customCourseName
  } else {
    if (!this.courseIds[this.selectedCourseIndex]) {
      this.showError('请选择考试课程')
      return
    }
    courseName = this.courseRange[this.selectedCourseIndex]
  }
  // ... 保存 examData.course = courseName
}
```
