# 课程模块编辑功能报告

时间：2026-09-16 14:03

## 一、修改内容

为课程详情页新增「修改课程」按钮，点击跳转到课程添加页进入编辑模式，预填原数据，保存后更新（而非新增）。

### 功能说明

- 仅用户添加的课程可修改（Mock 默认课程不可修改）
- 编辑模式下页面标题显示「编辑课程」
- 表单预填原课程数据（名称、教师、教室、星期、时间、周次）
- 保存时更新原课程，不产生新 id

## 二、问题原因

原实现中课程仅支持添加、查看、删除，用户添加课程填错后只能删除重加，体验不佳。

## 四、实现逻辑

### 1. storage.js 新增 updateCourse

```javascript
export function updateCourse(courseId, courseData) {
  return new Promise((resolve, reject) => {
    const index = courseCache.findIndex(c => c.id === courseId)
    if (index === -1) return reject(new Error('Course not found'))
    if (courses.some(c => c.id === courseId)) return reject(new Error('Cannot update default course'))
    
    const oldCourseCache = courseCache
    const updated = { id: courseId, ...courseData }
    courseCache = courseCache.map(c => (c.id === courseId ? updated : c))
    
    storage.set({
      key: STORAGE_KEYS.COURSES,
      value: JSON.stringify(courseCache),
      success: () => resolve(updated),
      fail: () => { courseCache = oldCourseCache; reject(new Error('Failed to update course')) }
    })
  })
}
```

### 3. course-add.ux 编辑模式

**接收 courseId 参数**：
```javascript
protected: {
  courseId: ''
}
```

**编辑状态判断**：
```javascript
onInit() {
  if (this.courseId) {
    this.isEdit = true
    ensureStorageReady().then(() => {
      const course = getCourses().find(c => c.id === this.courseId)
      if (course) this.prefill(course)
    })
  }
  this.generateWeeks()
}
```

**预填逻辑**：
```javascript
prefill(course) {
  this.name = course.name || ''
  this.teacher = course.teacher || ''
  this.classroom = course.classroom || ''
  this.selectedWeekday = course.weekday || 1
  this.startTime = course.startTime || '08:00'
  this.endTime = course.endTime || '09:00'
  
  if (course.weeks && course.weeks.length > 0) {
    this.startWeekIndex = Math.min(...course.weeks) - 1
    this.endWeekIndex = Math.max(...course.weeks) - 1
    
    const allOdd = course.weeks.every(w => w % 2 === 1)
    const allEven = course.weeks.every(w => w % 2 === 0)
    if (allOdd) this.weekType = 'odd'
    else if (allEven) this.weekType = 'even'
    else this.weekType = 'all'
  }
  
  this.generateWeeks()
}
```

**保存分支**：
```javascript
saveCourse() {
  // ... 校验逻辑不变
  
  const action = this.courseId
    ? updateCourse(this.courseId, courseData)
    : addCourse(courseData)
  
  ensureStorageReady()
    .then(() => action)
    .then(() => router.back())
    .catch(() => this.showError('保存失败'))
}
```
