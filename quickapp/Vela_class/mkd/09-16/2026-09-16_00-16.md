# 添加课程页面 Picker 滑动异常与影子问题修复报告

时间：2026-09-16 00:16

## 一、修改内容

移除添加课程页面中四处 picker 的多余包裹层（picker-wrap + picker-value），改为直接使用 picker 组件，与 task-add / exam-add 保持一致。

### 修改的四处 picker

| 位置 | 原结构 | 新结构 |
|------|--------|--------|
| 步骤2 - 开始时间 | `<div class="picker-wrap"><picker class="time-picker">...</picker><text class="picker-value">...</text></div>` | `<picker class="picker" ...>` |
| 步骤2 - 结束时间 | 同上 | 同上 |
| 步骤3 - 开始周 | `<div class="picker-wrap"><picker class="week-picker">...</picker><text class="picker-value">...</text></div>` | `<picker class="picker" ...>` |
| 步骤3 - 结束周 | 同上 | 同上 |

## 二、问题原因

1. **滑动异常**：.picker-value 使用 `position: absolute` 但父容器 .picker-wrap 未设 `position: relative`，导致 .picker-value 错位显示并悬浮遮挡 picker，拦截滑动事件。

2. **文字影子**：picker 组件自身会显示选中值，同时 .picker-value 也显示一份文字，两者重叠形成影子。

## 四、实现逻辑

### 模板修改

将四处 picker 从：
```html
<div class="picker-wrap">
  <picker class="time-picker" type="time" selected="{{ startTime }}" onchange="onStartTimeChange"></picker>
  <text class="picker-value">{{ startTime || '08:00' }}</text>
</div>
```

改为：
```html
<picker class="picker" type="time" selected="{{ startTime }}" onchange="onStartTimeChange"></picker>
```

### 样式修改

删除不再使用的样式：
- `.picker-wrap`
- `.time-picker`
- `.week-picker`
- `.picker-value`

新增 `.picker` 样式（与 task-add 一致）：
```css
.picker {
  width: 100%;
  height: 52px;
  background-color: #1A1A1A;
  border-radius: 14px;
  color: #FFFFFF;
  font-size: 17px;
}
```
