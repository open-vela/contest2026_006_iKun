# 课程编辑后返回详情页数据不刷新问题修复报告

时间：2026-09-16 14:17

## 一、修改内容

1. 详情页 onShow 增加 `refreshCoursesFromStorage()` 从 storage 重读数据
2. saveCourse 中把 update/add 动作移入 `ensureStorageReady` 的 then 回调内，消除竞态

## 二、问题原因

1. **详情页 onShow 仅调用 loadCourse**：`loadCourse` 读取内存 `courseCache`，未先从 storage 重读，导致读到旧数据
2. **saveCourse 竞态隐患**：`action`（updateCourse/addCourse）在 `ensureStorageReady` 之前创建并执行，可能在 storage 未就绪时操作缓存

## 三、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/course-detail/course-detail.ux` | import 增加 `refreshCoursesFromStorage`，onShow 改为先 refresh 再 load |
| `src/pages/course-add/course-add.ux` | saveCourse 中把 action 移入 ensureStorageReady 的 then 回调内 |

## 四、实现逻辑

### 1. course-detail.ux onShow 修改

```javascript
// 修改前
onShow() {
  ensureStorageReady()
    .then(() => this.loadCourse())
    .catch(() => this.loadCourse())
}

// 修改后
onShow() {
  ensureStorageReady()
    .then(() => refreshCoursesFromStorage())
    .then(() => this.loadCourse())
    .catch(() => this.loadCourse())
}
```

与 home.ux / schedule.ux 的返回刷新方式保持一致。

### 2. course-add.ux saveCourse 修改

```javascript
// 修改前（有竞态隐患）
const action = this.courseId
  ? updateCourse(this.courseId, courseData)
  : addCourse(courseData)

ensureStorageReady()
  .then(() => action)
  .then(() => router.back())
  .catch(() => this.showError('保存失败'))

// 修改后（消除竞态）
ensureStorageReady()
  .then(() => this.courseId ? updateCourse(this.courseId, courseData) : addCourse(courseData))
  .then(() => router.back())
  .catch(() => this.showError('保存失败'))
```

## 六、后续建议

1. **统一刷新模式**：所有详情页的 onShow 均采用 `ensureStorageReady → refreshXxxFromStorage → loadXxx` 模式
2. **竞态检查**：检查其他页面的 saveXxx 方法，确保操作在 storage ready 后执行
