# clearAllCourses 函数修复报告

时间：2026-09-16 15:10

## 1. 问题描述

当前 `clearAllCourses` 函数在清空课程时，除了清空 `courseCache`（用户添加的课程），还把 `useMockDataCache` 设为 false 并写入 storage。这导致 Mock 默认演示数据也被隐藏，课表完全清空。

用户需求是只删除用户手动添加的课程，保留 Mock 默认演示数据。

## 2. 根因分析

原实现中：
- `courseCache` = `[]` ✅
- `useMockDataCache` = `false` ❌（不应该修改）
- 写入 `STORAGE_KEYS.DEBUG_USE_MOCK_DATA` = `'false'` ❌（不应该写入）

## 3. 修改方案

修改 `clearAllCourses` 函数：
1. 保存 `courseCache` 旧值用于失败回滚
2. 将 `courseCache` 置为空数组
3. 只写入 `STORAGE_KEYS.COURSES` 为空数组字符串
4. 成功则 resolve，失败则回滚并 reject
5. 不再修改 `useMockDataCache`
6. 不再写入 `STORAGE_KEYS.DEBUG_USE_MOCK_DATA`
