# 添加考试「自定义课程」滑动误弹输入法修复报告

时间：2026-09-16 00:49

## 一、修改内容

将「弹出输入法」从 picker 选择动作中解耦，改为用户手动点击输入框才弹出键盘。

### 修改前后对比

| 修改点 | 修改前 | 修改后 |
|--------|--------|--------|
| `onCourseChange` | 选中第 0 项时自动弹键盘 | 仅更新 `selectedCourseIndex` |
| 自定义课程输入入口 | 只读 text 显示 | 可点击 input-wrapper |

## 二、问题原因

`onCourseChange` 在 `e.newSelected === 0` 时直接设置 `keyboardHidden = false`，而 picker 的 onchange 在滚轮滑动选中时即触发，导致滑到「自定义课程」就弹键盘。

## 四、实现逻辑

### 1. onCourseChange 简化

```javascript
// 修改前
onCourseChange(e) {
  this.selectedCourseIndex = e.newSelected
  if (e.newSelected === 0) {
    this.currentInputField = 'course'
    this.keyboardHidden = false
  }
}

// 修改后
onCourseChange(e) {
  this.selectedCourseIndex = e.newSelected
}
```

### 2. 模板改造

将只读 text 替换为可点击 input-wrapper（对齐「考场」写法）：

```html
<!-- 修改前 -->
<text if="{{ selectedCourseIndex === 0 && customCourseName }}" class="custom-course-display">课程名：{{ customCourseName }}</text>

<!-- 修改后 -->
<div if="{{ selectedCourseIndex === 0 }}" class="input-wrapper" @click="onInputFocus('course')">
  <text if="{{ !customCourseName }}" class="placeholder-text">请输入课程名称</text>
  <text class="input-text">{{ customCourseName }}</text>
</div>
```

### 3. 删除不再使用的样式

删除 `.custom-course-display` 样式。

### 4. 保留不变的部分

- `onInputFocus('course')` 逻辑
- `onKeyboardInput` 的 `'course'` 分支
- `onKeyboardDelete` 的 `'course'` 分支
