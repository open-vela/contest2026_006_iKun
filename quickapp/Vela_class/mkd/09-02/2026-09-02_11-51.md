## 四、parseDateTime安全分析

### 修改前

```javascript
export function parseDateTime(dateTimeStr) {
  return new Date(dateTimeStr)
}
```

### 修改后

```javascript
export function parseDateTime(dateTimeStr) {
  if (!dateTimeStr) {
    return null
  }
  const date = new Date(dateTimeStr)
  if (isNaN(date.getTime())) {
    return null
  }
  return date
}
```

### 安全检查点

| 输入 | 修改前 | 修改后 |
|------|--------|--------|
| undefined | Invalid Date | null |
| null | Invalid Date | null |
| "" | Invalid Date | null |
| "abc" | Invalid Date | null |
| "2026-09-01" | 正常 Date | 正常 Date |
