## 二、parseDateTime调用检查

### 调用点分析

| 文件 | 调用次数 | 安全性 |
|------|----------|--------|
| task.js | 8次 | 基本安全 |
| exam.js | 12次 | 安全 |
| time.js | 1次（定义） | - |

### task.js 调用分析

```javascript
// 第24-26行：filter 和 sort 中使用
const deadline = parseDateTime(t.deadline)
return deadline < now  // null < now 返回 false，安全
```

```javascript
// 第38-41行：isToday 中使用
const deadline = parseDateTime(t.deadline)
return isToday(deadline, now) && deadline >= now
```

**风险点**：如果 `deadline` 是 null，`isToday(null, now)` 会报错，因为 `null.getFullYear()` 会抛出异常。

### exam.js 调用分析

```javascript
// 使用模板字符串构建日期
const examEnd = parseDateTime(`${e.date}T${e.endTime}:00`)
return examEnd > now  // null > now 返回 false，安全
```

**安全性**：exam.js 中的调用基本安全，因为：
1. 使用模板字符串，即使字段缺失也会生成字符串
2. parseDateTime 返回 null 时，比较操作返回 false

## 三、发现的问题

### 问题1：isToday 函数没有 null 检查

```javascript
export function isToday(date, now) {
  return date.getFullYear() === now.getFullYear() &&  // 如果 date 是 null 会报错
    date.getMonth() === now.getMonth() &&
    date.getDate() === now.getDate()
}
```

**影响**：如果任务的 deadline 是 null，调用 isToday 会导致崩溃。

### 问题2：course-add 缺少字段校验

```javascript
saveCourse() {
  if (this.weeks.length === 0) {
    this.showError('请选择有效的上课周次')
    return
  }
  // 缺少对 name, teacher, classroom, startTime, endTime 的校验
  const courseData = {
    name: this.name,        // 可能为空
    teacher: this.teacher,  // 可能为空
    classroom: this.classroom,  // 可能为空
    weekday: this.selectedWeekday,
    startTime: this.startTime,  // 可能为空
    endTime: this.endTime,      // 可能为空
    weeks: this.weeks
  }
}
```
