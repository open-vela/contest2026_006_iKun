# 默认演示数据开关开发报告

时间：2026-09-07 10:57

## 一、功能目的

在 Debug 页面增加一个开关，用于控制是否启用默认演示数据，方便调试和比赛展示。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 添加 debug_use_mock_data 配置读写逻辑 |
| `src/pages/debug/debug.ux` | 添加默认演示数据开关 |

## 三、Switch组件实现

### 官方 switch 组件

```html
<switch class="setting-switch" checked="{{ useMockData }}" onchange="onMockDataChange"></switch>
```

### 绑定逻辑

```javascript
onMockDataChange(e) {
  const newValue = e.checked
  setUseMockData(newValue)
    .then(() => {
      this.useMockData = newValue
      prompt.showToast({
        message: newValue ? '已开启默认演示数据' : '已关闭默认演示数据',
        duration: 2000
      })
    })
    .catch((err) => {
      this.useMockData = !newValue // 回滚
    })
}
```

## 四、数据读取逻辑

### 开关状态控制

```javascript
// 获取课程数据
export function getCourses() {
  if (useMockDataCache) {
    // 合并默认数据和用户数据，去重
    const userCourseIds = courseCache.map(c => c.id)
    const mockCourses = courses.filter(c => !userCourseIds.includes(c.id))
    return [...mockCourses, ...courseCache]
  }
  return courseCache
}
```

### 数据合并策略

| 状态 | 数据来源 |
|------|----------|
| 开启 | 默认Mock数据 + 用户数据（去重） |
| 关闭 | 仅用户数据 |

### 去重逻辑

```javascript
// 课程
const userCourseIds = courseCache.map(c => c.id)
```

## 七、影响范围

| 影响项 | 说明 |
|--------|------|
| 课程数据 | 根据开关决定是否合并默认课程 |
| 考试数据 | 根据开关决定是否合并默认考试 |
| 任务数据 | 根据开关决定是否合并默认任务 |
| 首页 | 自动使用 getCourses/getExams/getTasks |
| 课表页面 | 自动使用 getCourses |
| 考试页面 | 自动使用 getExams |
| 任务页面 | 自动使用 getTasks |
