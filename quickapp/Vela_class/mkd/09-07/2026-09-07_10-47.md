# 历史考试功能开发报告

时间：2026-09-07 10:47

## 一、功能目的

将已经结束的考试从当前考试列表中分离出来，用户可以查看历史考试详情并删除不需要的历史考试。

| `src/pages/exam-history/exam-history.ux` | 新增历史考试页面 |
| `src/manifest.json` | 添加 exam-history 路由 |

## 四、数据分类逻辑

| 分类 | 条件 | 显示位置 |
|------|------|----------|
| 当前考试 | 考试结束时间 > 当前时间 | 考试页面 |
| 历史考试 | 考试结束时间 <= 当前时间 | 历史考试页面 |

### 分类函数

```javascript
// 当前考试
export function getUpcomingExams(now) {
  const exams = getExams()
  return exams
    .filter(e => {
      const examEnd = parseDateTime(`${e.date}T${e.endTime}:00`)
      return examEnd > now
    })
    .sort(...)
}

// 历史考试
export function getHistoryExams(now) {
  const exams = getExams()
  return exams
    .filter(e => {
      const examEnd = parseDateTime(`${e.date}T${e.endTime}:00`)
      return examEnd <= now
    })
    .sort(...) // 按结束时间倒序
}
```

## 五、页面设计

### 历史考试页面

- 页面标题：历史考试
- 列表显示：考试名称、日期、时间、地点
- 状态标识：已结束
- 空状态：暂无历史考试

### 与当前考试页面的区别

| 特性 | 当前考试 | 历史考试 |
|------|----------|----------|
| 倒计时 | 显示 | 不显示 |
| 状态标识 | 倒计时徽章 | "已结束"徽章 |
| 边框颜色 | 红色 | 灰色 |
| 添加按钮 | 有 | 无 |

## 六、删除流程

历史考试删除复用现有 exam-detail 页面的删除逻辑：

```
点击考试
  ↓
进入 exam-detail 页面
  ↓
点击删除按钮
  ↓
确认弹窗
  ↓
删除 Storage 中的考试
  ↓
返回历史考试页面
  ↓
刷新列表
```
