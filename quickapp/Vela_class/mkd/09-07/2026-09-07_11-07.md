# 默认演示数据隔离修复报告

时间：2026-09-07 11:07

## 一、问题原因

当Storage没有用户数据时，Mock数据直接进入了cache：

```javascript
// 原代码
courseCache = data ? JSON.parse(data) : [...courses]  // Mock数据进入cache
examCache = data ? JSON.parse(data) : [...exams]      // Mock数据进入cache
taskCache = data ? JSON.parse(data) : [...tasks]      // Mock数据进入cache
```

导致：
- 关闭开关后，courseCache 仍包含 Mock 数据
- getCourses() 返回 courseCache 时，Mock 数据仍然显示

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 修改数据初始化逻辑，Mock数据与用户数据分离 |

## 三、数据结构变化

### 修改前

```
Storage读取 → courseCache（可能包含Mock数据）
            ↓
        getCourses()
            ↓
        返回courseCache
```

### 修改后

```
Storage读取 → courseCache（只包含用户数据）
            ↓
        getCourses()
            ↓
        开启：Mock数据 + 用户数据（去重）
        关闭：用户数据
```

## 四、Mock数据读取逻辑

### 初始化逻辑

```javascript
// 修改后
courseCache = data ? JSON.parse(data) : []  // 没有用户数据时为空数组
examCache = data ? JSON.parse(data) : []    // 没有用户数据时为空数组
taskCache = data ? JSON.parse(data) : []    // 没有用户数据时为空数组
```

### 数据读取逻辑

```javascript
export function getCourses() {
  if (useMockDataCache) {
    // 合并默认数据和用户数据，去重
    const userCourseIds = courseCache.map(c => c.id)
    const mockCourses = courses.filter(c => !userCourseIds.includes(c.id))
    return [...mockCourses, ...courseCache]
  }
  return courseCache  // 只返回用户数据
}
```
