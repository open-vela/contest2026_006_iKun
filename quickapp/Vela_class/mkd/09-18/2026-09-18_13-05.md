# 课程详情页添加周次显示报告

时间：2026-09-18 13:05

## 1. 问题描述

course-detail.ux 中显示了课程名称、时间、教室、教师等信息，但缺少周次信息。

## 2. 根因分析

模板中未展示 weeks 字段，需用 formatCourseWeeks 格式化后显示。

## 3. 修改方案

在时间和教室之间插入周次行，loadCourse 中计算 weeksText。

## 4. 修改的文件和行号

| 文件 | 修改内容 |
|------|----------|
| `src/pages/course-detail/course-detail.ux` | 模板：在时间和教室之间插入周次 info-row |
| `src/pages/course-detail/course-detail.ux` | import：增加 formatCourseWeeks |
| `src/pages/course-detail/course-detail.ux` | private：新增 weeksText 字段 |
| `src/pages/course-detail/course-detail.ux` | loadCourse：计算 weeksText |

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| 模板中时间信息和教室信息之间新增了周次 info-row | ✅ |
| import 中增加了 formatCourseWeeks | ✅ |
| private 中新增了 weeksText 字段 | ✅ |
| loadCourse 中计算了 weeksText | ✅ |
| 周次行样式与教室/教师行一致 | ✅ |

## 6. 测试步骤

1. 进入连续周次课程详情（如 1-16 周），周次应显示"1-16周"
2. 进入单周课详情（如工程伦理），周次应显示"1-15周 单周"
3. 进入双周课详情（如周四的习近平），周次应显示"2-16周 双周"
4. 进入分段周次课详情（如形势与政策 9-11 周），周次应显示"9-11周"
5. 确认周次行位于时间和教室之间
