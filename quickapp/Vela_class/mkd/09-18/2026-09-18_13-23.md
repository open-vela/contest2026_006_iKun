# 待办历史功能报告（历史归档 + 天数设置）

时间：2026-09-18 13:23

## 1. 问题描述

当前待办页面只有"待处理 · X项"和"+"添加按钮，已完成待办全部显示在"已完成"区域，无历史归档功能。考试已有 exam-history 历史页面，待办缺少对应能力。

## 2. 根因分析

- task 数据结构只有 finished: boolean，无完成时间记录
- 无历史筛选函数
- 无历史/设置页面

## 3. 修改方案

1. storage.js：新增 taskHistoryDays 存储、修改 updateTaskStatus 记录 finishedAt
2. task.js：新增 getHistoryTasks 函数
3. 新建 task-history.ux：历史待办列表页
4. 新建 task-settings.ux：待办设置页
5. task.ux：操作栏增加"历史"和"设置"按钮
6. manifest.json：新增路由

## 6. 测试步骤

1. **历史归档**：完成一个待办 → 进入 debug 页将默认天数改为 1 天 → 返回待办页 → 点"历史" → 该待办应出现在历史列表

2. **天数设置**：进入待办设置页 → 选择 7 天 → 保存 → 完成一个待办 → 8 天后该待办应出现在历史列表

3. **自定义天数**：进入待办设置页 → 选择"自定义" → 输入 5 → 保存成功

4. **自定义校验**：进入待办设置页 → 选择"自定义" → 输入非数字 → 保存时提示错误

5. **页面跳转**：待办页操作栏应显示"历史"和"设置"蓝色文字按钮 → 点击分别跳转到历史页和设置页

6. **历史列表**：历史待办列表每项应显示标题、截止时间、完成时间

7. **空状态**：历史页空状态应显示"暂无历史待办"

8. **取消完成**：在待办详情页取消完成 → 该待办应从历史列表中消失
