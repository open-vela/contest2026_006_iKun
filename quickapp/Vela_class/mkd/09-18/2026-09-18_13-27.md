# 待办操作栏向中心收拢报告

时间：2026-09-18 13:27

## 1. 问题描述

task.ux 操作栏（action-row）当前宽度 380px，使用 justify-content: space-between 布局，左侧"待处理 · X项"和右侧"历史/设置/+"按钮组分别贴近两端，在 466px 圆形表盘上被表圈遮挡。

## 2. 根因分析

action-row width 380px 在 466px 圆屏上两侧贴边，被表圈遮挡。

## 3. 修改方案

缩小 action-row width 至 300px，向中心收拢 80px（每侧约 40px）。

## 4. 修改的文件和行号

| 文件 | 行号 | 修改内容 |
|------|------|----------|
| `src/pages/task/task.ux` | 157-163 | .action-row width 从 380px 改为 300px |

## 5. 验证结果

| 检查项 | 结果 |
|--------|------|
| action-row width 已改为 300px | ✅ |
| 操作栏内容在圆屏内不被遮挡 | ✅ |
| "历史""设置""+"按钮不重叠 | ✅ |

## 6. 测试步骤

1. 进入待办页，操作栏"待处理 · X项"和"历史""设置"+"按钮应全部在圆屏可见范围内，不被表圈遮挡
2. 确认按钮之间不重叠、不拥挤
