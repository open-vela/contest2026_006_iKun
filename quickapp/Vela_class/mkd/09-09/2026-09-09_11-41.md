# 项目修改报告

时间：2026-09-09 11:41

## 一、问题根因

三个添加页面的自定义输入法（InputMethod）使用绝对定位固定在页面底部（高度321px）。当用户点击底部输入框时：

1. 页面高度466px，滚动容器385px，键盘弹出后仅剩约60px可见区域
2. 原实现使用固定 `scrollBy({ top: 180 })`，不适应不同输入框位置
3. 键盘隐藏后未重置滚动位置，多次打开可能导致滚动累加
4. 步骤切换后未重置滚动位置

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/course-add/course-add.ux` | 替换固定scrollBy为基于getScrollRect的动态计算；增加步骤切换和键盘隐藏时的滚动重置；底部安全区域从80px增至200px |
| `src/pages/exam-add/exam-add.ux` | 同上逻辑；底部安全区域从80px增至200px |
| `src/pages/task-add/task-add.ux` | 同上逻辑；底部安全区域从80px增至200px |

## 三、滚动目标计算

采用 `getScrollRect` 获取实际内容高度和可视区域，动态计算滚动位置：

```javascript
_scrollToField(field) {
  // 1. 根据字段位置估算目标Y坐标
  const fieldOffsets = { name: 0, teacher: 85, classroom: 170 }
  const targetY = fieldOffsets[field] || 0

  // 2. 延迟300ms等待键盘动画完成
  setTimeout(() => {
    el.getScrollRect((rect) => {
      // 3. 计算最大滚动距离
      const maxScroll = rect.scrollHeight - rect.height

      // 4. 限制在合法范围
      let scrollTo = Math.max(0, Math.min(targetY, maxScroll))

      // 5. 使用scrollTo绝对定位
      el.scrollTo({ top: scrollTo, behavior: 'instant' })
    })
  }, 300)
}
```

**各页面字段位置估算：**
- course-add: name(0px), teacher(85px), classroom(170px)
- exam-add: classroom(268px)
- task-add: title(0px)

## 四、键盘显示和隐藏时的状态处理

**显示时：**
- `showKeyboard()` 设置 `keyboardHidden = false`
- 调用 `_scrollToField(field)` 计算并滚动到目标位置
- 使用300ms延迟确保键盘动画完成

**隐藏时：**
- `hideKeyboard()` 设置 `keyboardHidden = true`
- 延迟100ms后调用 `scrollTo({ top: 0 })` 重置到顶部
- `onBackPress()` 中同样处理

**步骤切换时：**
- `nextStep()` 和 `prevStep()` 中延迟50ms后重置滚动到顶部

## 五、底部安全区域确定

- 键盘高度：321px
- 原底部安全区域：80px
- 新底部安全区域：200px

计算依据：确保最后一个输入框（classroom）可以完整滚动到键盘上方可见区域。200px提供了足够的滚动余量，使内容高度超过滚动容器高度，产生实际滚动空间。
