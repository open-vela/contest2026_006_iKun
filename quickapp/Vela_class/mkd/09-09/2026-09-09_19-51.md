# 项目修改报告

时间：2026-09-09 19:51

## 一、修改内容

修复三个添加页面（course-add、exam-add、task-add）中自定义输入法弹出后底部输入框仍被遮挡的问题。

核心改动：将固定偏移量计算改为基于真实布局位置的动态计算。

## 二、问题原因

原实现使用固定的 `fieldBottoms` 字典模拟输入框位置：

```javascript
const fieldBottoms = { name: 85, teacher: 170, classroom: 255 }
```

存在以下问题：
1. 使用固定数字而非真实布局位置
2. 没有获取输入框实际坐标
3. 没有判断输入框是否真的被键盘遮挡
4. 不同步骤、不同屏幕下会失效

## 四、实现逻辑

### 1. 输入框位置获取

为每个输入框添加唯一 id：

```html
<!-- course-add -->
<div id="input-name" class="input-wrapper" @click="showKeyboard('name')">
<div id="input-teacher" class="input-wrapper" @click="showKeyboard('teacher')">
<div id="input-classroom" class="input-wrapper" @click="showKeyboard('classroom')">

<!-- exam-add -->
<div id="input-classroom" class="input-wrapper" @click="showKeyboard('classroom')">

<!-- task-add -->
<div id="input-title" class="input-wrapper" @click="showKeyboard('title')">
```

通过 `$element(id)` 获取真实元素引用，再用 `getBoundingClientRect()` 获取布局信息。

### 2. 键盘遮挡计算

```javascript
// 获取输入框真实位置
inputEl.getBoundingClientRect((inputRect) => {
  const inputBottom = inputRect.bottom
  
  // 键盘弹出后可见区域底部
  const keyboardTop = 466 - 321  // 页面高度 - 键盘高度
  const visibleBottom = keyboardTop - 10  // 10px安全间距
  
  // 判断是否被遮挡
  if (inputBottom > visibleBottom) {
    // 需要滚动
  }
  // 不遮挡则不滚动
})
```

### 3. scrollTop 计算

```javascript
if (inputBottom > visibleBottom) {
  const needScroll = inputBottom - visibleBottom + 10
  let scrollTo = currentScrollTop + needScroll
  
  // 限制在合法范围
  if (scrollTo > maxScroll) scrollTo = maxScroll
  if (scrollTo < 0) scrollTo = 0
  
  scrollEl.scrollTo({ top: scrollTo, behavior: 'instant' })
}
```

基于当前滚动位置（`currentScrollTop`）加上需要的偏移量，而非直接使用字段位置。

### 4. 最大滚动范围处理

通过 `getScrollRect()` 获取：
- `scrollHeight`: 内容总高度
- `height`: 可视区域高度
- `top`: 当前滚动位置

```javascript
const maxScroll = Math.max(0, scrollH - viewH)
```

如果 `maxScroll === 0` 且重试次数 < 3，延迟200ms重试（等待布局完成）。

### 5. 三个页面统一

三个页面使用相同的计算逻辑：
- 通过 `$element(id).getBoundingClientRect()` 获取输入框真实位置
- 通过 `getScrollRect()` 获取滚动容器状态
- 基于键盘位置和输入框位置计算是否需要滚动
- 仅在输入框被遮挡时才滚动
