# 项目修改报告

时间：2026-08-28 19:58

## 一、修改内容

增加开发调试用的 Mock 数据重置功能。

## 二、问题原因

修改 `data.js` 后，Storage 中已存在旧数据，应用仍使用旧缓存，不会自动加载新的默认数据。

## 三、修改文件

- `src/app.ux`

## 四、实现逻辑

### 已有函数
`storage.js` 已有 `resetToMockData()` 函数，功能：
- 将 courseCache、examCache、taskCache 重置为 data.js 中的默认数据
- 保存到 system.storage

### 新增调试入口
在 `app.ux` 的 `onCreate` 中，将 `resetToMockData` 暴露到全局：

```javascript
if (typeof globalThis !== 'undefined') {
  globalThis.resetMockData = function() {
    resetToMockData().then(() => {
      console.log('Mock data reset successfully')
    }).catch((err) => {
      console.error('Failed to reset mock data:', err)
    })
  }
}
```

### 使用方式
在模拟器控制台中执行：
```javascript
resetMockData()
```

即可重置所有数据为默认 Mock 数据。

## 五、测试验证

### 测试步骤：
1. 修改 `src/common/data.js`，新增一门课程
2. 在模拟器控制台执行 `resetMockData()`
3. 重新打开应用
4. 课表页面应显示新课程

### 预期效果：
- 执行重置后，课程、考试、待办数据恢复为 data.js 中的默认值
- 用户手动添加的数据会被清除
- 首页、课表、考试、待办页面显示最新默认数据
