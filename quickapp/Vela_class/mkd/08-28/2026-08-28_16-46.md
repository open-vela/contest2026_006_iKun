# 项目修改报告

时间：2026-08-28 16:46

## 一、修改内容

修复课程详情页面状态显示逻辑，根据进入来源决定是否显示实时状态。

## 二、问题原因

课程详情页无差别调用 `getCourseStatus()`、`getCourseProgress()` 等实时状态计算函数，导致从"本周课表"和"全部课程"进入详情时也显示实时状态信息。

## 三、修改文件

- `src/pages/schedule/schedule.ux`
- `src/pages/course-detail/course-detail.ux`

## 四、实现逻辑

### 1. schedule.ux 传递来源参数

修改 `goToDetail` 函数，增加 `source` 参数：
```javascript
goToDetail(courseId, source) {
  router.push({
    uri: '/pages/course-detail',
    params: {
      courseId: courseId,
      source: source || 'today'
    }
  })
}
```

不同模式传递不同 source：
- 今日模式：`onclick="goToDetail($item.id, 'today')"`
- 本周模式：`onclick="goToDetail($item.id, 'week')"`
- 全部模式：`onclick="goToDetail($item.id, 'all')"`

### 2. course-detail.ux 根据来源控制状态显示

**新增 protected 参数**：
```javascript
protected: {
  courseId: '',
  source: 'today'
}
```

**新增 private 状态**：
```javascript
showStatus: true
```

**onInit 中判断**：
```javascript
this.showStatus = this.source === 'today'
```

**loadCourse 中条件计算**：
```javascript
if (this.showStatus) {
  this.status = getCourseStatus(this.course, now)
  // ... 计算实时状态
}
```

**模板中条件显示**：
```html
<div if="{{ showStatus && status === 'ongoing' }}" class="status-section">
  ...
</div>
```

### 3. 状态逻辑
- `source === 'today'`：计算并显示实时状态（即将开始/进行中/已结束）
- `source === 'week'` 或 `'all'`：只显示课程基础信息，不显示状态区域
