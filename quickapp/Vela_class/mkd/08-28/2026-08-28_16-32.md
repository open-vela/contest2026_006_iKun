# 项目修改报告

时间：2026-08-28 16:32

## 一、修改内容

修复本周课表非当天课程错误显示实时状态的问题。

## 二、问题原因

`loadWeekCourses()` 函数使用当前时间 `now` 计算所有课程的状态，导致非当天课程也显示"还有X分钟开始"、"正在进行"等实时状态。

## 三、修改文件

- `src/pages/schedule/schedule.ux`

## 四、实现逻辑

**修改前**：
```javascript
loadWeekCourses(now) {
  const courses = getCoursesByWeekday(this.selectedDay, this.selectedWeek)
  this.weekCourses = courses.map(c => ({
    ...c,
    status: getCourseStatus(c, now)
  }))
}
```

**修改后**：
```javascript
loadWeekCourses(now) {
  const courses = getCoursesByWeekday(this.selectedDay, this.selectedWeek)
  const isToday = this.selectedWeek === this.currentWeek && this.selectedDay === getWeekdayNumber(now)

  this.weekCourses = courses.map(c => ({
    ...c,
    status: isToday ? getCourseStatus(c, now) : 'upcoming'
  }))
}
```

**判断逻辑**：
- 只有当 `selectedWeek === currentWeek` 且 `selectedDay === 当前星期` 时，才计算实时状态
- 否则统一显示为 `upcoming`（未开始），不显示实时状态
