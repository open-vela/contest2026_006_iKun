# 项目修改报告

时间：2026-08-26 15:43

## 一、修改内容

修复课程详情页无法显示手动添加课程的问题。

## 二、问题原因

课程详情页直接从静态 `data.js` 导入课程数据：
```javascript
import { courses } from '../../common/data'
this.course = courses.find(c => c.id === this.courseId)
```

而手动添加的课程保存在 `storage` 的 `courseCache` 中，不在静态 `data.js` 里，导致找不到动态 ID 的课程。

## 三、修改文件

- `src/pages/course-detail/course-detail.ux`

## 四、实现逻辑

### 修改前
```javascript
import { courses } from '../../common/data'
// ...
this.course = courses.find(c => c.id === this.courseId)
```

### 修改后
```javascript
import { getCourses, ensureStorageReady } from '../../common/storage'
// ...
onInit() {
  ensureStorageReady()
    .then(() => {
      this.loadCourse()
    })
}

loadCourse() {
  // 从统一课程缓存中查找课程
  this.course = getCourses().find(c => c.id === this.courseId)
}
```

### 数据流统一
```
storage → courseCache → getCourses() → course-detail
```

默认课程和手动新增课程都从同一个缓存读取。

## 五、测试验证

### 测试步骤：
1. 点击默认 mock 课程（如数据结构）→ 详情页正常显示
2. 手动添加新课程 → 保存成功
3. 在课表页面点击新课程 → 详情页正常显示课程信息
4. 退出应用重新进入 → 手动添加的课程详情仍可查看

### 预期效果：
- 默认课程和手动课程都能正常显示详情
- 不存在"课程不存在"错误

## 六、后续建议

1. 其他使用静态 `courses` 的页面也应检查是否需要改为统一数据源
