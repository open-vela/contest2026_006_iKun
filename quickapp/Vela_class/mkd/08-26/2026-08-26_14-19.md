### 使用官方 picker 实现时间选择
```html
<picker class="time-picker" type="time" selected="{{ startTime }}" onchange="onStartTimeChange">
  <text class="picker-text">{{ startTime || '选择时间' }}</text>
</picker>
```

事件处理：
```javascript
onStartTimeChange(e) {
  const hour = String(e.hour).padStart(2, '0')
  const minute = String(e.minute).padStart(2, '0')
  this.startTime = `${hour}:${minute}`
}
```

### 周次选择改造

**上课频率按钮**：
- 每周 (all)
- 单周 (odd)
- 双周 (even)

**开始周/结束周**：
- 使用官方 picker type="text"
- 范围：第1周 到 第16周
- 默认：第1周 到 第16周

**weeks 生成规则**：
```javascript
generateWeeks() {
  const startWeek = this.startWeekIndex + 1
  const endWeek = this.endWeekIndex + 1
  
  for (let i = startWeek; i <= endWeek; i++) {
    if (this.weekType === 'all') {
      weeks.push(i)  // 每周
    } else if (this.weekType === 'odd' && i % 2 === 1) {
      weeks.push(i)  // 单周：奇数周
    } else if (this.weekType === 'even' && i % 2 === 0) {
      weeks.push(i)  // 双周：偶数周
    }
  }
}
```

**示例**：
- 每周，第3-8周 → [3,4,5,6,7,8]
- 单周，第3-15周 → [3,5,7,9,11,13,15]
- 双周，第4-16周 → [4,6,8,10,12,14,16]
