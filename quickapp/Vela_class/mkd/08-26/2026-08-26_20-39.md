# 项目修改报告

时间：2026-08-26 20:39

## 一、修改内容

为考试和待办模块补充添加、详情、删除能力。

## 二、问题原因

- 考试模块只有查看功能，无法添加和删除
- 待办模块只有查看和完成状态切换，无法添加和删除

## 三、修改文件

### storage.js 新增接口

**考试相关**：
- `addExam(examData)` - 添加考试
- `isUserCreatedExam(examId)` - 判断是否用户添加的考试
- `deleteExam(examId)` - 删除考试

**待办相关**：
- `addTask(taskData)` - 添加待办
- `isUserCreatedTask(taskId)` - 判断是否用户添加的待办
- `deleteTask(taskId)` - 删除待办

### 新增页面

- `src/pages/exam-add/exam-add.ux` - 考试添加页面
- `src/pages/exam-detail/exam-detail.ux` - 考试详情页面
- `src/pages/task-add/task-add.ux` - 待办添加页面

### 修改页面

- `src/pages/exam/exam.ux` - 添加"+"入口和点击跳转
- `src/pages/task/task.ux` - 添加"+"入口和点击跳转
- `src/pages/task-detail/task-detail.ux` - 添加删除功能
- `src/manifest.json` - 添加新页面路由

## 四、实现逻辑

### 考试添加流程
1. 从 `getCourses()` 获取课程列表作为 Picker 选项
2. 生成未来 180 天日期选项
3. 使用官方 `picker type="time"` 选择时间
4. 考场使用 InputMethod 中文输入
5. 调用 `addExam()` 保存

### 待办添加流程
1. 任务名称使用 InputMethod 中文输入
2. 关联课程使用官方 Picker
3. 任务类型使用官方 Picker（实验/作业/报告/其他）
4. 截止日期使用官方 Picker
5. 截止时间使用官方 Picker
6. 调用 `addTask()` 保存，默认 `finished: false`

### 删除功能
- 只有用户添加的项目显示删除按钮
- 默认 Mock 数据不显示删除入口
- 删除前二次确认
- 删除成功后返回列表
- Storage 失败时回滚

### 数据流
```
考试：examCache ↔ @system.storage ↔ 考试列表/详情/首页
待办：taskCache ↔ @system.storage ↔ 待办列表/详情/首页
```

## 五、测试验证

### 考试测试：
1. 考试页面点击"+"进入添加页面
2. 选择课程、日期、时间、输入考场
3. 保存后返回列表显示新考试
4. 点击考试进入详情
5. 用户考试显示删除按钮
6. 默认考试不显示删除按钮

### 待办测试：
1. 待办页面点击"+"进入添加页面
2. 输入任务名称、选择课程、类型、截止时间
3. 保存后返回列表显示新待办
4. 点击待办进入详情
5. 标记完成/取消完成正常
6. 用户待办显示删除按钮
7. 默认待办不显示删除按钮
