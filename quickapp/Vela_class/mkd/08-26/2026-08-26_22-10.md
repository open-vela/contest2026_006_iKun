# 项目修改报告

时间：2026-08-26 22:10

## 一、修改内容

修复考试添加页面允许添加已过去考试的问题。

## 二、问题原因

- 默认日期 `selectedDateIndex: 0` 表示今天，用户可能添加今天已过去的考试
- 保存前没有校验考试开始时间是否晚于当前时间
- 添加成功后考试列表使用 `getUpcomingExams()` 只显示未来考试，导致新添加的考试"消失"

## 三、修改文件

- `src/pages/exam-add/exam-add.ux`

## 四、实现逻辑

### 1. 默认日期改为明天
```javascript
selectedDateIndex: 1  // 默认选择明天
```
避免用户在下午/晚上进入页面时默认生成非法的"今天上午考试"。

### 2. 保存前增加未来时间校验
```javascript
// 校验考试开始时间必须晚于当前时间
const examDateStr = this.dateValueRange[this.selectedDateIndex]
const examStartDateTime = new Date(`${examDateStr}T${this.startTime}:00`)
const now = getNow()

if (examStartDateTime <= now) {
  console.warn('考试时间不能早于当前时间')
  return
}
```

### 3. 校验顺序
1. 是否选择考试课程
2. 考场是否填写
3. 结束时间 > 开始时间
4. **考试开始时间 > 当前时间**（新增）
5. 调用 addExam()

### 4. 统一时间来源
使用 `getNow()` 获取当前时间，与考试列表 `getUpcomingExams(now)` 使用同一时间来源。

## 五、测试验证

### 测试步骤：
1. 当前时间 15:00，尝试添加今天 10:00 的考试 → 禁止保存
2. 当前时间 15:00，尝试添加今天 18:00 的考试 → 允许保存
3. 尝试添加昨天的考试 → 禁止保存
4. 尝试添加明天的考试 → 允许保存
5. 开始时间 14:00，结束时间 13:00 → 禁止保存

### 预期效果：
- 只有未来考试才允许保存
- 保存成功后考试列表正常显示新考试
