# 项目修改报告

时间：2026-08-26 22:23

## 一、修改内容

统一所有添加页面的输入合法性校验，使用 openvela 官方 `@system.prompt` 的 `prompt.showToast()` 显示错误。

## 二、问题原因

- 校验错误只通过 `console.warn()` 输出，用户看不到
- 部分页面缺少截止时间校验（待办）
- 错误提示方式不统一

## 三、修改文件

- `src/manifest.json`
- `src/pages/course-add/course-add.ux`
- `src/pages/exam-add/exam-add.ux`
- `src/pages/task-add/task-add.ux`

## 四、实现逻辑

### 1. manifest.json 新增 system.prompt
```json
{
  "name": "system.prompt"
}
```

### 2. 统一 showError 函数
每个添加页面都添加：
```javascript
showError(message) {
  prompt.showToast({
    message: message,
    duration: 2000
  })
}
```

### 3. 课程添加校验
- 课程名称为空 → "请输入课程名称"
- 开始/结束时间未选择 → "请选择上课时间"
- 结束时间 <= 开始时间 → "结束时间必须晚于开始时间"
- 无有效周次 → "请选择有效的上课周次"

**注意**：课程不需要"时间必须晚于当前时间"的限制。

### 4. 考试添加校验
- 未选择课程 → "请选择考试课程"
- 未选择时间 → "请选择考试时间"
- 结束时间 <= 开始时间 → "结束时间必须晚于开始时间"
- 考场为空 → "请输入考场"
- 考试开始时间 <= 当前时间 → "考试时间不能早于当前时间"

### 5. 待办添加校验
- 任务名称为空 → "请输入任务名称"
- 截止时间未选择 → "请选择截止时间"
- 截止时间 <= 当前时间 → "截止时间不能早于当前时间"（新增）

### 6. 时间比较
使用 `getNow()` 获取统一时间来源，与 `new Date()` 组合比较：
```javascript
const examStartDateTime = new Date(`${examDateStr}T${this.startTime}:00`)
const now = getNow()
if (examStartDateTime <= now) {
  this.showError('考试时间不能早于当前时间')
  return
}
```
