# 默认数据开关页面刷新修复报告

时间：2026-09-08 10:24

## 一、问题原因

当用户在 Debug 页面改变开关状态后，只有前一个页面的 onShow 会被触发，但其他已经加载过的页面不会自动刷新。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/debug/debug.ux` | 开关状态改变后自动返回前一个页面 |

## 三、刷新机制

### 修改前

```
Debug页面改变开关 → 用户手动返回 → 前一个页面onShow触发
```

### 修改后

```
Debug页面改变开关 → 自动返回前一个页面 → 前一个页面onShow触发
```

### 代码实现

```javascript
onMockDataChange(e) {
  const newValue = e.checked
  setUseMockData(newValue)
    .then(() => {
      this.useMockData = newValue
      prompt.showToast({
        message: newValue ? '已开启默认演示数据' : '已关闭默认演示数据',
        duration: 2000
      })
      // 强制刷新前一个页面
      setTimeout(() => {
        router.back()
      }, 500)
    })
    .catch((err) => {
      console.error('Failed to save mock data setting:', err)
      this.useMockData = !newValue // 回滚
    })
},
```

## 六、后续优化

1. **用户体验**：可考虑在开关改变后显示加载状态
2. **性能优化**：可考虑只刷新受影响的页面，而不是所有页面
