# 项目修改报告
时间：2026-09-08 14:07

## 一、修改内容

修复"关闭默认演示数据后，返回首页再进入 Debug 页面，开关重新变成开启"的问题。

## 二、问题原因

1. **`setUseMockData()` 引用了未声明的 `useMockDataManuallySet`**
   - 第305行：`useMockDataManuallySet = true`
   - 导致 ReferenceError，阻止 `storage.set()` 执行
   - 内存已改变，但持久化未完成

2. **`getUseMockDataFromStorage()` 逻辑错误**
   - 使用 `data !== 'false'` 判断，`null`/`undefined`/`''` 都返回 `true`
   - 读取失败时返回 `true`，覆盖用户设置

3. **Debug 页面 onInit/onShow 异步覆盖**
   - 两者都调用 `loadMockDataSetting()`
   - 保存后 onShow 的异步读取可能覆盖新值

## 三、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 修复 `setUseMockData()`、统一 `getUseMockDataFromStorage()` 与 `syncMockDataSetting()` |
| `src/pages/debug/debug.ux` | 添加 `isSaving`/`isLoading` 标志，防止异步覆盖 |

## 四、实现逻辑

### 1. 修复 `setUseMockData()`

```javascript
export function setUseMockData(useMock) {
  return new Promise((resolve, reject) => {
    const oldValue = useMockDataCache
    
    storage.set({
      key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
      value: String(useMock),
      success: function () {
        // 保存成功后才更新缓存
        useMockDataCache = useMock
        resolve()
      },
      fail: function (data, code) {
        // 保存失败时保持原值
        useMockDataCache = oldValue
        reject(new Error('Failed to save setting'))
      }
    })
  })
}
```

### 2. 统一读取逻辑

```javascript
export function getUseMockDataFromStorage() {
  return syncMockDataSetting()
}
```

`syncMockDataSetting()` 只在明确读取到 `'true'` 或 `'false'` 时更新缓存。

### 3. 防止异步覆盖

```javascript
export default {
  private: {
    isLoading: false,
    isSaving: false
  },
  
  onShow() {
    // 只在非保存状态下刷新
    if (!this.isSaving) {
      this.loadMockDataSetting()
    }
  },
  
  onMockDataChange(e) {
    this.isSaving = true
    const oldValue = this.useMockData
    
    setUseMockData(newValue)
      .then(() => {
        this.useMockData = newValue
        this.isSaving = false
      })
      .catch(() => {
        this.useMockData = oldValue
        this.isSaving = false
      })
  }
}
```
