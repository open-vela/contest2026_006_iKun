# 项目修改报告

时间：2026-09-08 14:57

## 一、修改内容

修复上一轮增加初始化条件渲染后引入的页面布局错位问题。

## 二、问题原因

上一轮新增了无样式外层容器：
```html
<div if="{{ isInitialized }}">
  原来的页面内容
</div>
```

这改变了原有布局层级，原先由 `.page` 控制的纵向排列不再直接作用于模式切换栏和内容区域。

## 三、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/schedule/schedule.ux` | 移除外层 div，将 `isInitialized` 条件直接添加到原有节点 |
| `src/pages/exam/exam.ux` | 移除外层 div，将 `isInitialized` 条件直接添加到原有节点 |
| `src/pages/task/task.ux` | 移除外层 div，将 `isInitialized` 条件直接添加到原有节点 |
| `src/pages/exam-history/exam-history.ux` | 移除外层 div，将 `isInitialized` 条件直接添加到原有节点 |

## 四、实现逻辑

### 1. schedule.ux

```html
<!-- 加载状态 -->
<div if="{{ !isInitialized }}" class="loading-container">
  <text class="loading-text">加载中...</text>
</div>

<!-- 模式切换 + 添加按钮 -->
<div if="{{ isInitialized }}" class="mode-row">
  ...
</div>

<!-- 今日模式 -->
<div if="{{ isInitialized && mode === 'today' }}" class="content">
  ...
</div>

<!-- 本周模式 -->
<div if="{{ isInitialized && mode === 'week' }}" class="content">
  ...
</div>

<!-- 全部模式 -->
<div if="{{ isInitialized && mode === 'all' }}" class="content">
  ...
</div>
```

### 2. exam.ux / task.ux / exam-history.ux

```html
<!-- 加载状态 -->
<div if="{{ !isInitialized }}" class="loading-container">
  <text class="loading-text">加载中...</text>
</div>

<!-- 操作栏 -->
<div if="{{ isInitialized }}" class="action-row">
  ...
</div>

<!-- 可滚动区域 -->
<scroll if="{{ isInitialized }}" class="exam-scroll" ...>
  ...
</scroll>
```
