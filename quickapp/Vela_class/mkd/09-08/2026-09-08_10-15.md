# Debug开关状态同步修复报告

时间：2026-09-08 10:15

## 一、问题原因

Debug页面只在 `onInit()` 时读取一次开关状态，导致：
- 页面重新打开时，读取的是内存缓存状态
- 而不是最新的Storage状态

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 添加 getUseMockDataFromStorage() 函数 |
| `src/pages/debug/debug.ux` | 在 onShow() 中重新读取Storage状态 |

## 三、状态读取逻辑

### 新增函数

```javascript
export function getUseMockDataFromStorage() {
  return new Promise((resolve) => {
    storage.get({
      key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
      success: function (data) {
        const result = data !== 'false' // 默认为true
        useMockDataCache = result // 同步更新缓存
        resolve(result)
      },
      fail: function () {
        resolve(true) // 默认为true
      }
    })
  })
}
```

### Debug页面修改

```javascript
onInit() {
  ensureStorageReady().then(() => {
    this.loadMockDataSetting()
  })
},

onShow() {
  ensureStorageReady().then(() => {
    this.loadMockDataSetting()
  })
},

loadMockDataSetting() {
  getUseMockDataFromStorage().then((value) => {
    this.useMockData = value
  })
},
```

## 四、测试结果

### 测试1：关闭后重新进入

**步骤**：
1. 打开Debug
2. 关闭默认演示数据
3. 返回首页
4. 再进入Debug

**结果**：
- ✅ Switch保持关闭

### 测试2：开启后重新进入

**步骤**：
1. 打开Debug
2. 开启默认演示数据
3. 返回首页
4. 再进入Debug

**结果**：
- ✅ Switch保持开启

### 测试3：关闭模拟器

**步骤**：
1. 设置关闭
2. 关闭模拟器
3. 重新启动

**结果**：
- ✅ 状态保持

### 测试4：数据显示

**结果**：
- ✅ 关闭状态：只显示用户数据
- ✅ 开启状态：Mock数据 + 用户数据

## 五、影响范围

| 影响项 | 说明 |
|--------|------|
| Debug页面 | 每次进入重新读取Storage |
| 开关状态 | 与Storage保持一致 |
| Mock数据逻辑 | 不受影响 |
| 用户数据 | 不受影响 |
