# 项目修改报告

时间：2026-09-08 14:47

## 一、修改内容

修复页面首次进入时出现空白，以及课表先显示第1周再跳到当前周的问题。

## 二、问题原因

1. **exam、task、exam-history 页面**：`private` 中数据初始值为空数组，页面先显示空状态，等异步加载完成后才显示数据。

2. **schedule 页面**：`private` 中 `currentWeek: 1, selectedWeek: 1, selectedDay: 1`，页面先显示第1周和星期一，等异步计算完成后才更新。

3. **所有页面**：没有统一的初始化完成状态，导致页面可见时数据还没有准备完成。

## 四、实现逻辑

### 1. 添加初始化状态

```javascript
private: {
  isInitialized: false,
  // ... 其他数据
}
```

### 2. 模板条件渲染

```html
<!-- 加载状态 -->
<div if="{{ !isInitialized }}" class="loading-container">
  <text class="loading-text">加载中...</text>
</div>

<!-- 主要内容 -->
<div if="{{ isInitialized }}">
  <!-- 页面内容 -->
</div>
```

### 3. onInit 完成后设置状态

```javascript
onInit() {
  ensureStorageReady()
    .then(() => syncMockDataSetting())
    .then(() => refreshData())
    .then(() => {
      this.loadData()
      this.isInitialized = true
    })
    .catch((err) => {
      console.error('Failed to initialize:', err)
      this.isInitialized = true
    })
}
```

### 4. onShow 避免首次重复加载

```javascript
onShow() {
  if (!this.isInitialized) return
  // ... 刷新数据
}
```

### 5. schedule 特殊处理

schedule 页面在初始化完成后才计算 `currentWeek`、`selectedWeek`、`selectedDay`，避免显示第1周和星期一。
