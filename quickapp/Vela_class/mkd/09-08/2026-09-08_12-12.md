# 默认数据状态同步重构报告

时间：2026-09-08 12:12

## 一、问题原因

问题是 `useMockDataCache` 是JS模块内存变量，页面切换或模块重新加载后会重新初始化为 `true`。

之前的解决方案（使用 `useMockDataManuallySet` 标志）不能彻底解决问题，因为 `useMockDataManuallySet` 本身也是内存变量。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 重构状态同步逻辑，使用 Storage 作为唯一真实来源 |

## 三、状态同步流程

### 新增函数

```javascript
/**
 * 同步Mock数据设置状态
 * 从Storage读取最新状态并更新缓存
 * @returns {Promise<boolean>}
 */
export function syncMockDataSetting() {
  return new Promise((resolve) => {
    storage.get({
      key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
      success: function (data) {
        useMockDataCache = data !== 'false' // 默认为true
        console.log('[DEBUG] syncMockDataSetting:', useMockDataCache)
        resolve(useMockDataCache)
      },
      fail: function () {
        useMockDataCache = true
        console.log('[DEBUG] syncMockDataSetting (fail, default true)')
        resolve(true)
      }
    })
  })
}
```

### 修改 refresh 函数

所有 refresh 函数在读取数据前先同步 `useMockDataCache`：

```javascript
export function refreshExamsFromStorage() {
  return new Promise((resolve, reject) => {
    // 先同步Mock数据设置
    syncMockDataSetting().then(() => {
      storage.get({
        key: STORAGE_KEYS.EXAMS,
        success: function (data) {
          // ...
        }
      })
    })
  })
}
```

### 修改 initStorage 函数

移除 `useMockDataManuallySet` 相关代码，简化初始化逻辑：

```javascript
initPromise = new Promise((resolve) => {
  let loaded = 0
  const total = 4 // 课程、考试、任务、学期设置（不再包含Debug配置）
  // ...
})
```
