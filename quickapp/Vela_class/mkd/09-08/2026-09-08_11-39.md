# 默认数据开关缓存同步修复报告

时间：2026-09-08 11:39

## 一、问题原因

从日志分析，问题在于 `initStorage()` 函数在某个时刻被重新调用，从 Storage 读取到旧的 `true` 值，覆盖了 `setUseMockData(false)` 设置的 `false` 值。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 添加 `useMockDataManuallySet` 标志，防止 `initStorage()` 覆盖手动设置的值 |

## 三、缓存同步逻辑

### 新增标志

```javascript
let useMockDataManuallySet = false // 标记是否手动设置过
```

### setUseMockData 函数

```javascript
export function setUseMockData(useMock) {
  return new Promise((resolve, reject) => {
    useMockDataCache = useMock
    useMockDataManuallySet = true // 标记为手动设置
    console.log('[DEBUG] setUseMockData cache updated:', useMockDataCache)
    storage.set({
      key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
      value: String(useMock),
      success: function () {
        console.log('[STORAGE_SET_SUCCESS] key=debug_use_mock_data,value=' + useMock)
        resolve()
      },
      fail: function (data, code) {
        console.error('[STORAGE_SET_FAIL] key=debug_use_mock_data,code=' + code)
        reject(new Error('Failed to save setting'))
      }
    })
  })
}
```

### initStorage 函数

```javascript
// 读取Debug配置
storage.get({
  key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
  success: function (data) {
    // 只有在没有手动设置过的情况下才更新缓存
    if (!useMockDataManuallySet) {
      useMockDataCache = data !== 'false' // 默认为true
    }
    checkComplete()
  },
  fail: function (data, code) {
    if (!useMockDataManuallySet) {
      useMockDataCache = true
    }
    checkComplete()
  }
})
```
