# 默认数据状态同步修复报告

时间：2026-09-08 13:26

## 一、问题原因

1. `syncMockDataSetting()` 在读取失败时强制恢复为 `true`，导致用户关闭开关后状态被恢复
2. 多个地方修改 `useMockDataCache`，导致状态被覆盖

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 修复 `syncMockDataSetting()` 函数，读取失败时保持当前状态 |
| `src/pages/home/home.ux` | 在 onShow 中调用 `syncMockDataSetting()` |
| `src/pages/exam/exam.ux` | 在 onShow 中调用 `syncMockDataSetting()` |
| `src/pages/task/task.ux` | 在 onShow 中调用 `syncMockDataSetting()` |
| `src/pages/schedule/schedule.ux` | 在 onShow 中调用 `syncMockDataSetting()` |
| `src/pages/exam-history/exam-history.ux` | 在 onShow 中调用 `syncMockDataSetting()` |

## 三、修改方案

### 1. 修改 `syncMockDataSetting()` 函数

```javascript
export function syncMockDataSetting() {
  return new Promise((resolve) => {
    storage.get({
      key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
      success: function (data) {
        // 只有明确读取到 'true' 或 'false' 时才更新缓存
        if (data === 'true') {
          useMockDataCache = true
        } else if (data === 'false') {
          useMockDataCache = false
        }
        // 其他情况（空值、异常值）保持当前缓存状态
        resolve(useMockDataCache)
      },
      fail: function () {
        // 读取失败时保持当前状态，不改变用户设置
        resolve(useMockDataCache)
      }
    })
  })
}
```

### 2. 简化 refresh 函数

移除 refresh 函数中的 `syncMockDataSetting()` 调用，改为在页面 onShow 中统一调用。

### 3. 修改页面 onShow 函数

所有页面在调用 refresh 函数前先调用 `syncMockDataSetting()`：

```javascript
onShow() {
  ensureStorageReady()
    .then(() => syncMockDataSetting())
    .then(() => refreshExamsFromStorage())
    .then(() => {
      this.loadExams()
    })
}
```

## 四、状态流转

```
页面显示 (onShow)
  ↓
ensureStorageReady()
  ↓
syncMockDataSetting()  ← 从 Storage 同步状态
  ↓
useMockDataCache 更新（只有明确的 'true'/'false' 才更新）
  ↓
refresh 函数读取数据
  ↓
getCourses/getExams/getTasks 使用最新状态
```
