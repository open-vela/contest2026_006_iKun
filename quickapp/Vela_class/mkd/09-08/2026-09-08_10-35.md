# Debug开关页面跳转修复报告

时间：2026-09-08 10:35

## 一、问题原因

原代码在开关切换后会自动调用 `router.back()` 返回上一页，导致用户无法在 Debug 页面连续操作。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/debug/debug.ux` | 删除开关切换后的自动返回逻辑 |

## 三、修改内容

### 修改前

```javascript
onMockDataChange(e) {
  const newValue = e.checked
  setUseMockData(newValue)
    .then(() => {
      this.useMockData = newValue
      prompt.showToast({
        message: newValue ? '已开启默认演示数据' : '已关闭默认演示数据',
        duration: 2000
      })
      // 强制刷新前一个页面
      setTimeout(() => {
        router.back()
      }, 500)
    })
}
```

### 修改后

```javascript
onMockDataChange(e) {
  const newValue = e.checked
  setUseMockData(newValue)
    .then(() => {
      this.useMockData = newValue
      prompt.showToast({
        message: newValue ? '已开启默认演示数据' : '已关闭默认演示数据',
        duration: 2000
      })
    })
}
```

## 四、测试结果

### 测试1：关闭默认数据

**步骤**：
1. 首页进入Debug
2. 关闭默认演示数据

**结果**：
- ✅ Debug页面保持显示
- ✅ Switch变为关闭
- ✅ 不自动返回首页

### 测试2：开启默认数据

**步骤**：
1. Debug页面开启默认演示数据

**结果**：
- ✅ Debug页面保持显示
- ✅ Switch变为开启
- ✅ 不自动返回首页

### 测试3：数据刷新

**步骤**：
1. 关闭默认演示数据
2. 手动返回首页

**结果**：
- ✅ 首页数据按照开关状态显示

### 测试4：重新进入Debug

**步骤**：
1. 切换开关后退出Debug
2. 再次进入

**结果**：
- ✅ Switch状态与Storage一致

## 五、影响范围

| 影响项 | 说明 |
|--------|------|
| Debug页面 | 开关切换后不再自动返回 |
| 开关状态 | 正常保存到Storage |
| 数据逻辑 | 不受影响 |
