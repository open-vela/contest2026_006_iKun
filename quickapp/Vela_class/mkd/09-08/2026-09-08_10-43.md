# 首页默认数据刷新修复报告

时间：2026-09-08 10:43

## 一、问题原因

`refreshExamsFromStorage()`、`refreshTasksFromStorage()`、`refreshCoursesFromStorage()` 函数在没有用户数据时仍然会使用 Mock 数据作为默认值，导致：
- 即使关闭了默认演示数据，刷新缓存后仍然包含 Mock 数据
- getCourses()、getExams()、getTasks() 返回的数据不正确

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | 修改 refresh 函数，没有数据时使用空数组 |

## 三、首页刷新流程

### 修改前

```
onShow()
  ↓
refreshExamsFromStorage() → 没有数据时使用 [...exams]
  ↓
examCache = Mock数据
  ↓
getExams() 检查 useMockDataCache
  ↓
即使 useMockDataCache = false，examCache 仍包含 Mock数据
```

### 修改后

```
onShow()
  ↓
refreshExamsFromStorage() → 没有数据时使用 []
  ↓
examCache = 空数组
  ↓
getExams() 检查 useMockDataCache
  ↓
useMockDataCache = false 时，只返回用户数据（空数组）
useMockDataCache = true 时，返回 Mock数据 + 用户数据
```

## 四、修改内容

### refreshExamsFromStorage()

```javascript
// 修改前
const parsed = data ? JSON.parse(data) : [...exams]

// 修改后
const parsed = data ? JSON.parse(data) : []  // Mock数据在getExams()中动态合并
```

### refreshTasksFromStorage()

```javascript
// 修改前
const parsed = data ? JSON.parse(data) : [...tasks]

// 修改后
const parsed = data ? JSON.parse(data) : []  // Mock数据在getTasks()中动态合并
```

### refreshCoursesFromStorage()

```javascript
// 修改前
const parsed = data ? JSON.parse(data) : [...courses]

// 修改后
const parsed = data ? JSON.parse(data) : []  // Mock数据在getCourses()中动态合并
```
