# 项目修改报告

时间：2026-09-08 14:25

## 一、修改内容

修复"关闭默认演示数据后，进入首页、课程、考试、待办等页面时，Mock 数据会先闪现再消失"的问题。

## 二、问题原因

1. `initStorage()` 只读取课程、考试、任务、学期设置，没有读取 `debug_use_mock_data`
2. `useMockDataCache` 默认为 `true`，导致首次渲染时显示 Mock 数据
3. 各页面 `onInit()` 在 `ensureStorageReady()` 后直接调用 load 函数，没有先同步 Mock 设置
4. `onShow()` 中的 `syncMockDataSetting()` 是异步的，完成前页面已经渲染

## 三、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/common/storage.js` | `initStorage()` 增加读取 `debug_use_mock_data`，纳入初始化完成条件 |
| `src/pages/home/home.ux` | `onInit()` 在 `ensureStorageReady()` 后先调用 `syncMockDataSetting()` |
| `src/pages/exam/exam.ux` | `onInit()` 在 `ensureStorageReady()` 后先调用 `syncMockDataSetting()` |
| `src/pages/task/task.ux` | `onInit()` 在 `ensureStorageReady()` 后先调用 `syncMockDataSetting()` |
| `src/pages/exam-history/exam-history.ux` | `onInit()` 在 `ensureStorageReady()` 后先调用 `syncMockDataSetting()` |
| `src/pages/schedule/schedule.ux` | `onInit()` 改为等待 Storage 和 Mock 设置完成后再调用 load 函数 |

## 四、实现逻辑

### 1. `initStorage()` 增加 Mock 设置读取

```javascript
initPromise = new Promise((resolve) => {
  let loaded = 0
  const total = 5 // Mock设置、课程、考试、任务、学期设置

  // 读取Mock数据设置（必须在课程、考试、任务之前完成）
  storage.get({
    key: STORAGE_KEYS.DEBUG_USE_MOCK_DATA,
    success: function (data) {
      if (data === 'true') {
        useMockDataCache = true
      } else if (data === 'false') {
        useMockDataCache = false
      }
      checkComplete()
    },
    fail: function () {
      checkComplete()
    }
  })

  // 读取课程、考试、任务、学期设置...
})
```

### 2. 各页面 `onInit()` 修改

```javascript
// 修改前
onInit() {
  ensureStorageReady()
    .then(() => refreshExamsFromStorage())
    .then(() => this.loadExams())
}

// 修改后
onInit() {
  ensureStorageReady()
    .then(() => syncMockDataSetting())
    .then(() => refreshExamsFromStorage())
    .then(() => this.loadExams())
}
```

### 3. schedule 页面特殊处理

```javascript
// 修改前
onInit() {
  const now = getNow(DEBUG_NOW)
  this.loadTodayCourses(now)
  this.loadWeekCourses(now)
  this.loadAllCourses()
}

// 修改后
onInit() {
  ensureStorageReady()
    .then(() => syncMockDataSetting())
    .then(() => Promise.all([
      refreshCoursesFromStorage(),
      refreshSemesterStartFromStorage()
    ]))
    .then(() => {
      const now = getNow(DEBUG_NOW)
      this.loadTodayCourses(now)
      this.loadWeekCourses(now)
      this.loadAllCourses()
    })
}
```
