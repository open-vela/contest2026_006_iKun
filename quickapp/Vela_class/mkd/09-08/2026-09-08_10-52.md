# 首页默认数据刷新问题修复报告

时间：2026-09-08 10:52

## 一、问题原因

当没有考试数据时，`updateStaticSummary` 函数没有重置 `examCountdown` 变量，导致首页仍然显示旧的考试倒计时数据。

## 二、修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/pages/home/home.ux` | 在 updateStaticSummary 中重置 examCountdown |

## 三、首页刷新流程

### 修改前

```javascript
if (nearestExam) {
  this.examCountdown = getExamCountdown(nearestExam, now)
}
// 没有考试时，examCountdown 保持旧值
```

### 修改后

```javascript
if (nearestExam) {
  this.examCountdown = getExamCountdown(nearestExam, now)
} else {
  // 没有考试时重置
  this.examCountdown = { value: 0, unit: '', status: '', isOngoing: false, remainingMinutes: 0 }
}
```

## 四、异步处理逻辑

首页 onShow 的异步流程是正确的：

```javascript
onShow() {
  ensureStorageReady()
    .then(() => Promise.all([
      refreshExamsFromStorage(),
      refreshTasksFromStorage(),
      refreshCoursesFromStorage()
    ]))
    .then(() => {
      this.updateTime()
      this.updateStaticSummary()  // 在所有 refresh 完成后调用
      this.updateCourseStatus()
      this.startTimers()
    })
}
```
