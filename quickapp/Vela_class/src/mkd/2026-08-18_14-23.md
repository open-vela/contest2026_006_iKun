## 3. 边缘滑动返回修复

### TouchEvent 使用方式
- touchstart: `event.touches[0].clientX`, `event.touches[0].clientY`
- touchmove: `event.touches[0].clientX`, `event.touches[0].clientY`
- touchend: `event.changedTouches[0].clientX`, `event.changedTouches[0].clientY`
- 包含空值保护：检查 `event.touches` 和 `event.changedTouches` 是否存在

### touchstart 逻辑
- 读取 startX, startY
- 判断 `startX <= EDGE_THRESHOLD`（35px）
- 设置 `edgeCandidate` 状态
- 只有边缘候选才可能触发返回

### touchmove 逻辑
- 只记录 lastX, lastY
- **绝对不调用 router.back()**
- 检查反向滑动（deltaX < -20 取消候选）
- 检查纵向移动过大（abs(deltaY) > abs(deltaX) * 2 且 > 30px 取消候选）

### touchend 逻辑
- 读取 endX, endY（从 changedTouches）
- 计算 deltaX, deltaY
- 必须同时满足全部条件才触发返回

### 实际阈值
- EDGE_THRESHOLD = 35px（左边缘区域）
- MIN_SWIPE_DISTANCE = 100px（最小滑动距离）
- MAX_VERTICAL_DISTANCE = 60px（最大纵向偏移）
- DIRECTION_RATIO = 1.5（横向/纵向比例）

## 5. 防误触措施

### 左边缘限制
- 只有 startX <= 35px 才视为边缘候选
- 超过此区域的触摸永远不能触发返回

### 防止点击误触
- MIN_SWIPE_DISTANCE = 100px，必须滑动足够距离
- 点击时手指的轻微位移（通常 < 10px）不会触发

### 防止纵向滚动误触
- MAX_VERTICAL_DISTANCE = 60px，纵向偏移超过此值不触发
- DIRECTION_RATIO = 1.5，横向移动必须明显大于纵向
- touchmove 中检测到明显纵向移动会取消候选

### 一次手势只返回一次
- gestureTriggered 标志位
- 触发后设置为 true
- 新的 touchstart 时重置
