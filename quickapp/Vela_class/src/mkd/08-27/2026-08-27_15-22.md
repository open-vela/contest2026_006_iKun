# 项目修改报告

## 一、修改内容

修复主页"下一节课"倒计时计算错误的问题。

## 二、问题原因

**根本原因**：`nextCourse` 分支调用了错误的函数 `getCourseRemainingTime()`，该函数计算的是距离课程**结束**的时间，而不是距离课程**开始**的时间。

**示例**：
- 当前时间：15:18
- 课程：16:00 - 17:40
- `getCourseRemainingTime()` 计算：15:18 → 17:40 = 约141分钟
- 正确应使用 `getMinutesUntilStart()`：15:18 → 16:00 = 约42分钟

## 四、实现逻辑

### 1. 添加导入
在 import 中添加 `getMinutesUntilStart`：
```javascript
import { getCurrentCourse, getNextCourse, getNextCourseAcrossDays, getCourseProgress, getCourseRemainingTime, getMinutesUntilStart, getTodayCourses, isTodayCoursesFinished } from '../../common/schedule'
```

### 2. 修改 nextCourse 分支
**修改前**：
```javascript
} else if (nextCourse) {
  this.status = 'next'
  this.mainCardClass = 'main-card-blue'
  this.nextCourse = nextCourse
  const minutes = getCourseRemainingTime(nextCourse, now)
  this.countdownText = `还有 ${minutes} 分钟`
}
```

**修改后**：
```javascript
} else if (nextCourse) {
  this.status = 'next'
  this.mainCardClass = 'main-card-blue'
  this.nextCourse = nextCourse
  const minutes = getMinutesUntilStart(nextCourse, now)
  this.countdownText = `还有 ${minutes} 分钟`
}
```

### 3. 保留 currentCourse 分支
正在上课的状态继续使用 `getCourseRemainingTime()`：
```javascript
if (currentCourse) {
  this.remainingMinutes = getCourseRemainingTime(currentCourse, now)
  // ...
}
```
