## 2. 今天模式周次显示

- 使用 `currentWeek` 显示
- UI 文案格式：`第3周 · 周二 · 共2节`
- 使用横向容器 + 两个并列 `<text>` 避免嵌套问题
- 第3周使用蓝色 #4FA3FF，后面文字使用 #8F8F8F

## 3. 本周周次选择

- 新增 `selectedWeek` 变量，初始化为 `currentWeek`（第3周）
- `currentWeek` 保持不变，始终表示当前实际教学周
- `selectedWeek` 表示用户正在查看的教学周
- 周次范围：第1周 ～ 第16周
- 上一周逻辑：`selectedWeek > 1` 时可切换
- 下一周逻辑：`selectedWeek < 16` 时可切换
- 显示格式：`‹ 第3周 ›`，边界时箭头降低透明度
- 当 `selectedWeek === currentWeek` 时显示"本周"标记

## 4. 星期日期

- weekDays 新增 `date` 字段存储日期数字
- 日期计算方式：
  1. 根据当前日期计算当前周的星期一
  2. 根据 `weekOffset = selectedWeek - currentWeek` 计算目标周星期一
  3. 依次加0-6天得到周一到周日的日期
- 使用 JavaScript Date 对象自动处理跨月
- 当前日期标记：只有 `selectedWeek === currentWeek` 时才标记 isToday
- 星期按钮调整为两行：星期文字 + 日期数字

## 5. 课程过滤

- 本周模式：使用 `selectedWeek` 过滤课程
- 今天模式：继续使用 `currentWeek` 过滤课程
- 全部模式：保持不变，不受周次限制
- 切换 `selectedWeek` 时保持 `selectedDay` 不变
