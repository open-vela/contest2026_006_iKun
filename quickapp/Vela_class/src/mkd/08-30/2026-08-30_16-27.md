# 项目修改报告

时间：2026-08-30 16:27

## 一、修改内容

修复"学期第一周之前日期被错误显示为第1周"的问题。

## 二、问题原因

`calculateCurrentWeek()` 函数中使用了 `Math.max(1, weekNumber)`，导致第一周之前的日期（weekNumber 为 0 或负数）被强制转换为第1周。

## 三、修改文件

- `src/common/schedule.js`
- `src/pages/schedule/schedule.ux`

## 四、实现逻辑

### 1. 修改 calculateCurrentWeek 函数

**修改前**：
```javascript
return Math.max(1, weekNumber)
```

**修改后**：
```javascript
if (weekNumber < 1) {
  return 0  // 0 表示学期开始前
}
return weekNumber
```

### 2. 课表页面处理 currentWeek = 0 的情况

**今日模式标题**：
```html
<text class="week-number">{{ currentWeek > 0 ? '第' + currentWeek + '周' : '学期未开始' }}</text>
```

**本周模式周次选择器**：
```html
<text class="week-number">{{ selectedWeek > 0 ? '第' + selectedWeek + '周' : '学期未开始' }}</text>
```

**本周模式摘要**：
```html
<text class="week-summary-text">{{ selectedWeek > 0 ? '第' + selectedWeek + '周' : '学期未开始' }} · {{ weekDayTitle }} · {{ weekCourses.length }}节课</text>
```

### 3. 周次选择器边界处理

- 当 `selectedWeek = 0` 时，左箭头禁用（`selectedWeek <= 1`）
- 当 `selectedWeek < 1` 时，右箭头不能点击（`selectedWeek > 0`）

### 4. 课程过滤逻辑

当 `currentWeek = 0` 时：
- `getTodayCourses(now, 0)` 不会匹配 `weeks.includes(0)`
- 因此不会错误显示第1周的课程
