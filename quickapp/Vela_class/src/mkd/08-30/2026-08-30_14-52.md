# 项目修改报告

时间：2026-08-30 14:52

## 一、修改内容

实现"学期第一周"设置功能，允许用户自定义教学周计算基准。

## 二、问题原因

原项目使用固定的默认第一周，无法适应不同学校、不同学期的开学日期，导致教学周显示错误。

## 四、实现逻辑

### 1. storage.js - 存储学期设置

- `initStorage()` 中读取学期设置
- 导出 `getSemesterWeek1Start()` 和 `setSemesterWeek1Start()`

### 2. schedule.js - 教学周计算
新增公共函数：
```javascript
export function calculateCurrentWeek(now) {
  const week1Monday = getWeek1Monday()
  if (!week1Monday) return 1 // 未设置时默认第1周

  const currentMonday = getMondayOfWeek(now)
  const diffTime = currentMonday.getTime() - week1Monday.getTime()
  const diffDays = Math.floor(diffTime / (1000 * 60 * 60 * 24))
  const weekNumber = Math.floor(diffDays / 7) + 1

  return Math.max(1, weekNumber) // 不返回负数或0
}
```

修改所有需要 `currentWeek` 参数的函数，不传参数时自动调用 `calculateCurrentWeek(now)`。

### 3. schedule-settings.ux - 设置页面
- 日期选择器：过去30天到未来120天
- 选择日期后自动计算所在周的周一
- 显示"第一周：X月X日 - X月X日"
- 保存到 Storage

### 4. schedule.ux - 课表页面
- 标题栏右侧添加设置入口（⚙图标）
- `currentWeek` 使用 `calculateCurrentWeek(now)` 计算
- `onShow()` 时重新计算 currentWeek

### 5. 计算逻辑
用户选择任意日期 → 计算该日期所在周的周一 → 保存为 `semesterWeek1Start`

教学周计算：`floor((当前日期 - semesterWeek1Start) / 7) + 1`
