## 2. 第几周显示修复

### 原来的问题
本周模式下，界面只显示"周二 · 2节课"，没有显示"第3周"。

### 原来的嵌套 text 结构
```html
<text class="sub-title">
  <text class="week-number">第{{ currentWeek }}周</text>
  · {{ weekDayTitle }} · {{ weekCourses.length }}节课
</text>
```
OpenVela 中 `<text>` 嵌套 `<text>` 会导致内部文本不显示。

### 修改后的并列 text 结构
```html
<div class="week-summary">
  <text class="week-number">第{{ currentWeek }}周</text>
  <text class="week-summary-text"> · {{ weekDayTitle }} · {{ weekCourses.length }}节课</text>
</div>
```
使用 `<div>` 作为容器，内部两个 `<text>` 并列显示。

### currentWeek 逻辑
保持不变，仍使用 `DEBUG_CURRENT_WEEK = 3`。
