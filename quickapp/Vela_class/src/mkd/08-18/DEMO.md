# Vela_class 校园助手 Demo 说明

## 页面结构

```
pages/
├── home/            # 首页「此刻」
├── schedule/        # 课表
├── exam/            # 考试
├── task/            # 待办
├── course-detail/   # 课程详情
└── task-detail/     # 待办详情
```

## 页面跳转

```
                    ┌─────────────┐
                    │   home      │
                    │   (首页)     │
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ schedule │    │   exam   │    │   task   │
    │  (课表)   │    │  (考试)   │    │  (待办)   │
    └──────────┘    └──────────┘    └──────────┘

    点击课程卡片 ──→ course-detail
    点击待办条目 ──→ task-detail
```

## 各页面功能

### home（首页「此刻」）
- 显示当前时间、日期
- 主卡片根据时间自动切换状态：
  - **下一节课**：课程名、开始时间、教室、倒计时（蓝色）
  - **正在上课**：课程名、剩余时间、进度条（绿色）
  - **今日课程已结束**：显示明天/最近课程
  - **今日无课**：显示最近考试倒计时
- 底部显示考试摘要、待办摘要卡片

### schedule（课表）
- **今天模式**：纵向时间轴展示今日课程，区分已结束/进行中/未开始
- **本周模式**：星期选择器 + 课程列表，支持切换周一到周日

### exam（考试）
- 顶部大卡片展示最近考试的倒计时
- 下方列表展示后续考试

### task（待办）
- 按「今天」「本周」「以后」分组
- 点击左侧 ○ 可标记完成 ●
- 紧急任务橙色提醒，临界任务红色提醒

### course-detail（课程详情）
- 显示课程时间、教室、教师
- 进行中显示进度条和剩余时间

### task-detail（待办详情）
- 显示任务名称、课程、类型、截止时间
- 可切换完成/未完成状态
