## 四、实现逻辑

### 当前实现已正确

**schedule.ux 跳转逻辑**：
```javascript
goToDetail(courseId, source) {
  router.push({
    uri: '/pages/course-detail',
    params: {
      courseId: courseId,
      source: source || 'today'
    }
  })
}
```

- 今日模式：`onclick="goToDetail($item.id, 'today')"`
- 本周模式：`onclick="goToDetail($item.id, 'week')"`
- 全部模式：`onclick="goToDetail($item.id, 'all')"`

**course-detail.ux 接收逻辑**：
```javascript
protected: {
  courseId: '',
  source: 'today'
},

private: {
  showStatus: true
},

onInit() {
  this.showStatus = this.source === 'today'
  // ...
}

loadCourse() {
  if (this.showStatus) {
    this.status = getCourseStatus(this.course, now)
    // 计算实时状态
  }
}
```

**模板显示逻辑**：
```html
<div if="{{ showStatus && status === 'ongoing' }}" class="status-section">
  <!-- 剩余时间、进度条 -->
</div>
<div if="{{ showStatus && status === 'upcoming' }}" class="status-section">
  <!-- 还有多少分钟开始 -->
</div>
<div if="{{ showStatus && status === 'finished' }}" class="status-section">
  <!-- 已结束 -->
</div>
```

### 逻辑验证
- `source='today'` → `showStatus=true` → 计算并显示实时状态
- `source='week'` → `showStatus=false` → 不计算状态，不显示状态区域
- `source='all'` → `showStatus=false` → 不计算状态，不显示状态区域
