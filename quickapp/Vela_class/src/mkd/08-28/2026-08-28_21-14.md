# 项目修改报告

时间：2026-08-28 21:14

## 一、修改内容

修复课表页面课程卡片文字过长导致显示异常的问题，使用 OpenVela 官方 `<marquee>` 组件实现跑马灯效果。

## 二、问题原因

课程卡片中课程名称、教室、教师、状态信息分行显示，当文字过长时会被截断或覆盖。

## 三、修改文件

- `src/pages/schedule/schedule.ux`

## 四、实现逻辑

### 1. 使用官方 marquee 组件
OpenVela 支持 `<marquee>` 组件，用于实现跑马灯效果：
```html
<marquee scrollamount="4" loop="-1" text-offset="50">
  滚动文本内容
</marquee>
```

### 2. 合并课程信息为单行文本
将原来的多个 `<text>` 合并为一个 `<marquee>`：
```html
<marquee class="card-marquee" scrollamount="4" loop="-1" text-offset="50">
  {{ $item.name }} {{ $item.classroom }} · {{ $item.teacher }}{{ $item.status === 'ongoing' ? ' 正在进行 · 剩余' + $item.remainingMin + '分钟' : '' }}
</marquee>
```

### 3. 滚动参数
- `scrollamount="4"`：每帧滚动4像素，速度适中
- `loop="-1"`：无限循环
- `text-offset="50"`：首尾相接时距离50px

### 4. 样式
```css
.card-marquee {
  font-size: 17px;
  color: #FFFFFF;
  width: 100%;
}
```
