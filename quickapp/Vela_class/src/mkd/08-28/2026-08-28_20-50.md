# 项目修改报告

时间：2026-08-28 20:50

## 一、修改内容

在首页增加隐藏 Debug 入口，方便开发测试时重置 Mock 数据。

## 二、问题原因

修改默认数据后，Storage 中已存在旧数据，需要手动触发重置才能加载新数据。

## 三、修改文件

- `src/pages/home/home.ux`
- `src/pages/debug/debug.ux`（新增）
- `src/manifest.json`

## 四、实现逻辑

### 1. 首页隐藏入口
底部添加 "VELA CLASS" 文字，使用极低调样式：
```css
.brand-text {
  font-size: 12px;
  color: #333333;
}
```

### 2. 连续点击逻辑
```javascript
onBrandClick() {
  this.debugClickCount++
  
  if (this.debugClickCount >= 5) {
    this.debugClickCount = 0
    router.push({ uri: '/pages/debug' })
    return
  }
  
  // 2秒内没有继续点击则重置计数
  this.debugClickTimer = setTimeout(() => {
    this.debugClickCount = 0
  }, 2000)
}
```

### 3. Debug 页面功能
- 显示"开发工具"标题
- 提供"重置测试数据"按钮
- 调用 `resetToMockData()` 重置数据
- 显示操作结果提示

### 4. 路由配置
manifest.json 新增：
```json
"pages/debug": {
  "component": "debug"
}
```

## 五、测试验证

### 测试步骤：
1. 打开首页，底部显示"VELA CLASS"
2. 连续点击5次 → 进入 Debug 页面
3. 修改 data.js 新增一门课程
4. 点击"重置测试数据"
5. 返回课表 → 新课程显示

### 预期效果：
- 普通用户只看到低调的"VELA CLASS"标识
- 开发人员连续点击可进入调试页面
- 重置后数据恢复为默认 Mock 数据
