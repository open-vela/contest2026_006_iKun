# 项目修改报告

时间：2026-08-28 20:58

## 一、修改内容

修复 resetMockData() 重置数据后首页统计数据不更新的问题。

## 二、问题原因

1. `resetToMockData()` 只更新了缓存和 Storage，但没有确保页面重新读取
2. 首页 `onShow` 只调用了 `refreshTasksFromStorage()`，没有刷新课程和考试数据
3. 从 Debug 页面返回首页时，考试和课程缓存仍是旧数据

## 三、修改文件

- `src/common/storage.js`
- `src/pages/home/home.ux`

## 四、实现逻辑

### 1. storage.js - resetToMockData 改进
- 使用深拷贝创建默认数据副本
- 确保 Promise 在所有数据保存完成后 resolve
- 保存失败时 reject

```javascript
export function resetToMockData() {
  return new Promise((resolve, reject) => {
    const defaultCourses = courses.map(c => ({ ...c }))
    const defaultExams = exams.map(e => ({ ...e }))
    const defaultTasks = tasks.map(t => ({ ...t }))
    
    courseCache = defaultCourses
    examCache = defaultExams
    taskCache = defaultTasks
    
    // 保存到 Storage...
  })
}
```

### 2. home.ux - onShow 改进
同时刷新课程、考试、待办三种数据：

```javascript
onShow() {
  ensureStorageReady()
    .then(() => Promise.all([
      refreshCoursesFromStorage(),
      refreshExamsFromStorage(),
      refreshTasksFromStorage()
    ]))
    .then(() => {
      this.updateTime()
      this.updateStatus()
    })
}
```
