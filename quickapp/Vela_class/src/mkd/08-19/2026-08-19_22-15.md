## 2. 待办无法继续滚动原因

### 原页面固定高度
`.page` 设置为 `height: 466px`，所有任务分组直接放在这个固定高度容器中。

### 原页面为什么发生内容裁切
当任务数量较多时，总内容高度超过 466px 可视区域，但缺少滚动容器，导致底部任务被圆屏裁切。

### 是否缺少 scroll 容器
是，原页面没有使用 `<scroll>` 组件，所有内容堆叠在固定高度的 `.page` 中。

## 3. Scroll 实现

### 使用的组件
使用 OpenVela 官方 `<scroll>` 组件，设置 `scroll-y="true"` 实现纵向滚动。

### scroll-y 设置
```html
<scroll class="task-scroll" scroll-y="true" bounces="true">
```

### scroll 最终宽度
```css
.task-scroll { width: 400px; }
```

### scroll 最终高度
```css
.task-scroll { height: 375px; }
```
根据页面顶部 45px padding + 标题高度 + 间距计算得出。

## 4. 圆屏底部安全区域

### bottom-safe-space 最终高度
```css
.bottom-safe-space { width: 100%; height: 80px; }
```

### 为什么需要额外底部空间
圆形屏幕下方有弧线，如果最后一个任务刚好停在屏幕底部，会被弧线遮挡。增加 80px 安全空间，用户滚到底后可以继续向上拖，让最后一个任务完整进入圆屏中间安全区域。

## 5. 手势兼容
