# 项目修改报告

时间：2026-08-19 21:52

## 一、修改内容

修复待办页面滚动布局问题，使用 scroll 组件实现纵向滚动，并处理圆屏底部安全空间。

## 二、问题原因

待办页面固定高度 466px，所有任务分组直接堆叠，当内容超出可视区域时底部任务被裁切，无法滚动查看。

## 三、修改文件

- `src/pages/task/task.ux`

## 四、实现逻辑

### 1. 添加 scroll 组件

使用 `<scroll>` 包裹任务内容区域，实现纵向滚动：

```html
<scroll class="task-scroll" scroll-y="true" bounces="true">
  <!-- 所有任务分组 -->
  <div class="bottom-safe-space"></div>
</scroll>
```

### 2. scroll 配置

```css
.task-scroll {
  width: 400px;
  height: 375px;
  flex-direction: column;
  align-items: center;
}
```

### 3. 防止 Flex 压缩

所有内容元素设置 `flex-shrink: 0`：
- `.section`
- `.task-list`
- `.task-item`
- `.section-title`
- `.bottom-safe-space`

### 4. 任务卡片最小高度

```css
.task-item {
  min-height: 64px;
  flex-shrink: 0;
}
```

### 5. 底部安全空间

```css
.bottom-safe-space {
  width: 380px;
  height: 90px;
  flex-shrink: 0;
}
```

## 五、测试验证

### 测试步骤：
1. 进入待办页面
2. 向上滑动查看所有任务
3. 确认最后一个任务完整显示
4. 确认底部有安全空间
5. 上下滑动不影响边缘返回手势

### 预期效果：
- 所有任务可完整显示
- 支持纵向滚动
- 圆屏底部不裁切内容

## 六、后续建议

1. 如果任务数量较多，可以考虑增加滚动条指示器
