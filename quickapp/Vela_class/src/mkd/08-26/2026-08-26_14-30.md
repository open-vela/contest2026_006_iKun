# 项目修改报告

时间：2026-08-26 14:30

## 一、修改内容

修复课程添加页面步骤2/3进入时卡死的问题，原因是 picker 组件内部嵌套了子组件。

## 二、问题原因

openvela 官方 `picker` 是原生表单组件，**不支持子组件**。

原来的代码在 picker 内部嵌套了 `<text>` 子组件：
```html
<picker type="time" ...>
  <text>08:00</text>  <!-- 错误：picker 不支持子组件 -->
</picker>
```

这导致 Native 组件初始化异常，引起模拟器卡死或调试连接断开。

## 四、实现逻辑

### 修改前（错误写法）
```html
<picker class="time-picker" type="time" selected="{{ startTime }}" onchange="onStartTimeChange">
  <text class="picker-text">{{ startTime || '选择时间' }}</text>
</picker>
```

### 修改后（正确写法）
```html
<div class="picker-wrap">
  <picker class="time-picker" type="time" selected="{{ startTime }}" onchange="onStartTimeChange"></picker>
  <text class="picker-value">{{ startTime || '08:00' }}</text>
</div>
```

### 修改的四个 Picker
1. **开始时间**：`type="time"`，picker 内部为空
2. **结束时间**：`type="time"`，picker 内部为空
3. **开始周**：`type="text"`，picker 内部为空
4. **结束周**：`type="text"`，picker 内部为空

### picker-wrap 布局
```css
.picker-wrap {
  width: 100%;
  height: 52px;
  background-color: #1A1A1A;
  border-radius: 14px;
  flex-direction: row;
  align-items: center;
  justify-content: center;
}
```

### picker-value 绝对定位
```css
.picker-value {
  font-size: 17px;
  color: #FFFFFF;
  position: absolute;
}
```

picker 和文字重叠显示，picker 负责响应点击，文字负责显示当前值。

## 六、后续建议

1. 使用 openvela 官方组件时，必须严格遵守组件规范
2. picker 等原生组件不支持子组件，只能通过外部布局显示额外信息
