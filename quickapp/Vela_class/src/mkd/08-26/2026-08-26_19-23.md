# 项目修改报告

时间：2026-08-26 19:23

## 一、修改内容

新增手动添加课程的删除功能：
- 默认 Mock 课程不显示删除按钮
- 用户手动添加的课程可以删除
- 删除前需要二次确认

## 二、问题原因

用户手动添加的课程无法删除，需要在课程详情页提供删除功能。

## 三、修改文件

- `src/common/storage.js`
- `src/pages/course-detail/course-detail.ux`

### course-detail.ux 新增状态和UI

**新增状态**：
- `canDelete`: 是否显示删除按钮
- `deleteConfirming`: 是否正在确认删除
- `deleting`: 是否正在删除中

**UI 结构**：
```
课程详情内容
↓
删除课程按钮（仅用户课程显示）
↓
点击后切换为：取消 + 确认删除
↓
底部安全空间
```

**onBackPress 处理**：
- 如果正在确认删除，先取消确认状态
- 否则交给系统默认返回

### 删除流程
1. 用户点击"删除课程"
2. 显示二次确认："确定删除这门课程？"
3. 点击"取消" → 恢复原状态
4. 点击"确认删除" → 调用 `deleteCourse(courseId)`
5. 成功 → 返回课表
6. 课表 `onShow()` 自动刷新，课程消失

## 五、测试验证

### 测试步骤：
1. 默认 Mock 课程（如数据结构）详情页不显示"删除课程"按钮
2. 手动添加新课程，保存
3. 进入新课程详情，显示"删除课程"按钮
4. 点击"删除课程" → 显示二次确认
5. 点击"取消" → 不删除，恢复原状
6. 再次点击"删除课程" → 点击"确认删除"
7. 返回课表 → 课程消失
8. 重新进入应用 → 课程仍然不存在

### 预期效果：
- 默认课程不可删除
- 手动课程可删除
- 删除前必须确认
- 删除持久化到 storage
