# 项目修改报告

时间：2026-08-26 21:47

## 一、修改内容

调整考试页和待办页的添加入口布局，与课表页面统一设计语言。

## 二、问题原因

原"+"按钮使用绝对定位在标题旁边，导致：
- 按钮挤压标题
- 圆形屏幕顶部区域视觉不协调
- 与课表页面布局风格不一致

## 三、修改文件

- `src/pages/exam/exam.ux`
- `src/pages/task/task.ux`

## 四、实现逻辑

### 考试页面修改

**原结构**：
```html
<div class="header">
  <text class="title">考试</text>
  <div class="add-btn">+</div>
</div>
```

**修改后**：
```html
<div class="header">
  <text class="title">考试</text>
</div>
<div class="action-row">
  <text class="action-text">近期考试 · {{ examList.length }}场</text>
  <div class="add-btn">+</div>
</div>
```

### 待办页面修改

**原结构**：
```html
<div class="header">
  <text class="title">待办</text>
  <div class="add-btn">+</div>
</div>
```

**修改后**：
```html
<div class="header">
  <text class="title">待办</text>
</div>
<div class="action-row">
  <text class="action-text">待处理 · {{ pendingCount }}项</text>
  <div class="add-btn">+</div>
</div>
```

### pendingCount 计算
```javascript
this.pendingCount = this.overdueTasks.length + this.todayTasks.length + this.weekTasks.length + this.futureTasks.length
```
不包含已完成任务。

### action-row 样式
```css
.action-row {
  width: 380px;
  flex-direction: row;
  align-items: center;
  justify-content: space-between;
  margin-bottom: 12px;
}
```
