# 项目修改报告

时间：2026-08-26 16:10

## 一、修改内容

优先使用 openvela 官方组件替代自定义实现：
1. 课表课程列表改用 `list/list-item`
2. 进度条改用官方 `progress` 组件
3. 课程详情页和待办详情页添加 `scroll` 滚动

## 二、问题原因

- 课表课程列表使用 `div for`，最后一项可能被圆屏裁切
- 进度条使用自制 `progress-bar/progress-fill`，官方已有 `progress` 组件
- 课程详情和待办详情没有滚动，长内容无法完整显示

## 三、修改文件

- `src/pages/schedule/schedule.ux`
- `src/pages/home/home.ux`
- `src/pages/course-detail/course-detail.ux`
- `src/pages/task-detail/task-detail.ux`

## 四、实现逻辑

### 1. 课表课程列表改用 list/list-item

**修改前**：
```html
<div class="timeline">
  <div for="{{ todayCourses }}" class="timeline-item">
    ...
  </div>
</div>
```

**修改后**：
```html
<list class="course-list" bounces="true">
  <list-item for="{{ todayCourses }}" class="timeline-item" type="todayCourse">
    ...
  </list-item>
  <list-item if="{{ todayCourses.length === 0 }}" type="todayEmpty" class="empty-item">
    <text class="empty-text">今日无课</text>
  </list-item>
  <list-item type="todaySafe" class="safe-space-item"></list-item>
</list>
```

三种模式（今天/本周/全部）都已迁移为官方 list。

### 2. 进度条改用官方 progress

**修改前**：
```html
<div class="progress-bar">
  <div class="progress-fill" style="width: {{ progress }}%"></div>
</div>
```

**修改后**：
```html
<progress class="progress-bar" percent="{{ progress }}"></progress>
```

**样式**：
```css
.progress-bar {
  color: #58D68D;
  layer-color: #2B2B2B;
  stroke-width: 8px;
}
```

### 3. 课程详情页添加 scroll

```html
<scroll class="detail-scroll" scroll-y="true" bounces="true">
  <div if="{{ course }}" class="content">
    ...
  </div>
  <div class="bottom-safe-space"></div>
</scroll>
```

### 4. 待办详情页添加 scroll

同样结构，支持长内容滚动。
