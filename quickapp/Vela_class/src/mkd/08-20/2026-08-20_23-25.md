# 项目修改报告

时间：2026-08-20 23:25

## 一、修改内容

将 InputMethod 组件集成到课程添加页面，实现中文输入功能。

## 二、问题原因

原课程添加页面使用原生 `<input>` 组件，无法输入中文。需要使用 InputMethod 组件替代。

## 三、修改文件

- `src/pages/course-add/course-add.ux`

## 四、实现逻辑

### 组件引入
```html
<import name="input-method" src="../../components/InputMethod/InputMethod.ux"></import>
```

### 输入区域改造
将原来的 `<input>` 改为可点击的 `<div>`，点击时显示键盘：
```html
<div class="input-wrapper" @click="showKeyboard('name')">
  <text if="{{ !name }}" class="placeholder-text">请输入课程名称</text>
  <text class="input-text">{{ name }}</text>
</div>
```

### 键盘状态管理
```javascript
private: {
  keyboardHidden: true,
  currentInputField: ''  // 记录当前正在输入的字段
}

showKeyboard(field) {
  this.currentInputField = field
  this.keyboardHidden = false
}
```

### 输入完成处理
```javascript
onComplete(evt) {
  const content = evt.detail.content
  if (this.currentInputField === 'name') {
    this.name += content
  } else if (this.currentInputField === 'teacher') {
    this.teacher += content
  } else if (this.currentInputField === 'classroom') {
    this.classroom += content
  }
}
```

### 删除处理
```javascript
onDelete() {
  if (this.currentInputField === 'name' && this.name.length > 0) {
    this.name = this.name.slice(0, -1)
  } else if (this.currentInputField === 'teacher' && this.teacher.length > 0) {
    this.teacher = this.teacher.slice(0, -1)
  } else if (this.currentInputField === 'classroom' && this.classroom.length > 0) {
    this.classroom = this.classroom.slice(0, -1)
  }
}
```

### 切换步骤时隐藏键盘
```javascript
nextStep() {
  if (this.step === 1) {
    this.keyboardHidden = true
  }
  ...
}
```
