# 项目修改报告

时间：2026-08-20 19:33

## 一、修改内容

实现了课程手动添加功能，用户可以在课表页面点击"+"按钮添加新课程。

## 二、问题原因

1. 原课程数据来自 `data.js` 的静态 mock 数据
2. `schedule.js` 直接导入 `courses` 静态数组，没有从 storage 读取
3. storage 已有课程缓存机制，但缺少课程新增接口
4. 用户无法手动添加自己的课程

## 三、修改文件

### 修改的文件：
1. `src/common/schedule.js` - 改为从 storage 读取课程数据
2. `src/common/storage.js` - 增加 `addCourse()` 函数
3. `src/manifest.json` - 增加 `course-add` 页面路由
4. `src/pages/schedule/schedule.ux` - 增加添加课程入口和 onShow 刷新

### 新增的文件：
1. `src/pages/course-add/course-add.ux` - 课程添加页面

## 四、实现逻辑

### 1. 统一数据源
- `schedule.js` 改为导入 `getCourses` from storage，而不是直接导入静态 `courses`
- 所有课程筛选函数（`getTodayCourses`、`getCoursesByWeekday`、`getAllCoursesByWeekday`）都从 `courseCache` 读取

### 2. 课程新增接口
- `storage.js` 新增 `addCourse(courseData)` 函数
- 自动生成唯一 ID：`course_` + 时间戳 + 随机字符串
- 使用不可变更新：`courseCache = [...courseCache, newCourse]`
- 持久化到 `system.storage`

### 3. 课程添加页面
- 分步骤填写：基本信息 → 时间 → 周次
- 支持全周/单周/双周/自定义周次选择
- 保存后自动返回课表页面

### 4. 数据同步
- `schedule.ux` 新增 `onShow()` 生命周期
- 从添加页面返回时自动调用 `refreshCoursesFromStorage()`
- 刷新今日课表、本周课表、全部课表

### 5. Storage 规则
- 有 storage 数据：读取 storage
- 无 storage 数据：使用默认 mock 课程
- 不会覆盖为空数组

## 五、测试验证

### 测试步骤：
1. 进入课表页面，点击右上角"+"按钮
2. 填写课程名称、教师、教室
3. 选择星期、开始时间、结束时间
4. 选择周次（全周/单周/双周/自定义）
5. 点击保存
6. 返回课表页面，确认新课程已显示
7. 切换到今日/本周/全部模式，确认课程正确显示
8. 返回首页，确认"下一节课"可能显示新课程

### 预期效果：
- 新课程自动保存到 storage
- 课表页面实时显示新课程
- 首页下一节课逻辑自动包含新课程
