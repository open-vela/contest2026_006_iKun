2. **输入框文字显示问题**：input 高度和字体大小配置需要优化
3. **onInputFocus 未实现真实滚动**：原代码只打印日志，没有执行滚动操作

## 四、实现逻辑

### 1. placeholder 问题解决方案

**问题**：OpenVela input 不支持 `placeholder-color` 属性

**解决方案**：使用自定义 placeholder 覆盖层

```html
<div class="input-wrapper">
  <text if="{{ !name }}" class="placeholder-text">请输入课程名称</text>
  <input class="input" type="text" value="{{ name }}" onchange="onNameChange" />
</div>
```

**实现原理**：
- 在 input 外层添加 `input-wrapper` 容器
- 使用 `<text>` 元素模拟 placeholder，颜色可自定义
- 当输入框有值时，通过 `if="{{ !name }}"` 隐藏 placeholder
- input 本身不设置 placeholder 属性

**样式配置**：
```css
.input-wrapper {
  width: 100%;
  height: 52px;
  background-color: #1A1A1A;
  border-radius: 14px;
  flex-direction: row;
  align-items: center;
}

.placeholder-text {
  position: absolute;
  left: 18px;
  font-size: 16px;
  color: #666666;  /* 中灰色，在深色背景下清晰可见 */
}

.input {
  width: 100%;
  height: 52px;
  background-color: transparent;
  border-radius: 14px;
  padding: 0 18px;
  font-size: 17px;
  color: #FFFFFF;
}
```

### 3. onInputFocus 实现真实滚动

**修改前**：
```js
onInputFocus(index) {
  const scrollTo = index * 85
  setTimeout(() => {
    console.log('Input focused, scroll to:', scrollTo)
  }, 300)
}
```

**修改后**：
```js
onInputFocus(index) {
  const scrollTo = index * 85
  setTimeout(() => {
    try {
      const scrollEl = this.$element('formScroll')
      if (scrollEl && scrollEl.scrollTo) {
        scrollEl.scrollTo(scrollTo)
      }
    } catch (e) {
      console.log('Scroll not available, using alternative approach')
    }
  }, 300)
}
```

**实现原理**：
- 使用 `this.$element('formScroll')` 获取 scroll 组件引用
- 调用 `scrollTo()` 方法滚动到指定位置
- 添加 try-catch 处理，防止 API 不可用导致崩溃
- 延迟 300ms 执行，等待键盘弹出后再滚动
