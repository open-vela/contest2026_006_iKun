## 2. 问题原因

### storage 数据覆盖问题
`refreshExamsFromStorage()` 和 `refreshTasksFromStorage()` 存在逻辑错误：

当 `system.storage` 中没有对应数据时（例如首次启动或数据未持久化），代码会将缓存设置为空数组 `[]`：

```js
const parsed = data ? JSON.parse(data) : []
```

这导致：
- `initStorage()` 正确初始化了 `examCache = [...exams]`（3场考试）
- 但进入考试页面时，`refreshExamsFromStorage()` 调用 `storage.get()` 获取数据
- 由于考试数据从未写入 `system.storage`，`data` 为空
- 结果 `examCache` 被覆盖为 `[]`
- 页面显示"暂无考试安排"

### 同样问题
`refreshTasksFromStorage()` 存在同样问题，可能导致待办数据丢失。

## 3. refreshExamsFromStorage 修改

### 修改前
```js
const parsed = data ? JSON.parse(data) : []
examCache = parsed.map(exam => ({ ...exam }))
```

### 修改后
```js
// 没有持久化数据时使用默认 mock 数据
const parsed = data ? JSON.parse(data) : [...exams]
examCache = parsed.map(exam => ({ ...exam }))
```

## 4. refreshTasksFromStorage 修改

同样修复：
```js
// 没有持久化数据时使用默认 mock 数据
const parsed = data ? JSON.parse(data) : [...tasks]
taskCache = parsed.map(task => ({ ...task }))
```

## 5. 新增 refreshCoursesFromStorage

为保持一致性，新增 `refreshCoursesFromStorage()` 函数，使用相同逻辑：
```js
const parsed = data ? JSON.parse(data) : [...courses]
courseCache = parsed.map(course => ({ ...course }))
```
