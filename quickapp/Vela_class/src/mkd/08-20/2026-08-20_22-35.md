# 项目修改报告

时间：2026-08-20 22:35

## 一、修改内容

修复课程添加页面输入框无法连续输入的问题。

## 二、问题原因

**现象**：
- 输入一个字符后，继续输入第二个字符时，第一个字符被覆盖
- 无法连续输入多个字符

**原因分析**：
- 原代码使用 `value="{{ name }}"` 双向绑定
- 每次输入触发 `onchange` 事件
- 更新 `this.name` 后，页面重新渲染
- `value` 被重新赋值，导致输入框内容被重置

**根本原因**：
OpenVela Quick App 的 `change` 事件在每次输入时都会触发，但页面重新渲染会覆盖输入框的值。

## 三、修改文件

- `src/pages/course-add/course-add.ux`

## 四、实现逻辑

### 解决方案：使用中间变量

**修改前**：
```html
<input class="input" type="text" value="{{ name }}" onchange="onNameChange" />
```

**修改后**：
```html
<input class="input" type="text" value="{{ inputName }}" onchange="onNameChange" />
```

### 数据结构调整

**新增中间变量**：
```javascript
private: {
  name: '',           // 最终提交的值
  inputName: '',      // 输入框绑定的值
  inputTeacher: '',
  inputClassroom: '',
  ...
}
```

### 事件处理

```javascript
onNameChange(e) {
  this.inputName = e.value
  this.name = e.value
}
```

### 工作原理

1. 输入框绑定 `inputName`，而不是直接绑定 `name`
2. 用户输入时，`change` 事件触发
3. 更新 `inputName` 和 `name`
4. 由于 `inputName` 是独立变量，不会影响其他逻辑
5. 输入框可以正常连续输入
