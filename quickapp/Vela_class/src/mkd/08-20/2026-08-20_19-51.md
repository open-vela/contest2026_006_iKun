# 项目修改报告

时间：2026-08-20 19:51

## 一、修改内容

优化了课程添加功能的手表端交互体验，包括添加按钮位置调整、输入框样式优化、滚动布局支持。

## 二、问题原因

1. **添加按钮位置异常**：原按钮使用 `position: absolute; right: 10px`，在圆形屏幕上可能遮挡标题文字
2. **输入框文字颜色问题**：placeholder 颜色在深色背景下不可见（OpenVela 不支持 `placeholder-color` 属性）
3. **键盘遮挡问题**：原页面没有使用 scroll 组件，键盘弹出后遮挡输入区域
4. **中文输入问题**：input type="text" 应该支持系统中文输入法

## 三、修改文件

### 修改的文件：
1. `src/pages/schedule/schedule.ux` - 调整添加按钮位置
2. `src/pages/course-add/course-add.ux` - 优化输入框和滚动布局

## 四、实现逻辑

### 1. 添加按钮位置调整
**调整前**：
- 按钮在标题栏内，使用 `position: absolute; right: 10px`
- 可能遮挡标题文字

**调整后**：
- 按钮移到模式切换区域右侧
- 使用 `flex-direction: row` 布局
- 按钮与模式切换栏并排显示
- 不遮挡标题

```html
<div class="mode-row">
  <div class="mode-switch">...</div>
  <div class="add-btn" onclick="goToAddCourse">
    <text class="add-text">+</text>
  </div>
</div>
```

### 2. 输入框样式优化
**调整内容**：
- 输入框高度从 44px 增加到 48px，提高可点击性
- 标签颜色从 `#8F8F8F` 改为 `#A0A0A0`，提高可见性
- 由于 OpenVela 不支持 `placeholder-color` 属性，placeholder 颜色由系统默认处理

### 3. 滚动布局支持
**添加 scroll 组件**：
```html
<scroll class="form-scroll" scroll-y="true" bounces="true">
  <!-- 表单内容 -->
</scroll>
```

**scroll 配置**：
- 宽度：400px
- 高度：380px
- 支持弹性滚动

**防压缩处理**：
- `.content`：`flex-shrink: 0`
- `.form-group`：`flex-shrink: 0`
- `.bottom-safe-space`：`flex-shrink: 0`

### 4. 时间选择器优化
- 使用 scroll 包裹时间选项列表
- 支持滚动选择时间

### 5. input 配置检查
- 保持 `type="text"`，支持系统中文输入法
- 中文输入法是否可用取决于系统能力

## 五、测试验证

### 测试步骤：
1. 进入课表页面，确认添加按钮在模式切换栏右侧

3. 点击输入框，确认可以弹出软键盘
